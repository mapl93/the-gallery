## Overview

Shipping Info presents an ordered set of target-owned service facts with optional icons, labels, and supporting text.

The `items` slot owns ordered information compositions. Icons are optional and do not define a fixed icon library or structured service schema.

## Usage Guidelines

<DoDont>
  <Do>Use short, verifiable service facts that help users understand fulfillment or policy expectations.</Do>
  <Dont>Do not present promotional claims that the target cannot fulfill.</Dont>
</DoDont>

Keep each label and supporting statement understandable without its icon.

## Accessibility

- Keep informative text in the DOM and do not rely on icons alone.
- Hide decorative icons from assistive technology; name an icon only when it adds unique meaning.
- Use native links when an item leads to a complete shipping, return, or security policy.
- Maintain sufficient contrast for labels, supporting text, and icons.
