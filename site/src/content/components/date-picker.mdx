## Overview

Date field with a custom calendar grid and month navigation.

## Presentation

Date Picker supports `default`, `error`, `success`, and `warning` validation families on its input while calendar selection remains an independent state.

## Usage Guidelines

<DoDont>
  <Do>Use a custom calendar when visual date context materially improves selection.</Do>
  <Dont>Don't replace a target's accessible native date input without a clear benefit.</Dont>
</DoDont>

## Accessibility

- Synchronize the input value with the selected calendar day.
- Expose current, selected, outside-month, and disabled states.
- Support arrow-key day navigation, PageUp/PageDown month navigation, selection, and Escape.
- Preserve the visible label and associated feedback.
