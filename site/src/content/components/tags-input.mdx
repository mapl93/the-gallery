## Overview

Multi-value text input that produces removable tag chips.

## Presentation

Tags Input supports `default`, `error`, `success`, and `warning` validation families around the complete entry surface.

## Usage Guidelines

<DoDont>
  <Do>Always pair form inputs with visible labels for accessibility.</Do>
  <Dont>Don't rely on placeholder text as the only label — it disappears on input.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Tags Input depends on the Tag primitive for chip semantics, but tag creation and removal behavior is target-owned.
</Callout>

- Provide a visible label or equivalent accessible name for the entry field.
- Name each remove button with the tag value it removes.
- Announce duplicate or invalid tag errors.
- Keep the text field focused after adding or removing tags when practical.
