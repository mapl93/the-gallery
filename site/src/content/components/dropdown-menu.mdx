## Usage Guidelines

<DoDont>
  <Do>Use dropdown menu for compact action lists that open from a button trigger.</Do>
  <Dont>Don't use dropdown menu for primary navigation when visible links would be clearer.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  The CSS adapter provides the visual states; the target implementation owns open state, focus movement, and keyboard behavior.
</Callout>

- Use a button trigger with `aria-haspopup="menu"`, `aria-expanded`, and `aria-controls`.
- Support ArrowUp, ArrowDown, Home, End, Enter, Space, and Escape.
- Close on `Escape` key press.
- Skip disabled items during keyboard activation.
