## Overview

Cart Line Item is the canonical target-controlled record used by Cart Page, Cart Drawer, Order Detail, and future cart or order collections. It requires a visible product identity and canonical Price composition; media, destination, details, Quantity Selector, remove, and save-for-later actions are optional.

## Presentation

`.cart-lines` is the native list and inline-size container. Every target line identity renders as one `li.cart-line`; a standalone example still uses the list wrapper. The line uses intrinsic reflow rather than viewport breakpoints, so the same anatomy works in Cart Drawer, Cart Page, and read-only Order Detail contexts.

`price` composes canonical Price; `quantitySelector` composes canonical Quantity Selector; `removeAction` and `saveAction` compose canonical Button. Cart Line Item does not reproduce their markup, value, formatting, busy, disabled, or focus contracts.

## Usage Guidelines

<DoDont>
  <Do>Keep one native line record synchronized with target cart or order truth and compose canonical dependencies.</Do>
  <Dont>Do not mirror raw platform records, format money, calculate inventory, or run a cart mutation service inside the presentation component.</Dont>
</DoDont>

- Render the title as one link only when the target has a truthful destination; otherwise use plain text.
- Treat adjacent media as decorative when title and details already identify the product. Use informative alt text only when the image adds unique meaning.
- Use `details` for complete target-authored variant, property, selling-plan, fulfilment, or discount text rather than exposing a Shopify-specific record schema.
- Omit Quantity Selector and mutation actions for read-only order records.
- Render save for later only when the target supplies a real persistence capability and result model.

## Accessibility

- Use `ul.cart-lines` and one `li.cart-line` per target line. Do not add `article`, widget roles, roving focus, or an aggregate line label.
- Keep every optional title link and Button keyboard reachable with the canonical visible focus treatment.
- Give Quantity Selector, remove, and save actions names that include the product context.
- Announce confirmed quantity/remove/save results and errors once from the surrounding target status policy; Price and each line are not live regions.
- After confirmed removal, the Cart Page, Cart Drawer, or Order Detail target places focus on a logical surviving control or collection heading.
