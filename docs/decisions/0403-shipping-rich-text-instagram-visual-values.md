# ADR 0403: Shipping, Rich Text and Instagram Visual Values

Status: Accepted

Date: 2026-09-13

Expose five Shipping Info roles for item/section measures, inset, gap and icon
size; seven Rich Text Section roles for measure, rhythm, separate list/quotation
insets, quotation rule and link mix; eight Instagram Feed roles for measure,
crop, inset, handle/figure spacing, underline and handle-color mix. All retain
their current defaults and shared semantic inputs. Text-relative em values stay
text-relative; no new typography-family decision or source unit is introduced.

These are passive presentation changes. Native document semantics, shipping
statements/policies, social records, media alternatives and destinations remain
target-owned. No provider request, tracking, source reordering or interaction is
added. Studio and Exhibit derive controls from matching contract inventories.
Generated Web/Shopify follow source; existing copies adopt explicitly.
