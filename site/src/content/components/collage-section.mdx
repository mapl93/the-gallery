## Overview

Collage Section arranges ordered target-owned media items in an art-directed grid with optional heading, item-level feature spans, and captions. Item activation remains target-specific.

Feature span is an item-level layout modifier rather than a component state. Captions are item content; hover and focus-within treatments do not define navigation or command behavior.

## Usage Guidelines

<DoDont>
  <Do>Choose one clear feature item and keep DOM order meaningful when the grid collapses.</Do>
  <Dont>Do not assume collage items navigate, open a lightbox, or disclose product information.</Dont>
</DoDont>

Let the target supply native semantics only after an item destination or action has been established.

## Accessibility

- Provide useful alternative text for informative media and semantic captions when they add context.
- Keep essential information available without hover.
- Preserve meaningful source order independently of feature spans.
- Any target-supplied link or control must have an accessible name, visible focus, and defined activation behavior.
