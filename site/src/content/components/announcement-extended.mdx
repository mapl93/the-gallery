## Overview

Announcement Extended (`G11`) is deprecated as an independent public component. The owner-selected direction merges its useful capabilities into canonical [Announcement Bar](/components/announcement-bar) (`C2`) before v1.

G11 remains temporarily discoverable only so existing references can be audited and migrated. It owns no CSS file, selector, renderer, fixture, behavior, event, target adapter, or permanent alias.

Migration maps former uses to canonical `.announcement--countdown` or `.announcement--rotating`; Static uses the base `.announcement` root.

Exhibit and Studio deliberately resolve G11 through the same `GlobalStudio` renderer and `AnnouncementArtwork` used by C2. The old `.announcement-bar--countdown`, `.announcement-bar--rotating`, `.announcement-bar__slides`, `.announcement-bar__slide`, and `.announcement-bar__dismiss` implementation has been removed.

## Guidelines

<DoDont>
  <Do>Replace G11 with C2 and select one `static`, `countdown`, or `rotating` mode.</Do>
  <Do>Use orthogonal `dismissible` only when the target owns controlled removal and reappearance policy.</Do>
  <Dont>Do not preserve the old fixed-height CSS animation or duplicated dismiss markup.</Dont>
  <Dont>Do not add a compatibility class or second renderer that lets G11 drift from C2.</Dont>
</DoDont>

## Accessibility

Migration must preserve the canonical C2 requirements: neutral static content, canonical Countdown semantics, named Carousel structure, native localized controls, durable focus/manual pause, reduced-motion suppression, and readable intrinsic wrapping.

## Specification

The temporary G11 contract forwards the canonical C2 property, token, anatomy, dependency, and Web mapping vocabulary solely for migration tooling. Its contract status is `deprecated`, never `stable`; its Shopify adapter is unsupported because canonical C2 is the only target identity.

Remove G11 references before the v1 public surface is frozen. New consumers must depend directly on [Announcement Bar](/components/announcement-bar).
