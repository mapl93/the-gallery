## Usage Guidelines

<DoDont>
  <Do>Use context menu for secondary commands tied to a specific object or region.</Do>
  <Dont>Don't make critical actions available only through a context menu.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Context Menu reuses Dropdown Menu item anatomy, but the target must provide invocation, positioning, and focus behavior.
</Callout>

- Support pointer `contextmenu` and keyboard invocation with Shift+F10 or the Menu key.
- Close on `Escape` key press.
- Restore focus to the invoking element when the menu closes.
- Clamp the positioned menu inside the viewport.
