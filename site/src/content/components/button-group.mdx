## Overview

Groups related Button instances into one visual set without changing the semantics or state of any child.

<Preview html={'<div class="btn-group" role="group" aria-label="Display options"><button class="btn btn--outline" type="button">Option 1</button><button class="btn btn--outline" type="button">Option 2</button><button class="btn btn--outline" type="button">Option 3</button></div>'} label="Button Group" />

## Presentation

Button Group has one inherited Button size and two layout variants. Child variants, labels, disabled states, and activation remain owned by Button.

| Property | Value | Web mapping |
| --- | --- | --- |
| `variant` | `default` | `.btn-group` |
| `variant` | `full` | `.btn-group--full` |
| `groupLabel` | string | `aria-label` on the group |

## Usage Guidelines

<DoDont>
  <Do>Group actions that operate on the same object or represent one compact command set.</Do>
  <Dont>Do not use Button Group to imply a selected value; use Toggle or Segmented Control for selection.</Dont>
</DoDont>

Keep labels short enough that every action remains legible. Use the full variant only when distributing the available width improves comparison or touch access.

## Accessibility

<Callout type="info">
  Button Group is structural. Every child remains a native Button or Link with its own name and behavior.
</Callout>

- Use `role="group"` with `aria-label` or `aria-labelledby` when nearby text does not already explain the relationship.
- Preserve normal tab order; do not convert the group into one composite focus stop.
- Keep each child action independently named and disabled.
- The focused child is raised above adjacent borders so its focus indicator remains visible.
