## Overview

## Usage Guidelines

<DoDont>
  <Do>Use this component consistently across your theme for a cohesive UI.</Do>
  <Dont>Don't override the component's built-in states with custom CSS — use the provided variants instead.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Primitive components are building blocks. They're referenced by higher-level components throughout the system.
</Callout>

- Use `<button>` elements for actions and `<a>` for navigation. Never use `<div>` with a click handler.
