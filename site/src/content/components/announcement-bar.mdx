## Overview

Announcement Bar is one controlled compact surface with three mutually exclusive content modes: `static`, `countdown`, and `rotating`. Dismissal is an independent capability available in every mode. The former G11 Announcement Extended identity is deprecated and adds no second implementation.

The component owns its intrinsic layout, dependency composition, rotating selection controls, and request events. The target owns campaign content, scheduling, eligibility, placement, persistence, reappearance, analytics, navigation, and focus after controlled removal.

### Content modes

- `static` renders one stable message and optional canonical Link. It is ordinary page content, not an alert or live region.
- `countdown` composes canonical Countdown with `countdown--inline`. Its deadline, selected units, current values, retained zero, expiry state, and event remain owned by Countdown.
- `rotating` composes canonical Carousel with real horizontal scroll-snap slides, previous/next Icon Buttons, and a visible localized current/total counter. It never renders dots or a timing bar.

Every mode wraps intrinsically from its container. Narrow hosts may produce more rows; hiding units, clipping messages, scaling the component, and fixed-height animation are invalid.

Canonical mode selectors are `.announcement--countdown` and `.announcement--rotating`; Static uses the unmodified `.announcement` root.

### Controlled dismissal

`dismissible=true` adds canonical Close Button without creating a fourth content mode. Activation emits `announcementdismissrequest`; the target reconciles `visible`, removes or hides the surface, and decides focus destination, persistence, scope, expiry, and reappearance.

## Guidelines

<DoDont>
  <Do>Use one concise static message, a truthful canonical Countdown, or a short ordered set of rotating messages.</Do>
  <Do>Keep the same message understandable when motion is unavailable and provide localized control names and templates.</Do>
  <Do>Let the target control Header placement, scheduling, dismissal persistence, URLs, and campaign analytics.</Do>
  <Dont>Do not combine Countdown and Rotating content or treat dismissal as a content mode.</Dont>
  <Dont>Do not rotate critical legal, checkout, consent, safety, or time-sensitive information.</Dont>
  <Dont>Do not recreate Countdown, Carousel, Icon Button, Close Button, or Link behavior inside Announcement Bar.</Dont>
</DoDont>

Autoplay is optional and defaults off. When enabled it defaults to 6000 ms, exposes pause/play, pauses for hover and hidden documents, and becomes durably paused after focus or manual navigation. Only an explicit Play request resumes it. Reduced motion suppresses automatic rotation and smooth scrolling.

## Accessibility

- Rotating mode requires a useful accessible region name and exposes `aria-roledescription="carousel"`.
- Each real message is a named `group` with `aria-roledescription="slide"`; exactly one has `aria-current="true"`.
- Previous, next, optional pause/play, and dismiss controls are native canonical buttons with localized accessible names.
- Direct touch scrolling and focused track keyboard scrolling remain available; no root-wide Arrow key listener is installed.
- The visible counter is not redundantly announced. A separate localized position status is `aria-live="off"` while autoplay runs and polite while user-controlled.
- Focus, hover, document visibility, and reduced-motion preferences stop automatic changes without hiding content.
- Static page-load content remains neutral. A target replacing content after load must choose live-announcement policy from the actual meaning and urgency.

## Specification

### Public properties

| Property | Type | Default | Meaning |
| --- | --- | --- | --- |
| `mode` | `static \| countdown \| rotating` | `static` | Exclusive content model |
| `label` | string | empty | Region name; composition-required for rotating mode |
| `message` | slot | conditional | Static message and optional Link |
| `countdown` | slot | conditional | Canonical inline Countdown |
| `messages` | slot | conditional | At least two ordered real rotating messages |
| `visible` | boolean | `true` | Target-controlled presence |
| `dismissible` | boolean | `false` | Orthogonal canonical Close Button |
| `dismissLabel` | string | required | Localized dismiss name |
| `autoplay` | boolean | `false` | Rotating-mode automatic progression |
| `autoplayInterval` | 3000–12000 ms | `6000` | Validated rotation interval |
| `previousLabel`, `nextLabel` | string | required | Localized Icon Button names |
| `pauseLabel`, `playLabel` | string | required | Localized rotation-control names |
| `counterTemplate` | string | required | Visible template with `{current}` and `{total}` |
| `statusTemplate` | string | required | Assistive template with `{current}` and `{total}` |

### Events

- `announcementdismissrequest` requests target-controlled removal.
- `announcementchange` reports zero-based `current`, `total`, and whether selection was manual.
- `announcementplaybackchange` reports `playing`, `paused`, or `off` and projected user-pause state.

### Anatomy and dependencies

The required `.announcement` and `.announcement__body` contain exactly one mode-specific composition. Rotating mode uses `.announcement__rotation`, `.announcement__track`, `.announcement__slide`, `.announcement__controls`, `.announcement__previous`, `.announcement__counter`, `.announcement__next`, optional `.announcement__rotation-control`, and `.announcement__status`. Dismissible composition adds `.announcement__dismiss.close-btn`.

Dependencies are canonical [Link](/components/link), [Close Button](/components/close-button), [Countdown](/components/countdown), [Carousel](/components/carousel), and [Icon Button](/components/icon-button).

### Target translation

- Neutral Web implements all modes through canonical CSS, the Countdown runtime, and the shared Carousel rotation service.
- Shopify currently implements the static Theme-section profile. Countdown, rotation, controlled dismissal, Header-group placement, and merchant schema remain explicit target maturity work.
- React and Angular should project the same controlled state and request events over the neutral DOM contract.
- Figma represents static, countdown, rotating, paused, dismissible, and wrapped visual states without simulating persistence or a clock.
- SwiftUI and Compose use native controls and scheduling while preserving the same exclusive modes and ownership boundary.

This implementation is prepared for human stability review but remains `pilot`. Review compact density, wrapping, control hierarchy, localized copy, RTL, zoom, forced colors, reduced motion, every exclusive mode, controlled dismissal, and the no-progress-bar treatment before any `stable` promotion.
