## Overview

Collection Hero is a passive collection introduction with one contextual title,
an optional concise description, an optional target-formatted count, and
optional image media. Supplying the image derives the image-backed contrast
composition; there is no separate variant control that can contradict it.

## Presentation

Without image media, the component uses the archival surface and primary text.
With image media, the target adds `.collection-hero--with-image`; canonical CSS
places the image behind a semantic contrast layer and pairs it with inverse text
in both light and dark themes. The content stack and information hierarchy do
not change between compositions.

Root padding responds to available inline size through token-bounded intrinsic
values.
Image-backed mode keeps a private minimum depth, while text-only mode grows from
its content. Title, description, and count wrap safely inside a private readable
maximum; these geometry details are not consumer properties.

## Usage Guidelines

<DoDont>
  <Do>Use one visible native title heading at the correct rank for the surrounding page.</Do>
  <Dont>Expose heading rank as a visual style switch or add a widget role.</Dont>
  <Do>Let image presence derive the image-backed class and contrast layer.</Do>
  <Dont>Offer independent image and variant controls that can produce contradictory markup.</Dont>
  <Do>Supply useful contextual alt text when the media conveys information, or an empty alt when it is decorative.</Do>
  <Dont>Copy the collection title into alt text merely to avoid an empty value.</Dont>
</DoDont>

Keep the description concise and plain text. Long-form or richly structured
collection narrative belongs in a separate content region. Count formatting,
pluralization, filtering meaning, and commerce data belong to the target. Omit
optional nodes instead of rendering empty spacing.

## Accessibility

- Render exactly one visible native heading for the collection title. A
  collection template commonly uses `h1`; this nested docs preview uses `h2`
  because the component page already owns its `h1`.
- Use a real image. Preserve meaningful alt text for informative media and
  `alt=""` for decorative atmosphere.
- Verify image-backed contrast against every supplied image frame in light and
  dark themes. Forced-colors presentation must not depend on image pixels.
- Keep the optional count as ordinary readable text, not an implicit live
  region. Filters or result summaries own synchronized announcements.
- Collection Hero has no focus, keyboard, controlled/uncontrolled, event, or
  reduced-motion contract because it owns no interaction or animation.

## Technical Specification

- root: `.collection-hero`
- image-backed root: `.collection-hero.collection-hero--with-image`, derived
  only when image media exists
- media: real `.collection-hero__image`
- content stack: `.collection-hero__content`
- required contextual heading: `.collection-hero__title`
- optional plain copy: `.collection-hero__description`
- optional formatted count: `.collection-hero__count`
- contrast layer: generated `.collection-hero--with-image::before`

The component adds no JavaScript, events, observers, timers, requests, or
layout loops. Target adapters choose heading rank, image resource/loading policy,
localized count text, and collection data source.

## Content And Responsive Coverage

Validate text-only and image-backed compositions with short, long, localized,
empty optional, and unbroken extreme content. Test informative and decorative
images, absent media, very light and dark frames, 200% zoom, all accepted themes,
forced colors, and mobile, tablet, desktop, and XL containers.
