## Overview

Interactive native radio group for choosing one integer rating from one through five. Star Input owns value entry; read-only contexts use Star Rating instead.

## Presentation

The root is a native fieldset with a visible legend. Five labels contain native radios that share one `name`; each label is a touch-sized focus projection for its radio, and the optional indicator remains decorative. Checked, hover, focus-visible, and disabled presentation derive from the native radio state.

The selected `value` is an integer from `1` through `5`. `required` and `disabled` map to native radio attributes, while `describedBy` associates the fieldset with supporting or validation feedback. Pointer preview never replaces the checked value.

## Usage Guidelines

<DoDont>
  <Do>Use one Star Input for one clearly labelled rating question inside a native form.</Do>
  <Dont>Do not replace the radios with click-only stars or reuse Star Input for passive display.</Dont>
</DoDont>

The containing form decides whether a rating is required and owns any supporting or validation message. Provider submission, persistence, and normalization remain outside Star Input.

## Accessibility

<Callout type="info">
  Native radios retain arrow-key movement, validation, reset, focus, and form-submission behavior.
</Callout>

- Use a visible legend or an equivalent programmatic group label.
- Give every radio a readable choice name such as `1 star` or `5 stars`.
- Keep all radios in the group on the same native `name`.
- Project `:focus-visible` from the radio onto its label without removing the radio from the focus order.
- Associate supporting or validation feedback through `aria-describedby` on the group.
- Use native `required` and `disabled` states rather than visual-only substitutes.
