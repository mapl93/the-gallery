## Overview

Filter Panel is the full multi-group filter surface for an associated result
region. One native GET form and one canonical control tree appear as an adjacent
panel when the owning container is wide enough and inside canonical Drawer when
constrained. It is not navigation and does not own the result query or data.

## Presentation

The panel has one density and two container-driven surfaces, not two component
trees. In a coherent wide host, the canonical Drawer root becomes a non-modal
in-flow panel beside the result slot. In a constrained host, a canonical Button
opens the same form inside modal Drawer with a visible title and Close Button.
Without enhancement, the native GET form remains inline and usable.

Groups remain visible in v1 and use native `fieldset`/`legend`. Filter Panel
does not add disclosure state. Result count, sort, view mode and other collection
toolbar content belong to the owning toolbar rather than this component.

`immediate` is the default: every canonical choice change is a committed query
change request. `manual` keeps one target-owned draft; Apply requests commitment
and Cancel restores the last committed values without changing the URL.

The adjacent panel width, borders, active-tag gap, root and group padding,
legend spacing/weight, option gap, price-field gap and manual-action gap are public tokens. Spacing
factors multiply the shared Element gap; the 15rem initial panel width remains
an independent component decision. Drawer retains its own width, surface,
header/body/footer and motion API; each form control and Tag also keeps its API.

The existing adaptive threshold remains structural in this checkpoint. Changing
panel width does not request a different surface or change the commit policy.
Consumers adopting this copy-and-own update regenerate/copy tokens and CSS
explicitly. No remote consumer is updated automatically.

## Usage Guidelines

<DoDont>
  <Do>Use Filter Panel for multiple labelled facet groups adjacent to one result surface.</Do>
  <Dont>Do not duplicate desktop and mobile forms or use Filter Panel as category navigation.</Dont>
</DoDont>

- Supply a real GET `formAction`, stable target-defined input names/values and
  truthful available/disabled states.
- Keep committed active values in one named native list of canonical Tags.
- Use canonical Checkbox for independent values and Radio for mutually exclusive
  values. Swatches must retain visible text and a non-color selected state.
- Keep groups always visible. A future collapsible group must compose a reviewed
  Disclosure or Accordion rather than turning the legend into an inert Button.
- Keep results outside the form so Product Card and other consumer forms remain
  valid.
- The target owns query-parameter names/serialization, URL/history, Back/Forward,
  cancellation, pending/error/empty status, result replacement, analytics,
  focus and pagination reset.
- Cap or search very large target facets through a separately reviewed data and
  control policy; do not silently virtualize or truncate authored choices.

## Accessibility

- Give the panel a non-empty visible title and use it to name the native GET form
  and constrained Drawer.
- In constrained mode preserve canonical Drawer focus containment, Escape and
  close behavior, backdrop policy, background exclusion, scroll lock and trigger
  restoration. In wide mode remove modal semantics and constrained-only actions.
- Keep exactly one form/control tree and one checked-state owner across surfaces.
- Group every related set with a first native Legend and preserve canonical
  Checkbox/Radio keyboard, disabled, checked, reset and FormData behavior.
- A Tag removal requests one committed-value removal; the target chooses
  surviving focus and any localized result announcement.
- Manual Cancel restores committed values without URL mutation. Apply and
  Immediate commitment update at most one target-owned result status.
- Preserve long/localized labels, RTL, unbroken text, text spacing, 200% zoom,
  forced-color focus and reduced motion through canonical dependencies.
