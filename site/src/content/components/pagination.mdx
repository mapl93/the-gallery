## Overview

Page navigation for bounded collection results.

## Presentation

The current page uses the neutral primary-action family. Adjacent pages remain quiet until hover or focus, and ellipsis content is informational rather than interactive.

## Usage Guidelines

<DoDont>
  <Do>Keep the current page and nearby destinations visible.</Do>
  <Dont>Do not render an ellipsis as a disabled link.</Dont>
</DoDont>

- Disable previous or next navigation only at a real boundary.
- Preserve collection filters and view mode when changing pages.
- Use target-native URLs so navigation still works without JavaScript.

## Accessibility

- Use a `<nav>` with a specific accessible label.
- Mark the current page with `aria-current="page"`.
- Give icon-only previous and next links accessible names.
- Use `aria-disabled="true"` only when an unavailable link remains in the DOM.
