# ADR 0385: Marketing Signal Visual Values

Status: Accepted

Date: 2026-09-12

Apply ADR 0293 to Trust Badges (9 new roles / 19 public values), Payment Icons
(3 / 4), Countdown (9 / 23) and Urgency (4 / 13), refining ADRs 0167–0169,
0225 and 0252's former private visual-value boundaries.

Expose wrapping-list gaps and padding, independent compact gaps, decorative
icon size, relative leading floors, payment mark heights, countdown segment/
separator/label gaps and card measures/padding, urgency cue/dot sizes and warning
mix share. Shared responsive spacing bases stay live. Component-relative rem/ch
measures preserve current meaning without adding primitive scale entries.

Payment marks retain native artwork, names, colors, aspect ratio and passivity.
Countdown keeps its absolute deadline, canonical selected units, shared scheduler,
one-shot expiration and target-owned expiry reactions; hidden announcement
geometry remains private accessibility infrastructure. Inline typography retains
its documented host inheritance. Urgency keeps all four target-qualified claim
types and introduces no stock, purchase or viewer calculation.

Both generated targets and the shared Studio/Exhibit inventory follow source.
No new semantic property, mode, platform, runtime, hosted data integration or
maturity promotion. See the marketing-signals checkpoint report.
