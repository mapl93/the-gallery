## Usage Guidelines

<DoDont>
  <Do>Show real-time updates (totals, quantities) when the user modifies the cart.</Do>
  <Dont>Don't require a page reload for cart changes — use AJAX for a smooth experience.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Cart components are designed for Shopify's AJAX Cart API. Wire up the JS interactions in your theme.
</Callout>

- Ensure proper color contrast ratios (4.5:1 for text, 3:1 for large text) when customizing tokens.
