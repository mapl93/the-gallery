## Overview

A named dialog composition for focused decisions and short tasks. Canonical CSS owns its bounded surface and scroll partition; each target owns true modality, focus, inertness, dismissal, and lifecycle.

## Presentation

Modal has one centered presentation. The overlay owns backdrop visibility while the dialog owns surface, scrolling, section anatomy, and entrance motion.

The component is composed of an overlay, a dialog container, and structural sections:

| Element            | Class             | Purpose                        |
|--------------------|-------------------|--------------------------------|
| Overlay            | `.modal-overlay`  | Darkened backdrop, click to dismiss |
| Container          | `.modal`          | The dialog box itself          |
| Header             | `.modal__header`  | Title row                      |
| Close              | `.modal__close`   | Required canonical Close Button |
| Body               | `.modal__body`    | Main content area              |
| Footer             | `.modal__footer`  | Action buttons (confirm/cancel)|

## Usage Guidelines

<DoDont>
  <Do>Use modals for focused tasks that require a decision — confirmations, short forms, important alerts.</Do>
  <Dont>Don't use modals for long content or multi-step flows. Use a dedicated page or drawer instead.</Dont>
</DoDont>

<DoDont>
  <Do>Always include a visible close mechanism — a cancel button, X icon, or backdrop click.</Do>
  <Dont>Don't trap users in a modal with no way out. Every modal must be dismissible.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Modal CSS alone is not modality. A target must make outside content inert, contain focus, close on Escape, and restore focus before it can assert `aria-modal="true"`.
</Callout>

- Set `aria-hidden="false"` on the overlay when open, `"true"` when closed.
- Use `role="dialog"` and `aria-modal="true"` on the `.modal` element.
- Add `aria-labelledby` pointing to the modal title's `id`.
- Add `aria-describedby` only for a short, simple description; omit it for rich or lengthy content.
- Return focus to the trigger element when the modal closes.
- Close on `Escape` key press.

```html
<div class="modal-overlay" aria-hidden="false">
  <div class="modal" role="dialog" aria-modal="true" aria-labelledby="modal-title">
    <div class="modal__header">
      <h2 class="modal__title" id="modal-title">Title</h2>
      <button class="close-btn modal__close" type="button" aria-label="Close modal">…</button>
    </div>
    <div class="modal__body">…</div>
    <div class="modal__footer">
      <button class="btn btn--outline">Cancel</button>
      <button class="btn">Confirm</button>
    </div>
  </div>
</div>
```
