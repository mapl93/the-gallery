## Usage Guidelines

<DoDont>
  <Do>Use tooltip for short supplemental text attached to a focusable trigger.</Do>
  <Dont>Don't put interactive content or required instructions inside a tooltip.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  The current web adapter renders the visual bubble from `aria-label`.
</Callout>

- Make the trigger keyboard focusable so the tooltip can appear on focus as well as hover.
- Keep tooltip text short and non-interactive.
- Use Popover when the floating content needs links, buttons, or richer structure.
