## Overview

Decorative CSS loading indicator with four sizes and optional visible status text.

<Preview html={'<div class="spinner-overlay" role="status"><span class="spinner" aria-hidden="true"></span><span class="spinner-overlay__text">Loading collection</span></div>'} label="Spinner" />

## Presentation

Sm, Default, Lg, and Xl change only the visual diameter. Supplying status text composes the spinner inside `.spinner-overlay`.

The overlay uses canonical `40px` composition padding in both Exhibit and Studio, wraps extreme status text, and keeps the ring head distinct from its track in forced colors even after reduced motion stops rotation.

## Usage Guidelines

<DoDont><Do>Mark the loading region busy and include concise status text when users need an announcement.</Do><Dont>Do not make the rotating graphic itself duplicate a visible status announcement.</Dont></DoDont>

## Accessibility

- Treat `.spinner` as decorative with `aria-hidden="true"`.
- Put `aria-busy` on the region being updated or use one `role="status"` wrapper with visible text.
- Remove the status when loading completes.
- Neutral web stops rotation when reduced motion is requested.

## Visual Customization

Studio and Exhibit expose fifteen public roles. Four diameter tokens preserve 16/24/40/56px presets, with independently editable ring width (2px), cycle duration (750ms), easing, overlay padding and status gap. The track remains a documented 20% tint of the spinner color; the leading arc uses that color directly.

Overlay spacing applies only when status text is present. Animation runs while the consumer renders its loading indicator, and reduced motion makes it static; this does not inherit Skeleton's bounded decorative shimmer policy. Keep the loading lifecycle and accessible status authoritative in the consumer.
