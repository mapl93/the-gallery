## Overview

Universal composition for a visible label, form control, helper text, and validation feedback.

## Presentation

Field Wrapper presents `default`, `error`, `success`, and `warning` feedback families without changing the semantics of its composed control.

## Usage Guidelines

<DoDont>
  <Do>Use one Field Wrapper for each visible label, control, and related messages.</Do>
  <Dont>Don't use the generated required marker without synchronizing native required state.</Dont>
</DoDont>

## Accessibility

- Associate labels with controls using matching `for` and `id` values.
- Reference helper and feedback messages with `aria-describedby`.
- Use `aria-invalid="true"` only for error feedback.
- Keep message order predictable after the control.
