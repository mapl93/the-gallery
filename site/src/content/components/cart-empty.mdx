## Overview

Cart Empty is the cart-specific resolved-absence profile of canonical Empty State. It replaces the prior cart composition when the target authoritatively reports no line items and may provide one recovery destination back to shopping.

## Presentation

The `.cart-empty` class is a domain hook layered on `.empty-state`; it adds no independent visual API. Canonical Empty State owns the icon, title, message, container response, wrapping, colors, typography, spacing, and one action slot. The recovery destination is a native Link with canonical Button presentation.

`title` is required and non-empty. `icon` and `message` are independently optional. `actionLabel` and `href` form one coherent optional pair: if either value is blank, no action renders and K7 does not invent a fallback destination.

K7 exposes no public presentation tokens, variant, size, heading level, cart count, event, focus target, or announcement property. Customize the composed Empty State and Button rather than adding Cart Empty-specific visual controls.

## Usage Guidelines

<DoDont>
  <Do>Replace lines, totals, discount, and checkout controls with Cart Empty after authoritative cart state reaches zero items.</Do>
  <Dont>Do not leave stale cart actions visible or render a label-only Link with an invented destination.</Dont>
</DoDont>

- Keep the message concise, truthful, localized, and specific to the empty cart.
- Provide one direct navigation path when a useful shopping destination exists.
- Treat the icon as supporting presentation, not the only explanation.
- Keep recommendations, personalization, cart mutation, loading, errors, and analytics outside K7.

## Accessibility

- Use the contextual native heading selected by the host under ADR 0236. The docs target uses H2 and Shopify main cart uses H1; heading rank is not a K7 property or visual control.
- Keep the optional icon decorative and hidden because the visible title is text-complete.
- Use a real native Link with non-empty `href`; preserve Tab, Enter, modified activation, history, and canonical Button focus treatment.
- Do not add a role, landmark, focus, `tabindex`, live region, or custom keyboard model to the static root.
- When removal of the final item creates this state dynamically, the parent cart coordinator owns any qualifying pre-existing localized Status output and deliberate focus recovery. Do not duplicate the visible title as an automatic announcement.
- Remove stale line, total, discount, and checkout focus stops in the same state transition.

## Target Mapping

- Neutral Web: `div.empty-state.cart-empty`, canonical Empty State parts, and one optional `a.btn[href]`.
- Shopify: authoritative cart state selects the branch; locale strings supply copy; `routes.all_products_collection_url` supplies the recovery destination; the existing Empty State snippet receives the `.cart-empty` profile hook.
- React and future framework targets: one parent-controlled cart store selects the profile and owns replacement, status, focus, navigation, and analytics.
- Figma: instance/profile of canonical Empty State. The recorded generic node IDs are traceability metadata, not component-specific visual approval.
