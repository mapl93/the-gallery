## Overview

Responsive structural toolbar for target-owned review-list controls, with optional Select and Button or link composition.

## Presentation

The required root provides responsive layout only. The optional sort wrapper contains a target-owned native control or composed Select. The optional write action composes Button or a native link. On narrow viewports, the layout stacks and stretches its child controls.

Select retains its label, options, enhancement, validation, focus, and disabled semantics. Button retains its action, link, focus, disabled, and busy semantics. The preview options are documentation fixtures rather than component defaults.

## Usage Guidelines

<DoDont>
  <Do>Use Review Toolbar to arrange controls whose meaning and behavior have already been chosen by the target.</Do>
  <Dont>Do not define sort options, filtering, write-review entry behavior, URL state, or result updates in this layout component.</Dont>
</DoDont>

Ordering and filtering models, navigation versus in-place updates, write-review destination, focus retention, empty results, and announcements remain open target decisions.

## Accessibility

<Callout type="info">
  Label the toolbar when surrounding context does not already identify its controls.
</Callout>

- Preserve the composed Select's visible label, native fallback, keyboard behavior, validation, and disabled state.
- Use Button for an action and an anchor when the write-review affordance navigates.
- Preserve visible focus and accessible names for every control.
- When a target updates results in place, preserve focus and announce meaningful changes outside this layout contract.
