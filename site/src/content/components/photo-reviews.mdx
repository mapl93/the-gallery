## Overview

Responsive gallery of ordered, target-owned review images. Items are passive by default and do not imply a Lightbox or Modal.

## Presentation

The required root contains repeated square `.photo-reviews__item` elements and `.photo-reviews__image` media. A direct child image remains supported as a compatibility fallback. Generated overlay, hover transform, and focus presentation apply only when the target renders an item as a native link or button.

The optional root label identifies the gallery when surrounding content does not. Item order, image data, alt text, and any native action are target-owned.

## Usage Guidelines

<DoDont>
  <Do>Keep review photos passive unless the target has selected a concrete native destination or activation pattern.</Do>
  <Dont>Do not make a div click-only or assume that every photo opens enlarged media.</Dont>
</DoDont>

Direct links, downloads, Lightbox triggers, Modal triggers, captions, image loading, focus management, navigation, and dismissal remain open target decisions. The local preview media is a documentation fixture rather than a remote asset.

## Accessibility

<Callout type="info">
  Every informative review image needs an alternative that conveys the relevant visible content.
</Callout>

- Give informative images meaningful `alt` text.
- Use empty alt text only for genuinely decorative duplicate images.
- Use native links or buttons when the target makes an item actionable.
- Preserve an accessible name and visible focus for each target-supplied action.
- Do not communicate review information only through hover or a generated overlay.
- Delegate modal or lightbox focus management and dismissal to the separately selected overlay component.
