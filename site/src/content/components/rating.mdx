## Overview

Read-only rating display with full- and half-star anatomy plus optional review-count text.

## Presentation

Rating has one classless presentation and one size. Filled, half-filled, and empty stars are structural states inside the star group; they are not interactive choices.

The target adapter composes the star sequence from its rating data. The neutral web CSS styles that supplied anatomy but does not parse a numeric value or generate the sequence.

## Usage Guidelines

<DoDont>
  <Do>Use Rating to display a value already resolved by the target adapter.</Do>
  <Dont>Do not use this passive component to collect a rating; use Star Input instead.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Rating Stars is display-only. Use Star Input for interactive review input.
</Callout>

- Provide a text alternative for the rating value (e.g., "4 out of 5 stars").
- Hide decorative star glyphs from assistive technology when a rating label is provided.
- Do not rely on color alone to communicate rating value.
