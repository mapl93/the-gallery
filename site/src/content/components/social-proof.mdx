## Overview

Social Proof is a passive commercial-activity profile of canonical Toast. It presents one target-verified, privacy-approved message with optional relevant media, optional time text, and optional canonical dismissal.

## Usage Guidelines

<DoDont>
  <Do>Render only current commercial activity whose source, wording, freshness, privacy, and publication are approved by the target.</Do>
  <Dont>Do not manufacture purchases, expose identifiable customer combinations, or infer notification timing, queueing, persistence, or recurrence from this preview.</Dont>
</DoDont>

The artwork copy is a documentation fixture, not a component default or evidence of a real purchase.

## Accessibility

- Keep the complete meaning in trimmed visible text; blank message content omits the complete item.
- Do not add `status`, `alert`, or live-region semantics to static/default marketing content and never move focus when it appears.
- Treat optional media as decorative when the message already supplies its meaning; use informative alt only when it adds relevant information.
- Compose dismissal through canonical Toast and Close Button with a non-empty localized label.
- Target Toast services own pause, stop, hide, frequency, duration, focus/window pause, Escape, queueing, and removal.
- Respect canonical Toast reduced-motion, forced-color, hidden-state, and focus behavior.
