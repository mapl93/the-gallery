## Overview

Bottom Navigation is a fixed mobile navigation region with target-owned destinations, visible labels, optional icons, current-page state, and optional badges.

## Presentation

The root is fixed by canonical CSS on narrow viewports; the documentation helper contains it as the artwork. Each `.bottom-nav__item` remains a native link with required `.bottom-nav__label`, optional `.bottom-nav__icon`, optional `.bottom-nav__badge`, and target-owned current-page state.

Destinations, item count, order, icon source, badge values, and body-offset policy are target responsibilities rather than component defaults.

## Usage Guidelines

<DoDont>
  <Do>Reserve the limited mobile space for persistent, high-priority destinations with visible labels.</Do>
  <Dont>Do not use badges or active color as the only way to identify a destination or state.</Dont>
</DoDont>

- Keep the destination set stable enough to build user recognition.
- Use badges only for concise target state that can remain synchronized.
- Coordinate page-bottom spacing in the consuming layout so content is not obscured.

## Accessibility

- Provide the required accessible navigation `label`.
- Keep a visible text label for every item, even when an icon is present.
- Use `aria-current="page"` for the active destination.
- Hide decorative icons from assistive technology.
- Announce dynamic badge changes according to target policy and preserve safe-area spacing and touch target size.
