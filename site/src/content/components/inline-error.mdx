## Overview

Inline field-level error message with icon.

<Preview html={"<span class=\"inline-error\">This field is required</span>"} label="Inline Error" />

## Usage Guidelines

<DoDont>
  <Do>Always pair form inputs with visible labels for accessibility.</Do>
  <Dont>Don't rely on placeholder text as the only label — it disappears on input.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Use the `field-wrapper` component to ensure consistent spacing and label alignment across all form fields.
</Callout>

- Ensure proper color contrast ratios (4.5:1 for text, 3:1 for large text) when customizing tokens.
