## Overview

Password field with a visibility toggle and text-backed strength meter.

## Presentation

Password Input supports `default`, `error`, `success`, and `warning` validation families independently of visibility and strength.

## Usage Guidelines

<DoDont>
  <Do>Use the visibility toggle to support entry verification without changing the value.</Do>
  <Dont>Don't use strength color bars without an equivalent text description.</Dont>
</DoDont>

## Accessibility

- Use a native password input with a visible label.
- Keep toggle name, pressed state, and input type synchronized.
- Use `type="button"` so the visibility control never submits a form.
- Respect `current-password` and `new-password` autocomplete purposes.
