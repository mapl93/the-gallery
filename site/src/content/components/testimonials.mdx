## Usage Guidelines

<DoDont>
  <Do>A/B test marketing components (hero copy, CTA placement, popup timing) to optimize conversion.</Do>
  <Dont>Don't show too many marketing elements at once — popups + banners + badges = fatigue.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Marketing components often need JavaScript for interactions (countdown timers, popup triggers, etc.).
</Callout>

- Ensure proper color contrast ratios (4.5:1 for text, 3:1 for large text) when customizing tokens.
