## Overview

Logo Bar presents an ordered set of target-owned logos or trust marks with an optional visible label. Marks may be passive or target-supplied native links.

`static` is the default wrapping presentation. `marquee` maps to `.logo-bar--marquee`; duplication, speed, direction, pause controls, and runtime motion are not semantic properties.

## Usage Guidelines

<DoDont>
  <Do>Use consistent mark dimensions and supply native links only when each logo has a meaningful destination.</Do>
  <Dont>Do not use continuously moving logos for essential information or duplicate semantic content for animation.</Dont>
</DoDont>

Keep trust claims accurate and let each target own any destination and repeated visual copies.

## Accessibility

- Give informative marks accessible names; use empty alternatives for purely decorative marks.
- If a logo links elsewhere, use a native link with a useful accessible name and visible focus.
- Hide animation-only duplicates from assistive technology.
- Respect reduced-motion preferences and preserve a static wrapping fallback.
