## Presentation

The base table can independently compose striped rows, row hover, and sortable-header anatomy. These controls are intentionally not exclusive: a sortable table may also be striped and preserve hover feedback. The optional native caption names the dataset. The responsive wrapper does not change table semantics; it preserves readable column widths and owns keyboard scrolling and focus when present.

Rows, columns, values, and the sample inventory in Exhibit and Studio are fixtures, not component defaults. Sortable presentation supplies the canonical control anatomy; each target owns comparison, locale rules, ordering, pagination, and remote data updates.

## Usage Guidelines

<DoDont>
  <Do>Use Table when values need to be compared across consistent columns.</Do>
  <Dont>Don't use table markup only to align unrelated page content.</Dont>
</DoDont>

Keep column labels concise and preserve the same data meaning down each column. Use the overflow wrapper when the table may be wider than its container instead of compressing cell content until it becomes unreadable. The wrapper uses inline overflow rather than changing the table into cards; target-specific adaptive tables remain a separate composition.

## Accessibility

<Callout type="info">
  Native table structure provides relationships that a collection of generic grid containers does not.
</Callout>

- Use `<thead>`, `<tbody>`, `<th>`, and `<td>` according to the data structure.
- Add `scope="col"` or `scope="row"` for simple headers and explicit header associations for complex tables.
- Provide a native caption or equivalent contextual label. A caption may be visually hidden when the same visible heading already identifies the dataset.
- Keep one `aria-sort` value on the owning sortable header and synchronize `none`, `ascending`, or `descending` with visible row order.
- Keep sort triggers as native buttons; do not rely on pointer hover or icon direction alone.
- Give an overflow wrapper a contextual accessible name, `tabindex="0"`, and a visible focus indicator so keyboard users can reach and scroll it.
