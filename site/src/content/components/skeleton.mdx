## Usage Guidelines

<DoDont>
  <Do>Match each skeleton shape to the geometry of the content that will replace it.</Do>
  <Dont>Do not use Skeleton for a resolved empty state or leave it visible after loading finishes.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Skeleton shapes are usually decorative. Put loading announcement semantics on the containing region when needed.
</Callout>

- Use `aria-busy` or `role="status"` on the loading region when users need loading feedback.
- Keep the individual skeleton shapes hidden from assistive technology.
- Replace skeletons with real content as soon as target data is available.
- Neutral web removes the shimmer animation when reduced motion is requested.
