## Overview

Decorative loading geometry that reserves the shape of expected content without owning its data or lifecycle.

## Presentation

Default is an unopinionated block whose dimensions come from its composition. Text, Title, Image, Button, and Circle are low-fidelity geometry presets; they do not change semantics or loading ownership.

## Usage Guidelines

<DoDont>
  <Do>Match each skeleton shape to the geometry of the content that will replace it.</Do>
  <Dont>Do not use Skeleton for unknown progress, a resolved empty/error state, or content whose final geometry cannot be predicted.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Skeleton shapes are always decorative. Put busy lifecycle on the real content region and use one actual localized Status message only when loading needs an announcement.
</Callout>

- Set `aria-busy="true"` on the consumer's content region while it is incomplete, then set it to `false` or remove it after replacement.
- Keep every Skeleton shape `aria-hidden="true"`; do not give it Status, Progressbar, label, focus, or interaction semantics.
- If explicit feedback is useful, provide one actual localized `role="status"` message outside the decorative shapes.
- Replace Skeletons promptly and keep placeholder/final geometry aligned to avoid layout shift.
- Neutral Web stops shimmer after at most 4.5 seconds and renders static solid geometry for reduced motion and forced colors.

## Visual Customization

Studio and Exhibit expose Text/Title height and width, Button width and shared height, surface colors, radii, cycle duration, and easing. Text heights keep `em` units and line widths keep percentages; they adapt to the consumer font and container. Default dimensions and Circle diameter remain composition-owned.

The requested cycle duration is bounded to 0–1500ms in Web CSS, with three cycles and a 4.5-second maximum established by ADR 0111. Editing the Studio preview starts one new bounded run; it creates no component timer or automatic loop. Reduced-motion and forced-color preferences always remove the animation. This is Skeleton’s existing behavior choice, not a system-wide motion limit. [WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) describes the conditions requiring a pause, stop, or hide mechanism for automatic motion lasting more than five seconds alongside other content.

The visual root is `.skeleton`. Variant values map to `.skeleton--text`, `.skeleton--title`, `.skeleton--image`, `.skeleton--button`, and `.skeleton--circle`; Default adds no modifier class. Text/Title spacing, Default dimensions, Circle diameter, repeated layout, busy lifecycle, Status text, data, errors, and replacement remain target-owned.

## Target Lifecycle

Skeleton has no controlled/uncontrolled state. A consumer conditionally renders decorative shapes, marks the real content region busy, replaces the shapes atomically, and clears busy state. A localized Status message is target composition, not a Skeleton property.

Use Spinner when future geometry cannot be represented, Progress when measurable completion matters, and Empty State only after absence is resolved.

## Motion And Targets

The base shimmer is finite and uses no JavaScript. Neutral Web consumers keep request/state ownership outside the component; Shopify composes the generated class contract inside target Liquid. Neither generated output owns request completion or loading announcements.
