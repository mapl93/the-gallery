## Overview

Horizontal or vertical rule with independent visual presentation and separator semantics.

<Preview html={"<div class=\"tg-preview-line\"><hr class=\"divider\" aria-hidden=\"true\" /></div>"} label="Divider" />

## Presentation

Default is a subtle rule. `decorative` increases visual emphasis; `section` increases separation along the active axis. `orientation` changes the axis without changing visual emphasis or semantics. These properties do not decide whether the divider is announced.

<Preview html={"<div class=\"tg-preview-stack\"><span>Default</span><hr class=\"divider\" aria-hidden=\"true\" /><span>Decorative</span><hr class=\"divider divider--decorative\" aria-hidden=\"true\" /><span>Section spacing</span><hr class=\"divider divider--section\" aria-hidden=\"true\" /></div>"} label="Divider presentations" />

A vertical divider uses `data-orientation="vertical"` inside a parent that establishes its cross-axis height.

## Usage Guidelines

<DoDont>
  <Do>Use a semantic separator only when the rule communicates structure between regions.</Do>
  <Dont>Don't announce a purely decorative rule to assistive technology.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Use semantic separator markup when the divider conveys structure. Hide purely decorative dividers from assistive technology.
</Callout>

- Use `hr` or `role="separator"` when the divider conveys structure.
- Use `aria-hidden="true"` for purely decorative dividers.
- Do not use divider spacing as the only cue for grouped content.
