## Overview

Rich Text Section provides a constrained reading column for an optional heading and required target-owned semantic document content.

## Presentation

<Preview html={'<section class="rich-text-section" aria-labelledby="rich-text-section-title"><h2 class="rich-text-section__title" id="rich-text-section-title">About the studio</h2><div class="rich-text-section__body"><p>We create functional ceramic work that joins traditional making with a quiet contemporary language.</p><h3>Materials and process</h3><p>Each form is built from stoneware clay, finished by hand, and fired in small batches.</p><blockquote>Useful objects can hold the memory of their making.</blockquote><p><a href="#">Read our material standards</a></p></div></section>'} label="Rich Text Section" />

The body slot retains target-owned paragraphs, headings, lists, quotations, links, and media. The component constrains presentation without flattening document semantics.

## Usage Guidelines

<DoDont>
  <Do>Use semantic document elements and a clear heading hierarchy for long-form reading.</Do>
  <Dont>Do not use manual line breaks or visual styling in place of paragraphs, lists, or headings.</Dont>
</DoDont>

Keep the content width readable and use links with descriptive destination text.

## Accessibility

- Preserve a logical heading order within the surrounding page.
- Use native lists, quotations, links, and media semantics inside the body.
- Give informative images useful alternative text and decorative images empty alternatives.
- Keep link purpose understandable out of context and preserve visible focus.
