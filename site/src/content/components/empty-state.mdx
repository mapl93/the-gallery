## Presentation

Title is required. Icon, message, and action are independent optional slots. Actions compose Button or Link; Empty State does not own a local action style.

The artwork, copy, and action shown in Studio are preview fixtures, not component defaults.

## Usage Guidelines

<DoDont>
  <Do>Explain what is empty and offer one clear next step when an action can resolve it.</Do>
  <Dont>Don't show an empty state while content is still loading.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Empty State is for resolved empty content, not loading. Use Skeleton or Spinner while data is still pending.
</Callout>

- Use clear title text that identifies the empty state.
- Make optional actions keyboard accessible and descriptive.
- Treat decorative icons as decorative when the title already communicates the state.
