# Refinement Batch 75 — Instagram Feed

Status: Human-review-ready; no stability promotion

Date: 2026-07-16

Component: Instagram Feed (`S16`, dependency order `176`)

## Outcome

Batch 75 converts Instagram Feed from a fixed responsive image grid with generic
focusable items, hidden artificial metrics and an invented account destination
into a passive finite media collection. A visible heading names a native
section, heading omission produces a generic root, missing records omit the
component, native list/figure/caption semantics preserve supplied content, and
only real native destinations enter the tab order. S16 adds zero runtime.

Exhibit and Studio use exact shared markup. Shopify gains a localized
target-native section with validated merchant media blocks and strict omission.

## Delivered

- Permanent S16 dossier, detailed refinement audit and ADR 0158.
- Contract `0.3.0`, registry/token audit, focused Studio metadata and shared
  conditional renderer.
- Canonical intrinsic Sections CSS with semantic H3, Body Small and Caption
  profiles, visible captions, native link cues, focus and content containment.
- Reconciled MDX fallback and primary-source APG/HTML/WAI/Open UI/Radix/Polaris
  research.
- Localized Shopify section with optional heading, paired account/action links,
  validated image blocks, optional captions/destinations, preset and zero JS.
- Paired before/after evidence at Mobile, Tablet, Desktop and XL plus direct
  widths, omissions, incomplete pairs, optional action, RTL/extreme content,
  effective 200% type, themes, contrast, forced colors, reduced motion, keyboard
  focus and mixed captions.
- Regenerated neutral Web, Webflow and Shopify assets/manifests.
