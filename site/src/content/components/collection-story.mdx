## Overview

Collection Story is a named, container-responsive editorial section that pairs optional media with a required title and narrative, plus an optional label, genuine quotation, and target-owned actions.

## Presentation

The default layout stacks into one column and becomes two columns only when media is present and the component content box is at least `42rem` wide. `title` and `body` are required; `media`, `label`, `inspiration`, and `actions` are optional target-owned content. Omitting media leaves one centered narrative column at every size.

`reversed` defaults to `false`. When enabled, `.collection-story--reversed` places media after narrative content in the intrinsic two-column composition without changing source order. Reversal is a layout property, not a state or registry variant. The component has no local state or JavaScript runtime.

## Usage Guidelines

<DoDont>
  <Do>Keep the media-then-narrative source order and omit optional parts instead of leaving empty wrappers.</Do>
  <Dont>Do not make the whole section interactive or treat reversal as a content or interaction state.</Dont>
</DoDont>

- Use one focused collection narrative rather than a list of product facts.
- Use `blockquote` only when the inspiration is genuinely quoted from another source; keep any attribution outside it.
- Compose actions whose destinations are owned by the target, using canonical Button or native control semantics without adding an extra navigation landmark.
- Let targets own image alternative text, decorative intent, focal point, crop, loading, rich-text safety, localization, and routing.

## Accessibility

- Associate the section with the visible collection heading through a target-unique `aria-labelledby`/`id` pair.
- Use a heading level appropriate to the surrounding page for the collection title; the visual class does not require `h2`.
- Give informative media concise useful alternative text, use `alt=""` for decorative or redundant media, and omit the media region when absent.
- Use quotation markup only for a real quotation and keep attribution outside the quoted content.
- Preserve source reading order when `reversed` changes only wide-viewport placement.
- Keep composed links/buttons native and keyboard accessible with canonical visible focus.
- Allow localized, unbroken and zoomed content to reflow without page-level horizontal overflow.

## References

**Dependencies:** None.

**Anatomy:** named `.collection-story` section root; required `.collection-story__layout`, `.collection-story__content`, contextual `.collection-story__title` heading, and `.collection-story__text`; optional `.collection-story__media` and target media, `.collection-story__label`, native `.collection-story__inspiration` quotation, and ordinary `.collection-story__actions` group. `.collection-story__layout--with-media` explicitly enables the intrinsic split and is omitted when media is absent.
