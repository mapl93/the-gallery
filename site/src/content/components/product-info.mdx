## Presentation

Product Info is a stacked editorial composition. Price remains delegated to Price, and metadata remains a semantic description list.

## Usage Guidelines

<DoDont>
  <Do>Optimize product images for web — use WebP format and responsive srcset.</Do>
  <Dont>Don't overload product components with too many badges or CTAs — keep it clean.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Product components are designed to work together. The product page combines gallery, info, form, and related products.
</Callout>

- Ensure proper color contrast ratios (4.5:1 for text, 3:1 for large text) when customizing tokens.
- Use one appropriate heading level for the product title in the page context.
- Render metadata as a description list when pairing labels and values.
