## Overview

Multicolumn presents an ordered set of target-owned feature items with optional icons, item headings, and supporting text beneath an optional section heading.

The parent owns the responsive column arrangement. The `items` slot owns ordered content; it does not establish a structured item API or interactive behavior.

## Usage Guidelines

<DoDont>
  <Do>Use parallel item structure and similarly weighted copy so the set remains easy to compare.</Do>
  <Dont>Do not use decorative icons as the only way to identify or distinguish an item.</Dont>
</DoDont>

Keep the number of columns appropriate to the available width and let the canonical layout wrap responsively.

## Accessibility

- Use a list when the features form a meaningful set.
- Keep item headings in a logical hierarchy beneath the optional section heading.
- Hide decorative icons from assistive technology; provide an accessible name when an icon conveys unique information.
- Do not rely on position alone to explain a sequence.
