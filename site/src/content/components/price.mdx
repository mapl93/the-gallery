## Overview

Passive commerce price display with current, compare-at, and unit-price content.

## Presentation

Price has one size. Default is the classless presentation; `on-sale` adds `.price--on-sale` to the root and may compose the optional compare-at value. The current price remains `--color-text-primary` in both variants; discount is not an error state.

| Property | Value | Web mapping |
| --- | --- | --- |
| `variant` | `default` | `.price` |
| `variant` | `on-sale` | `.price.price--on-sale` |
| `currentPrice` | formatted string | `.price__current` content |
| `compareAtPrice` | formatted string | `.price__compare` content |
| `unitPrice` | formatted string | `.price__unit` content |
| `accessibleLabel` | localized string | `aria-label` on `.price` |

Targets format monetary values before passing them to Price. The component does not parse amounts, choose currencies, or apply locale rules.

### OpenType Features

Price enables tabular numbers, slashed zero, and contextual alternates by default. Alternate digits and automatic fractions are opt-in. Every feature can be overridden independently through its `data-price-*` attribute; unsupported features are ignored by the active font.

| Property | Default | Web attribute | OpenType |
| --- | --- | --- | --- |
| `alternateDigits` | `false` | `data-price-alternate-digits` | `ss01` |
| `slashedZero` | `true` | `data-price-slashed-zero` | `zero` |
| `tabularNumbers` | `true` | `data-price-tabular-numbers` | `tnum` |
| `contextualAlternates` | `true` | `data-price-contextual-alternates` | `calt` |
| `fractions` | `false` | `data-price-fractions` | `frac` |

## Usage Guidelines

<DoDont>
  <Do>Pass complete, locale-aware monetary strings from the target adapter.</Do>
  <Dont>Do not pass raw numeric amounts and expect Price to format them.</Dont>
</DoDont>

<DoDont>
  <Do>Compose unavailable inventory externally with Badge when a sold-out label is needed.</Do>
  <Dont>Do not treat sold-out as a Price variant or interaction state.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Price owns display anatomy. Locale, currency, sale, and unit-price formatting belong to the target adapter.
</Callout>

- Expose the payable price in text.
- Supply a localized aggregate label or equivalent hidden text when compare-at pricing needs additional explanation.
- Do not rely on strikethrough or sale color alone to communicate the discount.
- Preserve locale and currency formatting for the target market.
