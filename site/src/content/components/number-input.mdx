## Overview

Numeric stepper with increment/decrement buttons.

## Presentation

Number Input supports `default`, `error`, `success`, and `warning` validation families. The field and stepper buttons retain the same family on hover and focus.

## Usage Guidelines

<DoDont>
  <Do>Always pair form inputs with visible labels for accessibility.</Do>
  <Dont>Don't rely on placeholder text as the only label — it disappears on input.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Number Input keeps native `type="number"` semantics while exposing clearer stepper controls.
</Callout>

- Associate the field with a visible label.
- Give increment and decrement buttons clear accessible names.
- Respect `min`, `max`, `step`, `disabled`, and `readonly` constraints.
- Disable increment or decrement buttons when the value reaches its limit.
