# ADR 0406: Review Content, Highlights and Photo Values

Status: Accepted

Date: 2026-09-13

Expose 22 Review roles for avatar/media measures, text/header/action/reply rhythm,
helpful-control padding and borders, focus and verified-color mix. Related header
spacing and rating/title rhythm remain shared decisions; reply and action preceding
gaps are independent. Expose eight Review Highlights roles for tag geometry and
focus, and eight Photo Reviews roles for grid/crop, optional hover and focus.
Defaults, shared colors, typography, radius and motion references remain.

Passive items remain passive. Optional native actions and their provider lifecycle
remain target-owned; the Studio's illustrative status/action icons do not prescribe
an icon asset in the neutral contract. Data, verification and helpfulness are not
token values. Normalize motion inventory category to existing transition where
needed for registry alignment. Public contract inventories drive Studio/Exhibit;
Web/Shopify regenerate and copied consumers adopt explicitly.
