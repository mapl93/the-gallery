## Overview

Pointer- or keyboard-invoked immediate-command menu that consumes the canonical
Dropdown Menu anatomy and behavior.

## Usage Guidelines

<DoDont>
  <Do>Use context menu for secondary commands tied to a specific object or region.</Do>
  <Dont>Don't make critical actions available only through a context menu.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Context Menu reuses the canonical Dropdown Menu group, item, disabled, danger,
  separator, focus, and typeahead behavior. The target owns invocation coordinates,
  viewport clamping, dismissal, and restoration.
</Callout>

- Support pointer `contextmenu` and keyboard invocation with Shift+F10 or the Menu key.
- Move focus to one roving menuitem; support arrows, Home, End, and optional printable typeahead.
- Close on selection, `Escape`, outside interaction, outside scroll, or resize. Scrolling its own command list keeps the menu open. Restore focus when appropriate.
- Clamp the positioned menu inside the owning viewport and retain a visible path to critical actions.

## Visual Customization

45 public roles expose surface and shared item customization. Seven surface tokens independently control minimum/maximum width (11.25rem/20rem), maximum height (20rem), padding (0.25rem), border (1px), upward entrance displacement (4px), and total viewport gutter factor (2). Item tokens reference Dropdown Menu directly. Coordinates, pointer/keyboard invocation, collision and portal placement remain target behavior. The local Studio preview preserves its own 8px inset and re-clamps after token edits; that inset is preview scaffolding, not a universal component limit.

Shared item tokens cover minimum height (2.5rem), gap and block/inline padding factors (0.5 and 0.25/0.75), transparent border width (1px), focus width/inset (2px each), icon size (1rem), shortcut extra-gap factor (0.5), separator width/block-gap (1px/0.25), label top/inline/bottom padding factors (0.375/0.75/0.25) and tracking (0.05em). Factors follow the existing responsive spacing base. Coarse input uses the greater of item minimum and shared touch target, so a larger custom row does not shrink on touch. Icon content and shortcut text remain consumer data.

Label weight reuses semibold; forced-color danger weight reuses bold as an additional cue. Danger text retains the documented 55% error plus 45% primary mix; Studio identifies both inputs. It is a per-item variant independent from hover, highlight and disabled. Context Menu composes that child variant without adding a second scalar property. Native forced colors remain authoritative for system colors.
