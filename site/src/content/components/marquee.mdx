## Overview

Marquee presents one ordered set of short, non-essential content as either a readable static strip or a progressively enhanced continuous motion rhythm. The authored native list always remains the source of truth.

`auto` is the default and maps to `.marquee--auto`; `static` maps to `.marquee--static`. When JavaScript, content, and motion preference allow it, the shared runtime creates one inert visual copy, measures one travel distance, and lets CSS animate the track. Static mode, reduced motion, one item, invalid markup, and failed or missing enhancement preserve the wrapping source list and omit the motion control.

## Usage Guidelines

<DoDont>
  <Do>Use concise supporting ideas that remain complete and understandable when the list is static.</Do>
  <Dont>Do not make price, policy, availability, deadlines, errors, or task instructions available only in moving content.</Dont>
</DoDont>

Use `direction="forward"` to reveal subsequent items from inline-end while the track moves toward inline-start. This resolves physically with the writing direction, so it does not mean “left.” `slow`, `default`, and `fast` map to private distance-normalized velocities; raw durations and clone counts are not public configuration.

## Behavior And State

- Auto enhancement creates at most one `.marquee__group--copy`. It is `aria-hidden`, inert, pointer-inactive, and its descendants cannot add focus stops.
- The canonical Button persistently pauses or resumes motion and always displays the next action.
- Pointer hover pauses temporarily. Focus entering creates a durable pause; only the explicit Resume action clears it.
- A hidden document suspends animation work. Returning to the page preserves the user's durable pause state.
- The runtime emits `marqueeplaybackchange` when effective playback state changes; it does not announce frames or loop boundaries.
- Neutral Web is uncontrolled for the mounted component lifetime. Framework targets may wrap the same state and event with a controlled API without adding a second owner.

## Accessibility

- Author one native `ul` and one or more native `li` items in meaningful order.
- Keep visual copies hidden from accessibility APIs and keyboard navigation.
- Supply localized `pauseLabel` and `resumeLabel`; the control is absent when it cannot control motion.
- Respect reduced motion and preserve source order, visible focus, RTL behavior, forced colors, localization, narrow containers, and 200 percent text zoom.
- A fixed list that moves is not a live region and does not use the ARIA `marquee` role.
