## Overview

Social Proof presents a viewport-contained notification with verified message content, optional time and image, and an optional native dismiss action.

## Usage Guidelines

<DoDont>
  <Do>Render only purchaser, product, location, and time claims verified by current target data.</Do>
  <Dont>Do not manufacture social proof or infer notification timing, queueing, persistence, or recurrence from this preview.</Dont>
</DoDont>

The artwork copy is a documentation fixture, not a component default or evidence of a real purchase.

## Accessibility

- Keep the complete meaning in text and treat the optional image as decorative when it adds no information.
- Use a polite status announcement only when dynamic insertion needs to be conveyed; do not move focus to passive social proof.
- Provide a named, keyboard-operable dismiss button when the notification persists.
- Do not auto-dismiss while the notification or an action within it has focus.
- Respect reduced-motion preferences for entrance and exit transitions.
