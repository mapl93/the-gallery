## Overview

Table of Contents is a passive, always-named same-document navigation landmark
for one long structured document. The target supplies ordered nested heading
records; L5 turns them into native ordered lists and canonical Links without
parsing rich HTML, inventing heading identifiers, or maintaining a second
reading-state service.

The complete component is omitted when its accessible label is blank or its
records are empty, malformed, or contain duplicate identifiers. It is not site
navigation, a menu, a tree, article pagination, related content, or a replacement
for the document's own headings.

The target-owned `items` records require a stable unique `id`, a complete
localized `label`, and optional nested `children`. The renderer preserves that
order and hierarchy as `.toc__list`, `.toc__item`, and canonical
`.link.link--nav.toc__link` anchors. Each `href` points to the encoded fragment
for the supplied id; the target must ensure that exactly one matching heading
exists in the same document.

`placement` accepts `sticky | flow` and defaults to `sticky`. Both modes use
identical content, DOM, semantics, and source order. Neutral Web makes sticky a
bounded preference only in sufficiently wide and tall viewports; narrow,
zoomed, short, or target-incompatible contexts stay in flow. The page adapter
still owns the real fixed-header offset, safe areas, collision boundary,
available height, long-list reachability, and focus-not-obscured proof.

## Usage Guidelines

<DoDont>
  <Do>Supply a concise hierarchy of stable major sections whose labels, order, nesting, and fragments match the document headings.</Do>
  <Dont>Do not pass arbitrary merchant HTML, a Shopify menu, visual indentation, or an independently generated set of ids as the heading source.</Dont>
</DoDont>

<DoDont>
  <Do>Pass one controlled `currentSectionId` only when target reading state knows the current visible section.</Do>
  <Dont>Do not use `aria-selected`, `aria-current="page"`, an active-only class, a live region, or a second scroll observer.</Dont>
</DoDont>

`currentSectionId` is optional controlled state. A matching record projects
`aria-current="location"` to exactly one Link; blank or unmatched values produce
no current marker. L5 has no uncontrolled mode. A capable target may derive the
value from the same bounded reading-state service used by Reading Progress, but
L5 itself adds no parser, observer, listener, scroll polling, generated ids,
smooth scrolling, focus relocation, history mutation, announcement, or runtime.

The optional visible `title` remains neutral text in the shared renderer because
its heading rank belongs to the surrounding document. A target that owns the
contextual rank and stable title id may render it as a heading and name the
navigation through `aria-labelledby`.

Shopify exposes L5 only when an article source already provides structured
heading records and matching ids, or when verified preprocessing emits both
atomically. Native `article.content` is not parsed or rewritten by neutral L5.

## Accessibility

- Use a native `nav`, ordered and nested lists, list items, and canonical
  anchors with real `href` fragments. Do not add menu, tree, disclosure,
  arrow-key, or roving-tabindex behavior.
- Give the landmark a useful localized name that distinguishes it from site,
  footer, category, or other page navigation.
- Keep labels, hierarchy, order, and fragments synchronized with headings and
  reject duplicate or invalid record ids rather than emitting ambiguous links.
- Use at most one `aria-current="location"` from a matching controlled id. Its
  logical-start border and stronger weight preserve a non-color cue.
- Preserve canonical Link focus, wrapping, forced colors, and reduced motion.
  Long localized labels stay complete and nested indentation follows RTL.
- Sticky and flow keep the same Tab order. A sticky target must bound tall
  content, keep every focused Link visible, preserve page escape, account for
  fixed chrome and safe areas, and degrade to flow when those conditions cannot
  be proven.
