## Overview

Table of Contents presents a target-owned hierarchy of links to headings in the current article. It supports an in-flow default and an optional sticky presentation.

The in-flow presentation has no modifier class. `sticky` maps to `.toc--sticky`. Third- and fourth-level items use `.toc__item--h3` and `.toc__item--h4`; a target-synchronized active link may use `.toc__link--active`.

## Usage Guidelines

<DoDont>
  <Do>Match every fragment destination to a unique heading identifier in the article content.</Do>
  <Dont>Do not mark a link active unless the target keeps that state synchronized with the reading position.</Dont>
</DoDont>

Heading extraction and active-section synchronization remain target-owned. Whether this component shares a neutral reading-state enhancement with Reading Progress or receives state independently from each target remains unresolved.

## Accessibility

- Use a `nav` landmark with a useful accessible name when the page contains more than one navigation region.
- Keep list indentation aligned with the article heading hierarchy.
- Ensure every fragment link resolves to one unique heading `id`.
- Use active styling or `aria-current` only when its semantics match synchronized target state.
- Preserve visible keyboard focus and touch-sized links.
