## Overview

Review-result profile of canonical Pagination. It provides a specific navigation name and consumes the same native list, Link destinations, current page, ellipses and intrinsic wrapping without defining a provider or result lifecycle.

## Presentation

The root layers `.review-pagination` on canonical `.pagination`. Every visible part and interaction state comes from Pagination or Link; Review Pagination adds no independent button, size, color, radius, spacing, motion or disabled-state API.

The target supplies one finite ordered page window with real destinations, exactly one current page and optional passive ellipses. The list wraps from its actual container and never hides items through Review-specific CSS.

## Usage Guidelines

<DoDont>
  <Do>Compose canonical Pagination with a localized review-navigation name and real target-owned URLs.</Do>
  <Dont>Do not recreate Pagination with review-specific buttons, tokens, scrolling, page-window state or provider behavior.</Dont>
</DoDont>

Numbered pages, cursor pagination, load more, infinite loading and provider-managed controls are different target strategies. Only the finite numbered strategy maps to this profile. When the provider reports one page, omit the complete navigation.

## Accessibility

<Callout type="info">
  Review context changes the landmark name and result coordinator, not Pagination semantics or keyboard behavior.
</Callout>

- Use a specifically named `<nav>` containing the canonical `ul`/`li` list.
- Use native canonical Links with `href` for every available destination.
- Mark exactly one non-interactive current item with `aria-current="page"`.
- Omit Previous on the first page and Next on the last page instead of leaving disabled focus stops.
- Hide passive ellipses from assistive technology and never make them interactive.
- Preserve ordinary Tab and Enter behavior; do not add roving focus or arrow-key navigation.
- Let one target coordinator own provider requests, results, loading/errors, URL/history, scroll, focus and announcements.

**Dependencies:** canonical Pagination, which already composes Link.
