## Overview

Trust Badges presents a wrapping collection of passive trust or guarantee statements with optional supporting icons.

Default uses `.trust-badges`; Compact adds `.trust-badges--compact` to reduce collection spacing and badge typography. Both treatments preserve repeated `.trust-badge` statements and optional SVG icons.

## Usage Guidelines

<DoDont>
  <Do>Use short, accurate statements that reflect guarantees the target can actually honor.</Do>
  <Dont>Do not use icons alone, make passive statements focusable, or imply protections that are not available.</Dont>
</DoDont>

Use list semantics when each statement is an independent assurance.

## Accessibility

- Keep every guarantee available as readable text.
- Hide decorative icons from assistive technology.
- Name an informative icon only when it adds meaning beyond the accompanying text.
- Keep passive badges out of the keyboard focus order.
