## Overview

Responsive collection of target-supplied review themes and optional counts. Items are passive by default; navigation or selection semantics belong to the consuming target.

## Presentation

The required root wraps repeated theme items. Each `.review-highlights__tag` may include a target-formatted `.review-highlights__count`. The root can receive an accessible label when surrounding content does not already identify the collection.

The neutral presentation supports passive text, native links, or native buttons. Pressed, active-class, hover, focus-visible, and disabled hooks only apply when the target has chosen matching native semantics.

## Usage Guidelines

<DoDont>
  <Do>Use passive theme text until the target has explicitly chosen navigation or in-place selection behavior.</Do>
  <Dont>Do not treat `.is-active` as a filtering contract or assume single-select, multi-select, or URL behavior.</Dont>
</DoDont>

Theme extraction, counts, filtering, result updates, URL state, focus retention, and announcements remain target-owned and unresolved. The preview values are documentation fixtures, not component defaults.

## Accessibility

<Callout type="info">
  Native element choice carries the interaction meaning; the visual tag class does not create semantics.
</Callout>

- Use plain text for passive themes, native links for navigation, and native buttons for in-place selection.
- Put `aria-pressed` on a toggle button only when the target has selected that behavior.
- Use an appropriate current-page attribute for target-owned navigation when applicable.
- Do not apply pointer behavior or interactive semantics to passive items.
- Keep each count programmatically associated with its theme label.
- Do not rely on color alone for a target-owned active state.
