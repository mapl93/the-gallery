## Overview

Canonical modal image viewer composed from Modal, Close Button, and Icon Button with synchronized figure content, finite or looping navigation, direct swipe, bounded zoom/pan, and fallback media.

## Usage Guidelines

Public tokens control viewport padding, content/image bounds, figure gap,
caption width, fallback bounds/border and independent close/navigation/zoom
insets. Spacing factors multiply the shared base; viewport factors preserve
dynamic viewport units and safe-area containment. Control size, icons, borders
and focus reuse Close Button and Icon Button tokens. Studio uses the actual
image bounds instead of an additional 340px fixture cap.

The existing fixed on-scrim palette remains a documented pending owner decision.
This geometry checkpoint does not claim complete color customization. Zoom
scale, pan coordinates and swipe thresholds remain private interaction state.

<DoDont>
  <Do>Use Lightbox for focused viewing of a finite image collection with synchronized alternative text and captions.</Do>
  <Dont>Don't use it for forms, video/model playback, downloads, or commerce actions; rich media belongs to its native viewer and higher composition.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Lightbox inherits modal behavior: focus management, Escape dismissal, and restored focus are target responsibilities.
</Callout>

- Use a stable dialog title, trap focus while open, and return focus to the trigger on close.
- Close on `Escape`, the documented backdrop interaction, or the visible Close Button.
- All images must have descriptive `alt` text.
- Keep image, alternative text, counter, figcaption, and polite status synchronized.
- Disable previous/next at finite bounds or wrap all navigation consistently when `loop` is enabled; logical arrow and swipe direction follows RTL.
- Provide named zoom out/reset/in controls, constrain zoom to 1x–3x, bound direct pan, and reset the transform on image change or close.
- Keep the dialog operable with a named fallback when media fails.
- Respect reduced motion and forced-colors preferences.
