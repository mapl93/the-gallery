## Overview

Payment Icons presents a passive collection of payment-method marks supplied as raster images or inline vectors.

The default treatment uses 24-pixel-high marks. The mapped `.payment-icons--sm` capability reduces mark height to 18 pixels; it is a size capability, not an interaction state, and the registry does not yet expose a shared size list for it.

## Usage Guidelines

<DoDont>
  <Do>Render only methods that current target checkout data confirms are available.</Do>
  <Dont>Do not use decorative payment marks as a substitute for accurate checkout information.</Dont>
</DoDont>

Use official, legible payment marks in production targets and preserve each brand's required treatment.

## Accessibility

- Give each method an accessible name when readable text is not present.
- Hide duplicate decorative marks from assistive technology.
- Keep passive marks out of the keyboard focus order even though canonical CSS includes a hover treatment.
- Do not announce unavailable payment methods.
