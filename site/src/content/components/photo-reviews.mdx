## Overview

Passive native collection of target-supplied review images. Photo Reviews owns
square, container-responsive presentation; it does not own a review provider,
image pipeline, moderation, upload, navigation, download, Lightbox or Modal.

## Presentation

The required `.photo-reviews` root is a native `ul[role=list]`. Every
`.photo-reviews__item` is a native `li` containing one strict
`.photo-reviews__image`. `role=list` defensively preserves the exposed
collection relationship after CSS removes visual markers.

The shared Exhibit/Studio artwork is passive. If a target has a real
destination or action, it places an optional native
`.photo-reviews__action` link or button *inside* the list item:

| Target intent | Native surface | Target-owned facts |
| --- | --- | --- |
| Passive evidence | no action wrapper | source, alt, responsive delivery |
| Full-media navigation | `a.photo-reviews__action[href]` | URL, destination name, history/download policy |
| Enlarged-media request | `button.photo-reviews__action[type=button]` | action name, overlay component, open/index state |

Only that action receives hover zoom, decorative overlay, a two-tone
focus-visible perimeter, disabled and reduced-motion treatment. Collection
membership never moves onto the link or button.

### State Ownership

The passive component has no controlled or uncontrolled value. A target that
composes Lightbox or Modal owns open state, active media, captions, navigation,
loading, preloading, dismissal, focus restoration, URL/history and analytics.
Static Web may author real links without component JavaScript.

### Target Translation

- **Web:** native list/items, strict image class and optional native action;
  target supplies `src`, `srcset`, `sizes`, `alt`, loading and failure policy.
- **Shopify:** a review-provider theme app block supplies moderated image data,
  Shopify CDN transforms, localized alternatives and any actions while
  consuming generated Reviews CSS.
- **React / Angular:** the passive list remains stateless; a separately accepted
  overlay composition owns controlled or initial open/index state.
- **Figma / native:** reproduce the reviewed passive grid and target-action
  visual states without inventing provider or overlay behavior.

## Usage Guidelines

<DoDont>
  <Do>Keep review images passive until the target has a real destination or a complete native overlay composition.</Do>
  <Dont>Do not make a list item or div click-only, infer Lightbox behavior from the square crop, or duplicate the image selector.</Dont>
</DoDont>

The square crop, grid minimum, gap, radius, overlay strength and zoom are
private composition. Do not expose them as public API merely because CSS uses
literal values.

Caption, reviewer attribution, duplicate-photo treatment, provider taxonomy,
moderation, source order, maximum count, formats, CDN transforms, fallback and
sensitive-content policy remain target/product decisions.

## Accessibility

<Callout type="info">
  Informative and functional images have different naming obligations. The
  photo alternative describes the essential visual content; an optional action
  name describes what activating it does or where it goes.
</Callout>

- Keep the native `ul` / `li` relationship and source order.
- Give informative review photos concise, contextual `alt` text.
- Use `alt=""` only when the same photo is genuinely decorative or redundant
  in its current context.
- Use a native link for navigation/download and a native button for an action.
- Give the action an explicit accessible name that describes its purpose or
  destination rather than relying only on the photo description.
- Preserve native Enter, Space for buttons, visible focus and native disabled
  behavior. Links do not use fake disabled state.
- Do not convey action, loading, failure, moderation or review information only
  through crop, hover, zoom or the decorative overlay.
- If enlarged media is selected, compose the complete Lightbox or Modal
  contract. Photo Reviews does not partially own focus containment, Escape,
  close, navigation or focus restoration.

## Content And Performance

Use responsive sources and modern formats appropriate to the target. Reserve
the square layout before the media loads, and let the target decide eager/lazy
thresholds, decoding, fallback and whether a failure removes or replaces an
item. Photo Reviews emits no live region for image loading or failure.

The docs fixture uses local editorial media with `loading="lazy"` and
`decoding="async"`. Those files demonstrate the renderer; their source size is
not a public production default.

The neutral component adds no listener, observer, timer, request, formatter,
layout read, JavaScript asset, icon, font or media file.

## Specification

**Anatomy:** required native `.photo-reviews` list, repeated native
`.photo-reviews__item` and `.photo-reviews__image`; optional native
`.photo-reviews__action`; generated action-only overlay.

**Dependencies:** None. A target may compose the canonical Lightbox or Modal
after separately accepting that product behavior.
