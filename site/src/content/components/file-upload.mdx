## Overview

Full-surface native file input with drag presence and selected-file status.

## Presentation

File Upload supports `default`, `error`, `success`, and `warning` validation families. Drag-over and focus retain the active family.

## Usage Guidelines

<DoDont>
  <Do>Keep the native file input as the sole selection and form-value owner.</Do>
  <Dont>Don't treat `accept` as validation or replace the native `FileList` during drag and drop.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Drag and drop is an enhancement. The native file input remains the primary upload path.
</Callout>

- Expose accepted file types and size limits in visible helper text.
- Announce validation errors and selected file names.
- Keep previews synchronized with the current file list.
- Provide useful alt text or file names for image previews.
- Revoke target-created object URLs when a preview changes or unmounts; the base enhancer creates none.

## References

### Visual customization

Studio and Exhibit expose the same public controls for surface minimum height,
normal/compact padding, border, optional icon size and gap, guidance/status gaps,
text weights, preview spacing and thumbnail geometry. Shared Input focus, colors,
typography, radii, opacity and timing remain shared roles. Minimum height is a
floor; longer content and padding can make the surface taller.

Compact surface measures apply when an ancestor query container is at most
320px wide. The demo wrapper provides that container. Selected image previews
are an optional site fixture using local object URLs; the native FileList remains
the authority and no upload is performed. Reset clears both selection and previews.
