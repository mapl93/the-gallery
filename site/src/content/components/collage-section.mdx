## Overview

Collage Section presents a finite ordered collection of target-owned media in an art-directed grid. An optional visible heading names the section, one item may receive feature emphasis, and captions remain visible without hover or focus.

Feature is item-level visual metadata, not a component state. It changes span only and never changes DOM order, meaning, focus, activation, loading priority, or announcements.

## Usage Guidelines

<DoDont>
  <Do>Keep source order meaningful, choose one clear feature item, and provide useful media alternatives.</Do>
  <Dont>Do not add `tabindex`, click behavior, Lightbox semantics, or product claims to passive items.</Dont>
</DoDont>

Targets may wrap one figure in a native anchor only when a real destination exists, or compose a separately defined control. The neutral component does not choose whether items navigate, open a Lightbox, or expose commerce.

## Accessibility

- Use a native heading-labelled section only when the visible heading exists; otherwise use a generic root.
- Render one native list in meaningful source order and one figure per valid item.
- Keep optional figcaptions visible without hover, focus, touch, or motion.
- Leave passive figures out of the tab order; real links and controls retain native keyboard behavior and visible focus.
- Omit the complete component when the required item collection is empty.
