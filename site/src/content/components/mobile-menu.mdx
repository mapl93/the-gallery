## Overview

Mobile Menu is a target-owned navigation list intended for composition inside Drawer. It owns link-list presentation, not overlay visibility or navigation data.

## Presentation

`items` supplies the required `.mobile-nav` list with target-owned `.mobile-nav__item` and `.mobile-nav__link` content. Visible dividers, touch targets, focus treatment, long-label containment, and current-page color are canonical presentation.

The artwork shows only the list so it does not invent a trigger or overlay runtime. Drawer owns open state, backdrop, focus containment, dismissal, and focus restoration when Mobile Menu is presented as an overlay.

## Usage Guidelines

<DoDont>
  <Do>Keep mobile destinations aligned with the target's navigation model and expose the current page.</Do>
  <Dont>Do not duplicate Drawer visibility or dismissal behavior inside Mobile Menu.</Dont>
</DoDont>

- Supply destinations, labels, hierarchy, and order from target navigation data.
- Keep labels concise enough to scan while allowing them to wrap safely.
- Resolve nested navigation and breakpoint policy in the consuming target.

## Accessibility

- Place the list inside a labelled `nav` region.
- Use native links with valid destinations and `aria-current="page"` when applicable.
- Preserve Drawer focus management and dismissal when the list appears in an overlay.
- Ensure navigation remains usable by keyboard and at touch target sizes.
