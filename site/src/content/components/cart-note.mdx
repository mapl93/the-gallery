## Overview

Cart Note is an optional disclosure for a target-owned order note. It delegates value entry, validation, resize behavior, and feedback to the Textarea dependency.

## Presentation

`expanded` defaults to `false` and synchronizes the disclosure state of the required toggle. The optional `field` slot composes the complete Textarea dependency at `.cart-note__field`.

Cart Note owns only disclosure and target persistence boundaries. Textarea owns the native value field, label, validation family, line bounds, and resize direction.

## Usage Guidelines

<DoDont>
  <Do>Persist the note to the target cart after deliberate change or blur handling.</Do>
  <Dont>Do not use the note field for structured choices that deserve dedicated controls.</Dont>
</DoDont>

- Preserve the note value across cart quantity and totals updates.
- Keep the field optional unless the surrounding flow explicitly establishes a requirement.
- Use Textarea properties for resize direction, line bounds, validation, and disabled state.

## Accessibility

- Connect the toggle to the field region with `aria-controls` and synchronize `aria-expanded`.
- Give the composed Textarea a visible label.
- Preserve Textarea keyboard, resize, validation, and feedback semantics.
- Do not discard entered content when the disclosure collapses.
- Keep the disclosure control keyboard reachable with visible focus.
