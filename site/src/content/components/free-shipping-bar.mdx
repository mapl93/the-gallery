## Overview

Free Shipping Bar communicates cart progress toward a target-owned shipping threshold. Visible text and native progressbar semantics carry the meaning; fill width is supporting presentation.

## Presentation

`value` represents the current cart amount and `max` represents the free-shipping threshold. Their contract defaults are `0` and `100`, and both remain required target inputs.

`achieved` defaults to `false`. When the threshold is reached, `.shipping-bar--achieved` changes the message treatment, but `text` must explicitly communicate the achieved state rather than relying on color or a full track.

## Usage Guidelines

<DoDont>
  <Do>Recalculate progress from the same cart state used for totals and shipping eligibility.</Do>
  <Dont>Do not infer free-shipping eligibility from presentation width alone.</Dont>
</DoDont>

- Format the remaining amount through the commerce target.
- Clamp visual progress to the valid range while preserving the true target state in text.
- Replace the remaining-amount message with a clear achieved message at the threshold.

## Accessibility

- Give the track `role="progressbar"` and synchronize `aria-valuenow` and `aria-valuemax` with `value` and `max`.
- Provide a concise accessible name for the progressbar.
- Expose the amount remaining or achieved state as visible text.
- Announce meaningful eligibility changes when cart totals update.
- Do not rely on fill width or success color alone.
