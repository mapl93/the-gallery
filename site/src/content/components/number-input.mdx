## Overview

Generic native numeric field with direct editing, explicit decrement/increment actions, constraints, and form semantics.

## Presentation

Number Input remains separate from the commerce-oriented Quantity Selector while sharing the same native stepping model. Validation, disabled, readonly, required, and boundary availability are independent states.

## Usage Guidelines

<DoDont>
  <Do>Use Number Input for actual numeric values and let the native field preserve empty or partial direct editing.</Do>
  <Dont>Don't use it for postal codes, card numbers, identifiers, or other digit strings.</Dont>
</DoDont>

## Accessibility

- Associate the field with a visible label or equivalent accessible name.
- Give decrement and increment actions clear names and connect them to the field with `aria-controls`.
- Keep native Arrow Up/Down and direct text editing available.
- Respect `min`, `max`, `step`, `required`, `disabled`, and `readonly` constraints.
- Disabled fields are unavailable and omitted from form data; readonly fields remain focusable and submittable with step actions disabled.

## References

### Visual customization

Number Input exposes preferred/minimum/maximum value width, value padding,
separator width, action icon/text size and value line height. It reuses the public
Input border/focus dimensions and existing shared typography, radius, colors,
opacity, motion and 46px minimum control height. Action width is independent.
The previous 48px outer height included borders on top of a 46px inner action;
the revised inner calculation yields 46px outside and 44px-high actions by default.

Use icon actions is a Studio fixture control; the default retains text signs.
Action icon size applies to supplied SVG artwork, while Action text size applies
to text signs. Neither choice changes the neutral contract or icon source.

Default borders mix 60% of the input color with primary text; validation
borders/icons mix 70%. The state swatches expose inputs to those derivations.
The numeric glyphs retain LTR order within RTL layouts. Centering, native spinner
suppression and line-height 1 for signs stay private. Keep minimum value width
below maximum width and leave room for both action targets plus borders.

The parent [Field Wrapper](/components/field-wrapper) owns labels and feedback;
these are not independent Number Input value/validation owners. Numeric `min`,
`max` and `step` describe accepted data, while the width controls describe CSS
geometry. Empty input is preserved and direct edits are not clamped.

Number Input and [Quantity Selector](/components/quantity-selector) share an internal native stepping model but remain distinct public components under ADR 0060.
