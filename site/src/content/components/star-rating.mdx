## Deprecated identity

Star Rating Display (`V2`) is deprecated as an independent component. ADR 0235
consolidates its half-step value and `default | lg` presentation into canonical
[Rating](/components/rating).

This migration page uses the same `RatingStudio`, `RatingArtwork`, fixture,
contract shape and canonical `.rating` CSS as A11. It owns no `.star-rating`
selector, CSS, renderer, fixture, behavior, token or target adapter.

## Migration

- Replace `.star-rating` with `.rating`.
- Replace V2 `label` with canonical `accessibleLabel`.
- Keep the supplied `ratingValue`; use the canonical `.rating--lg` class for
  the large presentation.
- Optional complete localized `reviewCount` now belongs to the same canonical
  Rating API.
- Replace V2 star containers/icon layers with canonical
  `.rating__stars > .rating__star` full/half/empty anatomy.
- Update Review Summary, Review Card and custom consumers to depend on `rating`.

Do not restore a compatibility selector alias. This registry entry remains only
to make pre-v1 migration explicit and is never eligible for `stable`.
