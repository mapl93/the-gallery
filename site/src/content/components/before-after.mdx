## Overview

Before / After compares two spatially aligned media states through one native range control. It is useful for treatment, restoration, material, process, or customization comparisons where a direct reveal adds meaning.

Use two separate figures when the media do not show the same subject and framing. Use Slider / Range directly when selecting a number is the task rather than comparing media.

The revealed percentage is fixed to `0–100`, defaults to `50`, and advances in steps of `1`. The same canonical Slider input owns value, focus, pointer, touch, keyboard, form submission, reset, `input`, and `change`; the clip and decorative divider only reflect that native owner.

Without shared enhancement, the authored comparison remains static and the unsynchronized input is hidden. No inactive draggable affordance is presented.

## Usage Guidelines

<DoDont>
  <Do>Use matched media with the same subject, crop, dimensions, and focal point so movement communicates a real change.</Do>
  <Dont>Do not use unrelated images, add a second drag engine, or expose crop and divider geometry as semantic API.</Dont>
</DoDont>

The accessible comparison label should explain what the percentage reveals. Visible Before and After state labels and the description are optional supporting content.

## Accessibility

- Provide a non-empty localized label for the native range input.
- Preserve native `min="0"`, `max="100"`, `step="1"`, current value, Arrow, Home, End, pointer, touch, form, and reset behavior.
- Give both matched media useful distinct alternatives, or use an equivalent concise grouped description without redundant announcements.
- Keep the divider decorative and unfocusable; the range input is the only interaction owner.
- Do not announce every value through a live region. Native range semantics already expose changes.
- The component introduces no motion, so reduced-motion mode behaves identically.
