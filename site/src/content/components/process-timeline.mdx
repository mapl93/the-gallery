## Overview

Process Timeline presents an ordered set of target-owned process steps in a horizontally scrollable track that becomes a wrapping grid at wider viewports.

## Presentation

`title` and the ordered `steps` slot are required. Each step exposes a visible sequence number and title, with optional image and description regions.

On narrow viewports, the track scrolls horizontally with snap alignment. When it overflows, the target must keep the region keyboard-scrollable and provide an accessible name where needed. Step records and their content remain target-owned.

## Usage Guidelines

<DoDont>
  <Do>Keep steps in the real process order and use visible sequence numbers.</Do>
  <Dont>Do not use connector lines or scroll position as the only indication of sequence.</Dont>
</DoDont>

- Keep step titles parallel and descriptions concise.
- Include images only when they clarify a stage of the process.
- Preserve the same logical order across narrow and wide layouts.

## Accessibility

- Use a heading level appropriate to the surrounding page for the timeline title and each step title.
- Preserve logical step order in the source regardless of responsive layout.
- Give meaningful step images useful alternative text and mark decorative images accordingly.
- Make an overflowing track keyboard-scrollable with visible focus.
