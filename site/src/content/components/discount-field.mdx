## Overview

Discount Field is a promo-code disclosure that composes Input and Button. It represents both code entry and an optional applied-code state while the commerce target owns validation and totals.

## Presentation

`expanded` defaults to `false` and controls the disclosure state of the promo-code form. The optional `input` slot is the canonical Input dependency; `applyLabel` names the adjacent Button action.

`applied` also defaults to `false`. When active, `appliedCode` supplies the readable code and `removeLabel` supplies the removal action's accessible name. Applying or removing a code updates target-owned commerce state rather than local presentation data alone.

## Usage Guidelines

<DoDont>
  <Do>Validate the submitted code through the commerce target and reflect the resulting totals.</Do>
  <Dont>Do not present a code as applied until the target confirms it.</Dont>
</DoDont>

- Preserve the entered value when a recoverable validation response is shown.
- Keep applied-code removal available wherever the active code is displayed.
- Use the Input dependency for field validation and feedback semantics.

## Accessibility

- Connect the disclosure button to the form with `aria-controls` and synchronize `aria-expanded`.
- Give the promo input a visible label; placeholder text is not its accessible name.
- Announce whether a code was applied, rejected, or removed and whether totals changed.
- Include the active code in `removeLabel`.
- Preserve visible focus for the disclosure and removal controls.
