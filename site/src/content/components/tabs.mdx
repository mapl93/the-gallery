## Usage Guidelines

<DoDont>
  <Do>Use tabs to switch between related panels at the same hierarchy level.</Do>
  <Dont>Don't use tabs as primary site navigation or for unrelated destinations.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Tabs require keyboard behavior in the target adapter, not just visual classes.
</Callout>

- Use `role="tablist"`, `role="tab"`, and `role="tabpanel"`.
- Use `aria-selected`, `aria-controls`, and `aria-labelledby` to connect tabs and panels.
- Hide inactive panels with `hidden`.
- Support arrow key navigation between tabs.
