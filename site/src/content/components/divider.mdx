## Overview

Horizontal or vertical rule with independent visual presentation and separator semantics.

<Preview html={"<div class=\"tg-preview-line\"><hr class=\"divider\" aria-hidden=\"true\" /></div>"} label="Divider" />

## Presentation

Default is a subtle rule. `decorative` increases visual emphasis with a stronger
color and `2px` thickness. `orientation` changes the axis without changing
visual style or purpose. Divider adds no external margin: its parent layout owns
the distance between surrounding regions.

<Preview html={"<div class=\"tg-preview-stack\"><span>Default</span><hr class=\"divider\" aria-hidden=\"true\" /><span>Decorative</span><hr class=\"divider divider--decorative\" aria-hidden=\"true\" /></div>"} label="Divider presentations" />

A vertical divider uses `data-orientation="vertical"` inside a parent that establishes its cross-axis height. When that vertical divider is structural, it also sets `aria-orientation="vertical"`; horizontal is the implicit separator default.

Purpose does not change appearance. A **Visual only** divider is hidden from
assistive technology; a **Semantic separator** communicates a real boundary
between regions. Studio presents these plain-language labels while the public
contract retains `semantics: decorative | structural` for compatibility.

## Usage Guidelines

<DoDont>
  <Do>Use a semantic separator only when the rule communicates structure between regions.</Do>
  <Dont>Don't announce a purely decorative rule to assistive technology.</Dont>
</DoDont>

<DoDont>
  <Do>Set section and element spacing on the parent stack, grid, or region.</Do>
  <Dont>Don't use Divider variants to control surrounding layout spacing.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Use semantic separator markup when the divider conveys structure. Hide purely decorative dividers from assistive technology.
</Callout>

- Use `hr` or `role="separator"` when the divider conveys structure.
- Use `aria-hidden="true"` for purely decorative dividers.
- Add `aria-orientation="vertical"` when a structural separator uses the vertical axis.
- Preserve a visible system-color rule in forced-colors mode.
- Do not use the divider line as the only cue for grouped content.
