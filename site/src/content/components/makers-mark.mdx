## Overview

Maker's Mark is a maker-attribution group with one required visible identity, one optional canonical profile Link, and optional target-owned stamp, studio context, and formatted year wording. It does not define a person, studio, vendor, product, provenance, certificate, or authenticity record.

## Presentation

`artist` is required and a blank value omits the complete component. `href`, `stamp`, `studio`, and `year` omit independently. A non-empty real `href` wraps only the complete visible identity in one native canonical Link; without it, the same identity remains ordinary text. The interactive Exhibit/Studio fixture and this fallback use the same content and structure; MG is hidden from assistive technology because the adjacent visible name already communicates the identity.

The neutral root is a generic non-landmark container. A target may choose `aside`, `article`, `section`, `address`, or another element only when its document context independently supports that meaning. The root, stamp, studio and year remain passive; the optional identity Link provides only target-owned profile navigation and makes no authenticity, verification, authorship, manufacture, or provenance claim.

## Guidelines

<DoDont>
  <Do>Keep a complete maker name visible and treat the stamp as contextual supporting content.</Do>
  <Dont>Do not force a landmark, Avatar, Badge, empty/scripted Link, verification state, or authenticity claim from the visual treatment.</Dont>
</DoDont>

- Use complete localized studio and year wording supplied by the target; R9 does not parse or infer their meaning.
- Use native `img` or appropriate graphic markup when a stamp adds information and provide an equivalent alternative.
- Use `alt=""` or `aria-hidden="true"` when a mark only repeats the adjacent visible identity.
- Omit empty stamp wrappers and optional text rather than leaving placeholders.
- Use the optional canonical Link on the complete visible identity only when the target owns a real maker-profile destination; never make the stamp or whole surface clickable.
- Keep certificate, QR, signature verification, provenance, vendor records, rights, and product relationships outside R9.

## Accessibility

- Keep the full maker identity available as visible text and fail closed when it is empty.
- Default to a generic container with no landmark role, accessible name, live region, or widget semantics; only the optional canonical identity Link enters tab order.
- Do not use `cite` for a person or organization name. Do not use `address` unless the content is actual contact information for the nearest article or page.
- Do not assign an image role to a generic empty block or announce initials plus the adjacent full name as two identities.
- Preserve automatic direction, complete text wrapping, 200% text, user spacing, forced-color boundaries, and source order.
- Never present a visual stamp, border, year, badge, icon, or code as evidence of authenticity without a separately substantiated target record.

## Specification

Public visual tokens control maximum width, stamp size, surface padding, stamp/text gaps and border thickness. The stamp alignment still follows the existing component-width query; profile navigation composes canonical Link. Spacing factors multiply the shared element gap; changing content or variants remains separate. Studio and Exhibit derive controls from the same public inventory.


**Dependencies:** canonical Link. Maker stamp media is not automatically Avatar or Badge composition.

**Anatomy:** required generic `.makers-mark`, optional `.makers-mark__stamp`, required `.makers-mark__info` and non-empty `.makers-mark__artist`, optional `.makers-mark__artist-link`, plus optional `.makers-mark__studio` and `.makers-mark__year`.
