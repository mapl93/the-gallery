## Overview

Canonical passive rating projection for a target-supplied value from zero
through five in half-step increments. Rating exposes one named star image,
shape-distinct full/half/empty anatomy, `default | lg` presentation, and an
optional independently readable localized review count.

## Presentation

`ratingValue` is required target-normalized data in `0.5` steps. The target
generates the five decorative states; neutral Web styles the supplied markup and
adds no parser, rounding service or runtime. Invalid required value/label
composition emits no Rating root in the shared renderer.

## Usage Guidelines

<DoDont>
  <Do>Use Rating for a supplied passive half-step value in commerce or review content.</Do>
  <Dont>Do not normalize provider data or collect a person's rating inside this component; use Star Input for value entry.</Dont>
</DoDont>

Provider scale normalization, rounding, missing/zero policy, aggregates,
structured data, dynamic announcements and an optional adjacent review Link
remain target-owned. `reviewCount` is passive complete localized text, not an
implicit destination.

## Accessibility

- Provide a non-empty complete localized `accessibleLabel` that agrees with the
  supplied value and visual star sequence.
- Expose that label once on `.rating__stars[role="img"]`; hide each star.
- Preserve solid, partial-fill and outline forms so state is not color-only.
- Keep optional count text outside the image and include its localized noun.
- Rating is unfocusable, non-live and has no controlled/uncontrolled input
  lifecycle.

## Visual Customization

Studio and Exhibit expose count gap, inter-star gap, both star sizes, count typography, and the shared filled/empty color roles. Large star size is independent of the default Body size; the inspector shows the applicable size control. Relative units remain relative to the consuming page. Half-fill clipping and left-to-right star order are rendering mechanics. The target still supplies an accurate localized label with its value.
