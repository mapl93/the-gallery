## Presentation

Selection is expressed by the root border and radio indicator. The frequency field appears only for the selected option and uses the shared `default`, `error`, `success`, and `warning` validation language.

## Usage Guidelines

<DoDont>
  <Do>Show the recurring price, savings, delivery frequency, and renewal terms before selection.</Do>
  <Dont>Do not preselect a subscription when the customer could mistake it for a one-time purchase.</Dont>
</DoDont>

- Keep one-time and recurring choices in the same radio group.
- State whether the customer can pause, change, or cancel the subscription.
- Use warning for recoverable schedule attention and error for an invalid frequency choice.

## Accessibility

- Use native radio controls or complete `radiogroup` and `radio` semantics with keyboard support.
- Keep `aria-checked` synchronized with the selected visual state.
- Connect the frequency label and message to the select control.
- Format prices and savings through the target commerce layer.
- Do not use the field indicator as the only carrier of validation meaning.
