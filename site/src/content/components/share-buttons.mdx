## Overview

Share Buttons arranges target-owned share links or actions in inline or column presentation. It does not choose providers, destinations, native sharing behavior, copy feedback, or fallbacks.

## Presentation

<Preview html={'<div class="share-buttons share-buttons--inline" role="group" aria-label="Share this article"><button type="button">Share</button><button type="button">Copy link</button></div>'} label="Share Buttons" />

`inline` maps to `.share-buttons--inline` and is the default. `sticky` maps to `.share-buttons--sticky`, which changes the action layout to a column but does not itself position the component. Each action retains the semantics and presentation owned by its target control.

## Usage Guidelines

<DoDont>
  <Do>Use links for provider destinations and buttons for native share or copy actions.</Do>
  <Dont>Do not infer providers, URLs, icons, feedback, or fallback behavior from the static preview.</Dont>
</DoDont>

Which CSS family is canonical between `.share-buttons` and `.share` remains unresolved. The layer that owns provider URLs, Web Share, copy feedback, and fallbacks also remains unresolved. This contract maps only the registry-backed `.share-buttons` family.

## Accessibility

- Give the action group a useful accessible name when surrounding text does not identify it.
- Use links for destinations and native buttons for actions.
- Give icon-only actions provider-specific accessible names.
- Preserve each composed control's visible focus and keyboard behavior.
- Announce copy success or failure through the target action's accepted feedback pattern.
