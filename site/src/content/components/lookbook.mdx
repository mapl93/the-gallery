## Overview

Lookbook composes an ordered, asymmetric set of target-owned media cells with optional item-level spans, captions, and hotspot content. Item destinations and hotspot behavior remain unresolved.

Wide and tall modifiers belong to individual `.lookbook__cell` elements. Captions and hotspots are item-level compositions; their presence does not establish navigation, disclosure, selection, or commerce behavior.

## Usage Guidelines

<DoDont>
  <Do>Build a deliberate visual sequence and keep essential captions available without pointer hover.</Do>
  <Dont>Do not add hotspot destinations or popovers until the target owns their native elements and complete behavior.</Dont>
</DoDont>

Use span modifiers sparingly so the reading order remains understandable when the grid collapses.

## Accessibility

- Give informative media useful alternative text and use semantic captions where they add context.
- Keep DOM order meaningful independently of wide or tall visual spans.
- Use native interactive elements only when a destination or command has been established.
- Any target-owned hotspot must have an accessible name, visible focus, keyboard activation, and a defined result.
