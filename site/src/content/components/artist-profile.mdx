## Overview

Artist Profile is a responsive editorial biography that preserves the reading order of portrait, label, name, location, biography, philosophy, and target-owned actions.

## Presentation

The default presentation stacks into one column and becomes a balanced two-column layout at wider viewports. `portrait`, `label`, `location`, `philosophy`, and `actions` are optional; `name` and `biography` are required.

Biography and actions are target-owned slots. Their rich content and controls retain their own semantics, while Artist Profile owns the narrative order and responsive composition.

## Usage Guidelines

<DoDont>
  <Do>Keep the biography focused and preserve the authored narrative sequence.</Do>
  <Dont>Do not rearrange the source order to match the wide visual columns.</Dont>
</DoDont>

- Use portrait media that supports the biography rather than repeating it.
- Keep the philosophy concise enough to remain a supporting quotation.
- Compose only actions that belong to the artist context.

## Accessibility

- Use a heading level appropriate to the surrounding page for the artist name.
- Give meaningful portrait media useful alternative text and mark decorative media accordingly.
- Preserve source reading order when the layout changes between one and two columns.
- Keep composed actions keyboard accessible with visible focus indicators.
