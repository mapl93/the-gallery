## Overview

Article Hero is a passive native `header` that introduces the surrounding article with one required complete contextual heading and optional category, media, and target-formatted metadata. It supports full-image, split, and text-only editorial presentations without owning article data, navigation, or runtime behavior.

`full` maps to `.article-hero--image`, `split` maps to `.article-hero--split`, and `text-only` maps to `.article-hero--text`. The root owns a named inline-size container and the private `.article-hero__layout` responds to available component width. Full media uses `.article-hero__bg` plus a visual-only `.article-hero__overlay`; split media uses `.article-hero__media`.

When the selected full or split media slot is absent, the renderer adds private `.article-hero--without-media`. The complete content then remains readable in normal colors without an empty split track, inverse text over transparency, or an invented substitute image.

Unsupported variant input normalizes to `full` before that derived state is
calculated, so malformed input cannot retain inverse media styling without
media.

## Usage Guidelines

<DoDont>
  <Do>Choose the presentation from the article context and available media, retain a complete title, and supply semantic target metadata.</Do>
  <Dont>Do not use Article Hero as the article boundary, page shell, action surface, date formatter, reading-time calculator, or image-content policy.</Dont>
</DoDont>

Use full-image only when the complete responsive crop and private contrast overlay keep category, title, and metadata compliant. Prefer split or text-only when media cannot support overlaid text. The target chooses the heading rank, image alternative, localized metadata order/format, and any independent category or author destinations.

## Accessibility

- Compose the native `header` inside the target article/page and choose a heading level that fits the surrounding hierarchy; a standalone article normally uses `h1`, while this docs fixture uses `h2`.
- Give informative media useful contextual alternative text and decorative media `alt=""`. Full versus split placement does not determine image meaning.
- Verify overlaid category, title, and metadata contrast against every image crop, theme, and viewport. The visual overlay is `aria-hidden` and is not public configuration.
- Use machine-readable `time[datetime]` values for dates and durations and hide visual-only separators from assistive technology.
- Preserve complete wrapping content, normal DOM reading order, forced-colors readability, intrinsic reflow, and zero motion/runtime dependency.
