## Usage Guidelines

<DoDont>
  <Do>Use semantic HTML (section, nav, aside) alongside the layout classes.</Do>
  <Dont>Don't nest layout overlays (modal inside drawer, etc.) — it creates confusing z-index stacking.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Layout components handle z-index and focus trapping. Test keyboard navigation before shipping.
</Callout>

- Use `<nav>` with `aria-label` to identify the navigation region.
