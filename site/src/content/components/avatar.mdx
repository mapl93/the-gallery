## Overview

Circular identity primitive composed with an image or initials and available in four sizes.

<Preview html={"<span class=\"avatar\" role=\"img\" aria-label=\"Maria Pacheco\">MP</span>"} label="Avatar" />

## Presentation

`size` changes the avatar diameter without changing its content or identity semantics. Default is the classless size.

<Preview html={"<div class=\"tg-preview-inline\" aria-hidden=\"true\"><span class=\"avatar avatar--sm\">SM</span><span class=\"avatar\">MD</span><span class=\"avatar avatar--lg\">LG</span><span class=\"avatar avatar--xl\">XL</span></div>"} label="Sizes" />

| Property | Value | Web mapping |
| --- | --- | --- |
| `size` | `sm` | `.avatar.avatar--sm` |
| `size` | `default` | `.avatar` |
| `size` | `lg` | `.avatar.avatar--lg` |
| `size` | `xl` | `.avatar.avatar--xl` |

Image content is composed as a native `img` inside the avatar. Initials are direct text content. The current contract does not automate image loading failure or initials fallback.

## Usage Guidelines

<DoDont>
  <Do>Keep the represented person's name available through nearby text, image alt text, or an accessible name.</Do>
  <Dont>Don't treat initials as a sufficient accessible name on their own.</Dont>
</DoDont>

<DoDont>
  <Do>Choose an image or initials composition explicitly in the consuming markup.</Do>
  <Dont>Do not assume Avatar derives initials or swaps content when an image fails.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Avatar supports image or initials composition. Identity text should be available either through alt text, nearby visible text, or an accessible name.
</Callout>

- Give avatar images descriptive alt text when the avatar conveys identity.
- Use empty alt text when nearby visible text already identifies the person.
- Expose an accessible name for initials-only avatars when identity is not otherwise present.
