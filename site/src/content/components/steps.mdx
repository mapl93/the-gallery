and completed states.

## Usage Guidelines

<DoDont>
  <Do>Use steps to show a user's position in a known ordered process.</Do>
  <Dont>Don't use steps as decorative bullets when there is no current progress state.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Render Steps as a labelled ordered list. Mark at most one current item with
  `aria-current="step"`; visual orientation does not require `aria-orientation`.
</Callout>

- Do not communicate completion only by color or an `aria-hidden` checkmark; include equivalent state text.
- Keep source order and semantics identical in horizontal, vertical, localized, RTL, and narrow layouts.
- The base is passive. Compose native Links or Buttons only when the owning workflow defines navigation and validation.

## Visual Customization

Twenty-five public roles cover appearance and geometry. Indicator size (1.75rem), indicator border (2px), connector width (2px), completed icon size (0.875rem), and horizontal item basis (7rem) are independently editable. Connector centering derives from indicator and line size. Flexible items grow into the parent width; horizontal overflow remains scrollable when their combined basis no longer fits.

Horizontal content-gap and description-gap factors start at 0.5/0.25 of the responsive spacing base. Vertical item gap, bottom padding and content inset factors start at 0.75/1.5/0.25. Indicator/title weights reuse semibold/medium. Orientation remains a variant independent from current, completed or upcoming state; the old done class remains an alias for completed, not a separate state. Terminal connector rules and the decorative stacking level are structural geometry.

Steps remains a named passive ordered list, with at most one current step and completion expressed in text as well as its decorative icon. Token changes do not add navigation, an index controller, automatic orientation or checkout integration. Checkout Progress inherits its indicators and type; its own narrow composition may hide connectors and set layout gaps under ADR 0163, rather than becoming a new Steps mode.
