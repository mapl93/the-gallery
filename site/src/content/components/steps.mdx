## Usage Guidelines

<DoDont>
  <Do>Use steps to show a user's position in a known ordered process.</Do>
  <Dont>Don't use steps as decorative bullets when there is no current progress state.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Steps can be rendered as an ordered list. Mark the current step with `aria-current="step"`.
</Callout>

- Do not communicate completion only by color.
- Keep horizontal and vertical layouts semantically equivalent.
- Use clear text labels for active, completed, and upcoming steps.
