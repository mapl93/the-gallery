## Overview

Certificate of Authenticity is a contained record surface for a piece title, artist attribution, certificate details, signature, and target-owned verification guidance.

## Presentation

`title` is required. The certificate label, artist, metadata details, signature, and verification regions are optional. Metadata is a target-owned collection of name-value pairs that collapses to one column on narrow viewports.

Targets own certificate records, verification destinations, and authenticity guarantees. This component presents those records but does not create or validate them.

## Usage Guidelines

<DoDont>
  <Do>Present only certificate data supplied by an authoritative target record.</Do>
  <Dont>Do not imply authenticity from the visual treatment alone.</Dont>
</DoDont>

- Keep metadata labels concise and values unambiguous.
- Use the signature region for a signature or artist mark supplied by the target.
- Provide a readable verification destination in addition to any machine-readable image.

## Accessibility

- Use semantic name-value markup such as a description list for certificate details.
- Expose verification as a descriptive link when it has a destination; a QR image must not be the only verification path.
- Give a verification image alternative text that describes its action, unless adjacent link text already provides the accessible name.
- Treat the divider as decorative.

## References

**Dependencies:** None.

**Anatomy:** required `.coa` root and `.coa__title`; optional `.coa__header`, `.coa__artist`, `.coa__divider`, `.coa__details`, repeated detail pairs, `.coa__detail-label`, `.coa__detail-value`, `.coa__signature`, `.coa__qr`, verification image, and `.coa__verify`.
