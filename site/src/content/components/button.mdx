## Overview

The button is the foundation for all interactive actions in The Gallery. It comes in 5 variants × 3 sizes × 6 states, giving you full flexibility for any context.

<Preview html='<button class="btn">Primary</button> <button class="btn btn--secondary">Secondary</button> <button class="btn btn--outline">Outline</button> <button class="btn btn--link">Link</button> <button class="btn btn--danger">Danger</button>' label="All Variants" />

## Variants

### Primary

The default button. Use it for the main action on a page — "Add to Cart", "Checkout", "Submit".

<Preview html='<button class="btn">Primary Button</button>' label="Primary" />

### Secondary

For supporting actions that sit alongside a primary button.

<Preview html='<button class="btn btn--secondary">Secondary Button</button>' label="Secondary" />

### Outline

Lower visual weight. Good for filter toggles, secondary navigation, or when many buttons appear together.

<Preview html='<button class="btn btn--outline">Outline Button</button>' label="Outline" />

### Link

Renders as a text link with button semantics. Use sparingly — prefer actual `<a>` elements for navigation.

<Preview html='<button class="btn btn--link">Link Button</button>' label="Link" />

### Danger

For destructive actions: delete, remove, cancel order.

<Preview html='<button class="btn btn--danger">Danger Button</button>' label="Danger" />

## Sizes

<Preview html='<button class="btn btn--sm">Small</button> <button class="btn">Default</button> <button class="btn btn--lg">Large</button>' label="Sizes" />

| Class      | Use case                          |
|------------|-----------------------------------|
| `.btn--sm` | Inline actions, table rows        |
| *(default)*| Most buttons                      |
| `.btn--lg` | Hero CTAs, full-width mobile      |

## Usage Guidelines

<DoDont>
  <Do>Use one primary button per section to establish a clear action hierarchy.</Do>
  <Dont>Don't place multiple primary buttons side by side — demote one to secondary or outline.</Dont>
</DoDont>

<DoDont>
  <Do>Use the danger variant for destructive actions like "Delete" or "Remove".</Do>
  <Dont>Don't use danger for non-destructive actions — it creates unnecessary alarm.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Always provide visible text inside buttons. If using an icon-only button, add `aria-label` for screen readers.
</Callout>

- Buttons are focusable by default — don't override `tabindex` unless necessary.
- Use `<button>` for actions and `<a>` for navigation. Never use `<div>` with a click handler.
- Disabled buttons (`disabled` attribute) are excluded from the tab order automatically.
