## Overview

Countdown presents repeated time values and units in Default, Inline, or Cards treatments. Runtime calculation and expiration behavior are not defined by the source component.

Default uses `.countdown`; Inline adds `.countdown--inline` for compact value-and-unit rows; Cards adds `.countdown--cards` for padded segment surfaces. Optional separators remain visual content between repeated segments.

## Usage Guidelines

<DoDont>
  <Do>Use Countdown only after the consuming target defines a trustworthy deadline and what happens when it expires.</Do>
  <Dont>Do not infer target time, time zone, tick cadence, clock correction, synchronization, or expiration behavior from the preview.</Dont>
</DoDont>

The displayed values are documentation fixtures, not a running timer or component defaults.

## Accessibility

- Associate every value with a visible or programmatic unit label.
- Expose one concise complete time-remaining phrase when the visual segments would be verbose or ambiguous.
- Do not announce every tick through a live region.
- Communicate the accepted expiration behavior before treating the countdown as functional.
