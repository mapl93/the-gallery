## Presentation

The current page uses the neutral primary-action family. Available destinations remain quiet until hover or focus, ellipses are informational, and the finite list wraps when its container is narrow.

Item gap, page and ellipsis padding, current weight and directional icon size
are public tokens, alongside the existing palette, radius, type and control size.
The owner selected 18px icons in both Web and Shopify. SVG paths remain target
content; CSS tokens override intrinsic SVG dimensions. Link keeps its own focus,
underline and motion API. Page height is a minimum and grows with taller text.

Copy-and-own consumers explicitly adopt the CSS/token update. There is no new
page-window algorithm, variant or runtime. The Shopify icon default changes from
16px to the approved 18px; Web Studio retains its initial 18px.

## Usage Guidelines

<DoDont>
  <Do>Keep the current page and nearby destinations visible.</Do>
  <Dont>Do not render an ellipsis as a disabled link.</Dont>
</DoDont>

- Omit the unavailable directional destination at that boundary.
- Preserve collection filters and view mode when changing pages.
- Use target-native URLs so navigation still works without JavaScript.
- Let the target calculate the finite page window; CSS must not hide destinations.

## Accessibility

- Use a specifically named `<nav>` containing a native `ul`/`li` list.
- Use native anchors with `href` for every available destination.
- Mark exactly one non-interactive current page with `aria-current="page"`.
- Give icon-only previous and next links accessible names.
- Omit previous on the first page and next on the last page instead of leaving dead focus stops.
- Hide passive ellipses from assistive technology and never render them as links.
