## Overview

Search Overlay is a named modal search dialog with a visible title, canonical dismiss action, labelled native query field, and optional target-owned result content. It does not choose a search provider or imply combobox behavior.

## Presentation

The shared Exhibit/Studio renderer uses the same fixture and canonical implementation. Its documentation target demonstrates input focus on open, contained `Tab`, `Escape`, named Close Button dismissal, removal of closed focusables, and restoration to the trigger. Production targets still own background inertness, scroll locking, mutual exclusion, and lifecycle cleanup.

`title` names the modal from visible text and `dismissLabel` names its canonical Close Button. `inputLabel`, `query`, and optional `placeholder` map to the native search control. `results` is optional target-owned result, loading, empty, error, or status content. Endpoints, ranking, debounce, records, price formatting, and announcements are not defaults.

## Usage Guidelines

<DoDont>
  <Do>Keep the field label useful and let the target render truthful loading, empty, error, or result content.</Do>
  <Dont>Do not treat fixture products, prices, ranking, or query timing as Search Overlay API.</Dont>
</DoDont>

- Keep placeholder text supplemental to the accessible label.
- Use native lists and links for navigable results; compose the separate Combobox contract only when its interaction is genuinely required.
- Choose one query owner: controlled target state or intentionally initialized native state.
- Keep provider, cancellation, caching, and analytics policy in the consuming target.

## Accessibility

- Provide visible `title`, contextual `dismissLabel`, and native `inputLabel`; placeholder text does not replace either name.
- Expose `role="dialog"`, `aria-modal="true"`, and `aria-labelledby` only while interaction behind the overlay is actually blocked.
- Keep open presentation and accessible availability synchronized; closed content must not remain focusable.
- Move focus to the query, contain `Tab`, close on `Escape`, and restore focus logically.
- Announce changing result status only from truthful target-owned content; do not create an unconditional live region.
- Give informative result media useful alternative text; hide decorative thumbnails from assistive technology.
