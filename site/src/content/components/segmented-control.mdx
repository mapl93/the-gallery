## Overview

Inline radio-like control with sliding indicator.

## Presentation

Segmented Control supports `default`, `error`, `success`, and `warning` validation families independently of the selected option.

## Usage Guidelines

<DoDont>
  <Do>Always pair form inputs with visible labels for accessibility.</Do>
  <Dont>Don't rely on placeholder text as the only label — it disappears on input.</Dont>
</DoDont>

## Accessibility

<Callout type="tip">
  Segmented Control is backed by native radio inputs for mutually exclusive choices.
</Callout>

- Provide a group label with `fieldset`/`legend`, `aria-label`, or `aria-labelledby`.
- Keep checked state synchronized with the visible selected segment.
- Support keyboard navigation consistent with radio groups.
