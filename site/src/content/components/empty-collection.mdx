## Overview

Empty collection result with clear guidance and an optional recovery action.

## Presentation

The message remains centered and intentionally sparse. An optional passive icon may reinforce the state, while the recovery action uses the primary button family.

## Usage Guidelines

<DoDont>
  <Do>Explain why no results are visible and offer the most direct recovery.</Do>
  <Dont>Do not present an empty state when results are still loading.</Dont>
</DoDont>

- Tailor the guidance to filtered, searched, or genuinely empty inventory states.
- Use one primary recovery action.
- Remove the CTA when no honest recovery path exists.

## Accessibility

- Make the message understandable without the optional icon.
- Move focus only when the surrounding workflow explicitly requires it.
- Announce the transition to an empty result set when it follows an asynchronous action.
- Keep the recovery label specific to its effect.
