## Overview

Cart Note is a native disclosure for one target-owned order note. It composes a complete Textarea and leaves persistence, validation policy, and result feedback to the target.

## Presentation

`expanded` defaults to `false` and maps to the initial native `open` state. Static Web becomes uncontrolled after parsing; a stateful adapter may bind the live `open` property and `toggle` event. The required `field` slot composes one complete Textarea at `.cart-note__field`.

Cart Note owns only disclosure and target-persistence boundaries. Textarea owns the native value field, label, validation family, line bounds, and resize direction. Closing the disclosure hides but does not unmount the field, so its live value and control state remain intact.

## Usage Guidelines

<DoDont>
  <Do>Persist the note to the target cart after deliberate change or blur handling.</Do>
  <Dont>Do not use the note field for structured choices that deserve dedicated controls.</Dont>
</DoDont>

- Preserve the note value across cart quantity and totals updates.
- Keep the note value optional unless the surrounding flow explicitly establishes a requirement.
- Use Textarea properties for resize direction, line bounds, validation, and disabled state.

## Accessibility

- Use native `details` and a first-child `summary`; do not add duplicate disclosure ARIA to the native pair.
- Give the composed Textarea a visible label.
- Preserve Textarea keyboard, resize, validation, and feedback semantics.
- Do not discard entered content when the disclosure collapses.
- Keep the disclosure control keyboard reachable with visible focus.
