## Presentation

Review Card composes canonical Rating and never duplicates passive star markup
or reuses interactive Star Input. Optional photos are a labelled native list;
optional helpfulness uses a native toggle button with target-owned persistence;
an optional reply stays ordinary associated content inside the article.

## Usage Guidelines

<DoDont>
  <Do>Supply one coherent review record and compose canonical Rating for its read-only value.</Do>
  <Dont>Do not infer verification, calculate helpfulness, or create a hidden provider lifecycle inside the card.</Dont>
</DoDont>

## Accessibility

- Preserve logical author, date, Rating, title and body order.
- Supply machine-readable `datetime` independently from localized date text.
- Use a contextual heading rank for an optional review title.
- Associate helpfulness count with the native button when both exist; the count
  is not a live status.
- Photos are passive unless a target supplies a complete native link/button
  action with visible focus.

## References
