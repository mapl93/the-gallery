# The Gallery Shopify Target

Shopify is the first commercial platform target consuming the new token and adapter architecture.

Read `docs/adapters/shopify.md` before adding or changing Shopify sections, snippets, blocks, templates, settings, or adapter validation. Shopify target-ready means target-native: Liquid plus schema/settings/data/behavior/editor support where the component requires those platform surfaces.

Token flow:

```text
tokens/source/
  -> platforms/web/tokens.css
  -> platforms/shopify/assets/tokens.css
```

`platforms/shopify/assets/tokens.css` is generated by `scripts/build-shopify-tokens.js` from the neutral web target. Do not edit it directly.

## Commands

```sh
npm run build:tokens:shopify
npm run validate:tokens:shopify
npm run build:adapter:shopify
npm run validate:adapter:shopify
```

The wrapper validation checks that Shopify loads `tokens.css` before component CSS in both `theme.liquid` and `password.liquid`.

Component CSS assets are still copied from `components/css/` with:

```sh
npm run build:components
```

The Shopify adapter build refreshes the target-specific base layer, component CSS assets, shared JS, and adapter manifests:

```text
platforms/shopify/assets/base.css
platforms/shopify/assets/*.css
platforms/shopify/assets/theme.js
platforms/shopify/adapter.manifest.json
platforms/shopify/adapter.summary.json
```

`base.css` is generated from `components/css/reset.css`, `components/css/foundations.css`, and `components/css/utilities.css`. It must not define token values; token values belong in `tokens.css`.

`adapter.manifest.json` inventories every registry component against its contract, Shopify CSS output, detected Liquid selector usage, section/block schema, data mapping, template composition, editor-preview readiness, and computed Shopify maturity.

Shopify maturity is computed with `shopify-maturity-v1`:

- Every component requires a CSS output.
- Embedded class contracts can be target-ready without a dedicated Liquid root.
- Dedicated Shopify adapters need a section/snippet/template/layout root selector.
- Section and theme-block adapters need valid schema.
- Dedicated adapters need detectable Shopify data, settings, render, or section mapping.
- Section adapters need JSON template composition, a layout section call, or presets.
- Editor-preview readiness checks that schema controls are wired into Liquid.
- Behavior is accepted only when the Shopify contract status is `implemented`.

Current maturity warnings are expected while Shopify contracts are reconciled with existing Liquid. Warnings now focus on dedicated Shopify adapters whose Liquid/schema/data/editor evidence exists while contract status still says `planned`.

The legacy Style Dictionary build no longer writes Shopify tokens. Webflow and Framer remain on the legacy token build until they receive their own wrappers or source-token targets.
