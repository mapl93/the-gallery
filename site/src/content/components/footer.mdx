Footer closes the global site shell with required target-owned link groups and optional legal, locale, copyright, or brand metadata.

## Presentation

`.footer__grid` adapts the target-owned link groups from one column to the canonical wider layout. Each group may use `.footer__heading` and `.footer__links`; `.footer__bottom` is the optional metadata region.

Footer owns responsive composition and text treatment. CMS schemas, newsletter behavior, locale selection, legal revisions, consent, and external services remain target responsibilities.

## Usage Guidelines

<DoDont>
  <Do>Group destinations under clear headings and keep legal or locale metadata separate from navigation.</Do>
  <Dont>Do not make Footer the only route to critical support or account actions.</Dont>
</DoDont>

- Order groups by user need rather than by internal organization.
- Omit empty groups instead of rendering placeholder columns.
- Keep target-managed legal text current and readable.

## Accessibility

- Use labelled navigation regions for groups of footer links.
- Keep heading levels appropriate to the surrounding page hierarchy.
- Use descriptive link text and preserve visible keyboard focus.
- Ensure metadata remains readable at narrow widths and does not rely on visual position for meaning.
