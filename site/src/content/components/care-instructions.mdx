## Overview

Care Instructions groups concise, text-first guidance with optional supporting icons and recommended or discouraged emphasis.

## Presentation

`items` is required and `title` is optional. Each item requires a text label and can add explanatory detail or a supporting icon.

The default treatment is neutral. `do` maps to `.care-instructions--do` and `dont` maps to `.care-instructions--dont`; legacy item-level hooks remain implementation facts. Icons and color only support the written guidance.

## Guidelines

<DoDont>
  <Do>Write each instruction so its meaning is complete without an icon or color treatment.</Do>
  <Dont>Do not mix recommended and discouraged guidance under a root variant that implies one shared meaning.</Dont>
</DoDont>

- Use `do` for a set of recommended actions and `dont` for a set of discouraged actions.
- Keep explanations practical and specific to the target-provided care guidance.
- Use the neutral variant when the set contains informational instructions.

## Accessibility

- Express every instruction in text.
- Do not rely on success or error color to distinguish recommended and discouraged care.
- Hide decorative icons from assistive technology.
- Use a heading level appropriate to the surrounding document.

## Specification

**Dependencies:** None.

**Anatomy:** `.care-instructions`, optional title, required grid and repeated `.care-item` records with optional icon, required label, and optional description.
