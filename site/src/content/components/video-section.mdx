## Overview

Video Section is a passive media figure shell. It composes one required target-owned poster, native video, embed, or complete accessible player with an optional visible editorial caption. It does not implement or imply playback.

`contained` is the default padded presentation. `fullwidth` maps to `.video-section--fullwidth`. The private `16 / 9` wrapper is a visual candidate, not public player configuration.

## Usage Guidelines

<DoDont>
  <Do>Supply one complete target media composition and let that target own the entire accessible player lifecycle when the media is interactive.</Do>
  <Dont>Do not overlay a play icon or focusable control unless it invokes a real player and exposes its complete result.</Dont>
</DoDont>

Use the visible `figcaption` for editorial context. It does not replace synchronized captions, audio description, a transcript, or an accessible player for meaningful time-based media.

## Accessibility

- Give informative poster imagery contextual alternative text; use an empty alternative for decorative or redundant imagery.
- A passive poster has no tabindex, action role, cursor, control label, pressed state, or keyboard model.
- A target-native player owns keyboard controls, visible focus, labels, contrast, playback/loading/error state, autoplay policy, captions, descriptions, transcript, privacy/consent, events, and analytics.
- Prefer a native `<video controls>` or an established accessible player when the selected target profile supports it. Custom controls require complete player evidence.
- Omit the entire figure when required media is absent; omit only `figcaption` when the optional caption is empty.
