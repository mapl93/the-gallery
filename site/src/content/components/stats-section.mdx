## Overview

Stats Counter presents an ordered set of target-owned metric values and labels beneath an optional heading. Formatting, count-up calculation, live updates, and announcements remain target-owned.

The parent owns metric arrangement only. `data-animate` is an existing presentation hook, not a public animated state or evidence of count-up behavior.

## Usage Guidelines

<DoDont>
  <Do>Pair every value with a concise label and use target-appropriate number formatting.</Do>
  <Dont>Do not animate static fixture values or imply live data without a target-owned update model.</Dont>
</DoDont>

Keep the metric set comparable and avoid mixing unrelated units without enough context.

## Accessibility

- Keep each value and label adjacent in the reading order.
- Include units and qualifiers needed to understand the value.
- Do not announce every animation frame; targets that update live values must define appropriate live-region behavior.
- Respect reduced-motion preferences when a target implements count-up transitions.
