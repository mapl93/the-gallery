## Presentation

The required `items` slot contains ordered `.masonry-gallery__item` records. Each record requires a `.gallery-piece` and image; overlay, title, and price regions are optional. The gallery grows from one to three columns as space allows.

The artwork intentionally uses passive figures. ADR 0080 leaves activation unresolved: a target may later choose passive pieces, native links, Lightbox triggers, or more than one target-specific mode. Overlay metadata remains visible for non-hover inputs and may disclose on focus only when target-owned interaction exists.

## Usage Guidelines

<DoDont>
  <Do>Keep artwork items in a meaningful source order and let their natural proportions shape the columns.</Do>
  <Dont>Do not assume that every gallery piece opens a link or Lightbox.</Dont>
</DoDont>

- Use concise overlay metadata that does not replace the image description.
- Choose title and price content according to target data policy.
- Add native interactive markup only after the target activation mode is decided.

## Accessibility

- Give every meaningful artwork image useful alternative text and mark decorative images accordingly.
- Keep overlay title and price available without hover-only interaction.
- If a target makes a piece interactive, use native link or button semantics with an accessible name and visible focus.
- Preserve source order across responsive column changes and do not rely on image scale motion to communicate activation.

## References

**Dependencies:** None. Lightbox is not a dependency while activation remains unresolved.

**Anatomy:** required `.masonry-gallery` root, `.masonry-gallery__item`, `.gallery-piece`, and piece image; optional `.gallery-piece__overlay`, `.gallery-piece__title`, and `.gallery-piece__price`.
