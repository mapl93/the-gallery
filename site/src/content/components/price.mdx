## Overview

Price is a passive commerce primitive for one complete target-formatted current
price with optional compare-at and unit-price content. It owns readable anatomy,
semantic compare-at markup, bidirectional isolation, and typography; the target
owns money data, locale, currency, rounding, ranges, tax copy, selling plans,
discount truth, live updates, and structured commerce data.

## Presentation

Price has one container-responsive size. Default is classless and presents the
current value plus optional unit price. `on-sale` adds `.price--on-sale` and is
coherent only when the target supplies both a current value and a valid
compare-at value. Discount is not an Error state and does not use feedback color.

| Property | Value | Web mapping |
| --- | --- | --- |
| `variant` | `default` | `.price` |
| `variant` | `on-sale` | `.price.price--on-sale` |
| `currentPrice` | formatted string | `.price__current .price__value` content |
| `compareAtPrice` | formatted string | `.price__compare .price__value` content |
| `unitPrice` | formatted string | `.price__unit .price__value` content |
| part labels | localized strings | `.price__label` DOM content |

The current value uses the primary H4 hierarchy. Compare-at uses body type and a
native `<s>`; unit price uses body-small type. Supporting content uses the
secondary text family rather than disabled text. All parts wrap when their
container narrows; formatted values use `<bdi>` so symbols, ISO codes, and digits
remain isolated inside surrounding LTR or RTL copy.

### OpenType Features

ADR 0061 keeps five independent typography capabilities. Inter-oriented defaults
enable tabular numbers, slashed zero, and contextual alternates; alternate digits
and automatic fractions are opt-in. Unsupported features are ignored by the
active font without changing the text.

| Property | Default | Web attribute | OpenType |
| --- | --- | --- | --- |
| `alternateDigits` | `false` | `data-price-alternate-digits` | `ss01` |
| `slashedZero` | `true` | `data-price-slashed-zero` | `zero` |
| `tabularNumbers` | `true` | `data-price-tabular-numbers` | `tnum` |
| `contextualAlternates` | `true` | `data-price-contextual-alternates` | `calt` |
| `fractions` | `false` | `data-price-fractions` | `frac` |

## Usage Guidelines

<DoDont>
  <Do>Pass complete locale-aware strings from the target formatter or commerce platform.</Do>
  <Dont>Do not pass raw amounts and expect Price to choose currency, rounding, separators, or tax policy.</Dont>
</DoDont>

<DoDont>
  <Do>Supply localized Regular price and Sale price labels when compare-at content renders.</Do>
  <Dont>Do not rely on line-through, color, or DOM order alone to explain a discount.</Dont>
</DoDont>

<DoDont>
  <Do>Let a changing Product or Cart region own any deliberate price-update announcement.</Do>
  <Dont>Do not give every static Price `role="status"` or component-owned live behavior.</Dont>
</DoDont>

- Use `currentPrice` for complete truthful text such as `$120.00`, `From $120`,
  `$120–$160`, or localized Free/Unavailable wording supplied by the target.
- Render compare-at only with `on-sale` after the target verifies the relationship.
- Pass one complete unit-price expression; do not split its amount, reference
  value, unit, or separator inside the neutral component API.
- Compose Sale/Sold out Badge, financing, subscription, taxes, duties, deposits,
  tier tables, and currency controls outside Price.

## Accessibility

<Callout type="info">
  Price is ordinary readable content, not a widget. The root has no group, focus,
  keyboard, status, or live-region semantics.
</Callout>

- Use native `<s>` for the no-longer-current compare-at value.
- Include localized part labels in DOM content so sale and unit meaning remains
  available without an aggregate ARIA name.
- Keep the payable value visible and text-based; never communicate it only through
  an image, badge, color, or generated decoration.
- Isolate each formatted value with `<bdi>` and preserve the surrounding label's
  language direction.
- The parent target decides whether an interaction-caused price change warrants a
  polite status update and avoids duplicate announcements.
- Preserve complete market-specific currency, unit, tax, and legal wording.

## Specification

| Prop / class | Type | Default | Description |
| --- | --- | --- | --- |
| `currentPrice` | string | required | Complete target-formatted payable price or truthful price text |
| `currentPriceLabel` | string | none | Localized Price or Sale price label; provide for on-sale |
| `compareAtPrice` | string | none | Optional target-formatted previous price used with on-sale |
| `compareAtPriceLabel` | string | none | Localized Regular price label required when compare-at renders |
| `unitPrice` | string | none | Optional complete target-formatted unit-price expression |
| `unitPriceLabel` | string | none | Localized Unit price label recommended with unit content |
| `variant` | enum | `default` | `default` or target-validated `on-sale` |
| `alternateDigits` | boolean | `false` | Enables `ss01` when supported |
| `slashedZero` | boolean | `true` | Enables slashed zero when supported |
| `tabularNumbers` | boolean | `true` | Enables tabular numeric widths when supported |
| `contextualAlternates` | boolean | `true` | Enables contextual alternates when supported |
| `fractions` | boolean | `false` | Enables automatic fractions only for intentional notation |

Required anatomy is `.price > .price__current` with one `.price__value`.
`.price__compare` is a native `<s>` and appears only for coherent on-sale content;
`.price__unit` is optional. Each rendered part may contain one localized
`.price__label` before its isolated value.
