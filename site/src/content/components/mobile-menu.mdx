## Overview

Mobile Menu is a direct-link site navigation list composed inside canonical Drawer. It owns only list-and-link presentation; Drawer owns modal lifecycle and the target owns destinations.

## Presentation

`items` supplies one or more required `.mobile-nav__item` entries with native `.mobile-nav__link` destinations. Dividers, semantic body typography, touch targets, focus treatment, long-label containment, and a contrast-safe current-page underline are canonical presentation.

The shared Exhibit/Studio artwork composes the list inside the real canonical left Drawer and Close Button. Its documentation target demonstrates focus entry, contained `Tab`, `Escape`, removal of closed focusables, and focus restoration; these are inherited Drawer behavior, not duplicate Mobile Menu properties.

## Usage Guidelines

<DoDont>
  <Do>Keep mobile destinations aligned with the target's navigation model and expose the current page.</Do>
  <Dont>Do not duplicate Drawer visibility or dismissal behavior inside Mobile Menu.</Dont>
</DoDont>

- Supply direct destinations, labels, and order from target navigation data.
- Keep labels concise enough to scan while allowing them to wrap safely.
- Resolve nested disclosure navigation, successful-navigation closing, and breakpoint policy in the consuming target.

## Accessibility

- Place the native list inside a labelled `nav` region and canonical modal Drawer.
- Use native links with valid destinations and `aria-current="page"` when applicable.
- Do not apply `menu`, `menuitem`, `menubar`, roving focus, or application-style arrow-key interaction to ordinary site navigation.
- Preserve Drawer focus entry, containment, `Escape`, named dismissal, background inertness, and restoration.
- Ensure navigation remains usable by keyboard, touch, reduced-motion, and forced-colors users.
