## Overview

Cart Summary presents target-owned totals and the primary checkout handoff. It supports an optional expectation note and optional target-native express checkout actions.

## Presentation

`rows` is a required slot for subtotal, shipping, discounts, taxes, and total. The total row may use `.cart-summary__row--total` for emphasis, while each target-formatted amount uses `.cart-summary__value`.

The checkout button is required. `checkoutDisabled` represents a temporarily unavailable cart state; optional express actions compose in their own region without replacing the primary handoff.

## Usage Guidelines

<DoDont>
  <Do>Derive every displayed amount and checkout state from the same commerce snapshot.</Do>
  <Dont>Do not estimate taxes, discounts, or shipping in the component presentation.</Dont>
</DoDont>

- Keep the total visually distinct from supporting rows.
- Use `note` for concise checkout expectations, not policy-length content.
- Explain unavailable checkout state in surrounding content when disabling the action.

## Accessibility

- Use readable labels for every subtotal, discount, tax, shipping, and total value.
- Keep row labels and values in a logical reading order.
- Ensure the checkout action remains keyboard reachable after totals update.
- Do not rely on sticky positioning as the only path to checkout.
- Give target-native express actions distinct accessible names.
