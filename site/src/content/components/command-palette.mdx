visible dismissal, and target-owned filtering and execution.

## Usage Guidelines

<DoDont>
  <Do>Use command palette for global commands, search, and fast navigation.</Do>
  <Dont>Don't hide essential navigation or destructive actions only inside the command palette.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Command Palette composes canonical Modal and Close Button presentation. The
  target owns modality, shortcut scope, filtering, active-descendant focus,
  announcements, restoration, and command execution.
</Callout>

- Focus the named search input on open; keep result options outside the page Tab sequence.
- Trap Tab among modal controls, close through the visible button or `Escape`, and restore logical prior focus.
- Keep one enabled command synchronized with `aria-activedescendant`; support arrows, Home, End, and Enter.
- Preserve native text editing and IME composition. Do not nest interactive controls inside an option.

## Visual Customization

Fifty-seven public roles cover the command surface and the Modal values it actually consumes. Twenty-nine source values expose its own geometry. Top inset is the smaller of 20vh and 4rem; panel maximum width starts at 35rem. Panel, search-divider and footer-divider borders each start at 1px and can change independently. Modal still owns overlay tint/opacity, side/bottom inset factor, viewport height bound and panel entrance movement. Close Button keeps its own component API; command results and search use this component's canonical anatomy.

Search gap/block-padding/inline-padding factors start at 0.5/0.75/1, search icon at 1.25rem and shared focus width at 2px. Results have a 20rem maximum height and padding factor 0.25. Group top/inline/bottom padding factors are 0.5/0.75/0.25, tracking 0.05em and weight shared semibold. Result gap factor is 0.625, minimum height 2.5rem, block/inline padding factors 0.5/0.75, transparent border 1px, focus inset 2px and icon 1rem. Shortcut extra-gap factor is 0.5, empty padding factor 1.5, and footer gap/block/inline padding factors 0.5/0.5/1.

Factors retain the responsive spacing base; coarse input respects the larger of custom result minimum and shared touch target. Results scroll inside the Modal height bound. Search focus uses its token-sized inset shadow normally and a system-color inset outline in forced colors, where shadows are suppressed. The option focus style does not change active-descendant behavior or add options to Tab order. Query, filtering, disabled commands, announcements, command execution and shortcut scope remain target-owned. User-customized tokens still need contextual accessibility review.
