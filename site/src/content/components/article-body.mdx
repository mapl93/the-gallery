## Overview

Article Body is the article-specific consumer of the reusable Foundations
`.prose` style contract. Its passive, non-landmark `.article-body.prose` root
presents one required block of target-owned semantic long-form content and may
extend it with an optional drop cap, authored pull quotes, passive callouts,
media collections, named local overflow, and canonical commerce islands.

Foundations is the sole owner of generic Prose typography and semantic-element
styles. L3 does not parse content, become the surrounding `article`, or copy
the markup or behavior of child components.

The only root presentation property is `dropCap`. It adds
`.article-body--drop-cap` to the `.article-body.prose` root, affects the first
letter of the first direct paragraph, and returns to ordinary text in very
narrow containers. All authored rich nodes remain inside the required
`content` slot.

Use `.prose__overflow.article-body__overflow` only as an explicitly named,
keyboard-focusable wrapper around code or genuinely two-dimensional data that
cannot reflow. Ordinary paragraphs, links, headings, lists, figures, callouts,
and media collections remain in normal flow; neither Prose nor the page becomes
a horizontal scroll region.

## Usage Guidelines

<DoDont>
  <Do>Supply complete native semantic content in document order, use Article Body BEM extensions, and compose canonical child components inside `.prose-excluded`.</Do>
  <Dont>Do not duplicate generic Prose rules, infer heading ranks, put attribution inside `blockquote`, assign alert semantics to static guidance, or emulate page-wide breakout inside Prose.</Dont>
</DoDont>

- The target owns authoring, trust and sanitization, localization, link policy,
  image meaning and delivery, heading hierarchy, table relationships, code
  language, publishing, SEO, and analytics.
- `.article-body__pull-quote` is an authored `figure` containing `blockquote`
  and optional `.article-body__pull-quote-attribution` `figcaption`. A nested
  `cite` identifies a cited work, not a person's name.
- `.article-body__callout` remains ordinary grouped content. Compose canonical
  Alert only when timing or importance truthfully requires alert or status
  semantics.
- Commerce in the article flow uses
  `.prose-excluded.article-body__commerce-island` and canonical Product Card
  and Price. Article Body owns neither product markup nor price formatting.
- Genuinely full-bleed media belongs to host layout outside `.prose`; neither
  Foundations Prose nor L3 exposes a viewport-breakout hook.
- Legacy `.pull-quote`, `.pull-quote__attribution`, `.callout`,
  `.callout__icon`, and callout-variant aliases remain for one pre-v1 migration
  cycle. New markup uses Article Body BEM parts; remove the aliases before the
  public v1 contract freezes.

L3 owns no parser, editor, CMS schema, syntax highlighter, reading-time
calculation, observer, event handler, controlled/uncontrolled state, asset, or
neutral JavaScript.

## Accessibility

- Preserve contextual heading ranks, native list/figure/pre/code/table
  structure, captions, and header/data-cell relationships.
- Keep quote attribution outside `blockquote`; associate pull-quote attribution
  through `figure` and `figcaption`.
- Give informative media useful contextual alternative text and decorative
  media an empty alternative; captions do not replace required alt text.
- Name every local overflow region and make it keyboard focusable only when
  wide code or two-dimensional data needs scrolling.
- Keep authored callouts passive and canonical child components outside Prose
  descendant styling through the explicit exclusion boundary.
- Preserve visible focus for links and local overflow, logical RTL flow,
  320-CSS-pixel reflow, effective 200-percent text, user text spacing, forced
  colors, and zero authored motion.
- Omit the complete root when semantic content is absent; do not emit an empty
  article landmark or use a drop cap as content.
