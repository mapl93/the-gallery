## Overview

The product card is the primary way to display items in collection grids and related product sections. It combines passive media, a close artist-and-piece identity, a two-line description, pricing, and an optional compact Quick Look overlay.

### Usage in Grids

Product cards are designed to work inside CSS Grid layouts. The card is fully fluid — it fills its grid cell width.
Badge, text, Price, Quick Look, and optional footer actions share the same compact
logical inset so the complete composition aligns as one column in either text
direction.
Every card in one grid, slider, recommendation surface, or saved-product list
should receive the same `mediaRatio` value so rows remain aligned. `square`
maps to 1:1 and `portrait` maps to the established 3:4 portrait proportion;
arbitrary numeric ratios are intentionally not part of the public API.

```html
<div class="collection-grid">
  <article class="card product-card">…</article>
  <article class="card product-card">…</article>
  <article class="card product-card">…</article>
</div>
```

<Callout type="tip">
  The card image uses `object-fit: cover` and a subtle scale transform on hover. No extra JS needed for the hover zoom effect — it's pure CSS.
</Callout>

## Usage Guidelines

<DoDont>
  <Do>Keep artist and piece name close, separate the optional two-line description and Price, and place one compact Quick Look action over the media.</Do>
  <Dont>Don't place complete Product Form controls or multiple competing actions directly on the card.</Dont>
</DoDont>

<DoDont>
  <Do>Use consistent image aspect ratios across all cards in a grid.</Do>
  <Dont>Don't mix landscape and portrait images in the same collection grid.</Dont>
</DoDont>

## Accessibility

Public tokens retain the approved shared inset across badges, content, Price,
Quick Look and footer. Identity gap plus Description additional gap controls the
title-to-description separation; artist and description size factors use Body
size base. Card owns the reused surface, border, radius and media hover scale.
The parent owns card width. Square/portrait proportions and the two-line
description remain semantic contract decisions. Reduced motion disables image
scaling as well as transitions. Child Button, Badge and Price APIs remain in
their own references.

- Use one descriptive product-title link as the navigation target and keep media passive; do not add a redundant image link.
- Treat the artist name as optional presentation. Hiding it must not remove the title or the required Price.
- Give the primary image descriptive alternative text when it adds information. Alternate hover imagery for the same product uses empty alternative text.
- Keep Quick Look above the stretched title-link hit area. Reveal it on fine-pointer hover or focus-within, keep it visible on coarse/no-hover input, and include the product name in its accessible name when cards repeat.
- Preserve the complete description in DOM content even though CSS shows at most two lines; Quick View or product detail provides the complete reading context.
- Preserve the card-sized title focus indicator and reduced-motion behavior from canonical CSS.
