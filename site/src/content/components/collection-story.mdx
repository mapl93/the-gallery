## Overview

Collection Story pairs optional media with a required editorial title and narrative, plus optional label, inspiration quotation, and target-owned actions.

## Presentation

The default layout stacks into one column and becomes two columns at wider viewports. `title` and `body` are required; `media`, `label`, `inspiration`, and `actions` are optional target-owned content.

`reversed` defaults to `false`. When enabled, `.collection-story--reversed` places media after narrative content at wider viewports without changing source order. Reversal is a layout property, not a state or registry variant.

## Usage Guidelines

<DoDont>
  <Do>Keep the source in meaningful media-then-narrative order even when using the reversed layout.</Do>
  <Dont>Do not treat reversal as a content change or interaction state.</Dont>
</DoDont>

- Use one focused collection narrative rather than a list of product facts.
- Keep the inspiration quotation subordinate to the main body.
- Compose actions whose destinations are owned by the target.

## Accessibility

- Use a heading level appropriate to the surrounding page for the collection title.
- Give meaningful collection media useful alternative text and mark decorative media accordingly.
- Use quotation markup for the inspiration text when it is a quotation.
- Preserve source reading order when `reversed` changes only wide-viewport placement.
