## Overview

Blog Sidebar is one passive named complementary container for target-authored modules. It requires a useful accessible label and non-empty semantic sections; missing either omits the complete `aside` instead of leaving an unnamed or empty landmark. The initial v1 profile contains Recent Articles and Topics as native Link lists.

The component has one intrinsic stacked presentation. `.blog-sidebar__section` repeats inside the root. Recent Article links use `.blog-sidebar__list`; Topic links use `.blog-sidebar__topics`. The legacy `.tag-cloud*` selectors remain temporary migration aliases on the same native list elements and do not define public identity or compose Tag; they must be removed before the v1 contract freezes.

## Usage Guidelines

<DoDont>
  <Do>Use L8 only when the complete composition supports but remains separate from the surrounding main content.</Do>
  <Dont>Do not turn its root into a search engine, filter controller, sticky rail, or API for every possible editorial module.</Dont>
</DoDont>

The target owns module order, limits, contextual heading ranks, content, routes, data, localization, and integration. Search appears only when a real target owner supplies its native search landmark, canonical Form, field semantics, Input, Button, query and result lifecycle. Newsletter and Search stay separate canonical or target compositions, not root booleans. Those modules keep their complete behavior and do not change L8's passive root contract.

## Accessibility

- Require a non-empty localized `label` and non-empty `sections`; omit the complete root when either is absent.
- Use the native `aside` only for genuinely complementary content, and distinguish repeated complementary landmarks with useful names.
- Give each thematic section a visible contextual heading and preserve native `ul`/`li` structure for grouped destinations.
- Use canonical anchors with `href` for navigation. Tag remains a passive/removable value label and is not placed on an anchor.
- Preserve canonical Link focus, hover, forced-color, reduced-motion, and complete-label behavior.
- Keep the layout intrinsic and logically reflowing; page columns, sticky placement, responsive order, hiding, and collapse remain host responsibilities.
