## Usage Guidelines

<DoDont>
  <Do>Use the collection title as the primary identity signal for the page.</Do>
  <Dont>Do not use image-backed presentation when the media cannot support readable text.</Dont>
</DoDont>

- Keep the description curatorial and concise.
- Format the count through the target commerce layer.
- Treat decorative media as empty-alt content; provide useful alternative text when it carries meaning.

## Accessibility

- Use the page-appropriate heading level for the collection title.
- Ensure image-backed text maintains sufficient contrast in every theme.
- Do not make the product count the only way collection size is communicated after filtering.
