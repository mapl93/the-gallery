## Overview

Passive aggregate rating and review count with an optional target-supplied
distribution. Review Summary composes canonical Rating; it owns no aggregation,
normalization, provider, filtering or live-update service.

## Presentation

The exact aggregate and canonical star projection are explicit inputs.
`ratingValue`/`scoreLabel` may preserve a provider value such as `4.6`, while
`ratingDisplayValue` must be the target-selected half-step passed to Rating.
Neutral code never silently rounds one into the other. `ratingLabel` must agree
with that star projection.

The optional distribution is a labelled native list. Every visual bar has
visible bucket and count text; targets supply widths and records.

## Usage Guidelines

<DoDont>
  <Do>Supply exact aggregate, half-step star projection, localized labels, count, and optional distribution as one coherent snapshot.</Do>
  <Dont>Do not calculate aggregates, infer bucket widths, or announce provider updates inside Review Summary.</Dont>
</DoDont>

## Accessibility

- The visible score is hidden from the accessibility tree because canonical
  Rating owns the equivalent target-projected value and scale once.
- Keep the review count as readable visible text.
- Name the optional native distribution list and retain text equivalents for
  every bar.
- The entire component is passive, unfocusable and non-live.
