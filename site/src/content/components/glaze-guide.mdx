## Overview

Glaze Guide presents named glaze samples in a responsive grid and can include target-owned detail content without defining a selection model.

## Presentation

The required `swatches` slot owns target-provided samples. A title and a `.glaze-detail` region with image, text, name, and metadata are optional.

The artwork keeps samples passive. The existing selected-state selector is only a visual hook; targets decide whether samples are passive or selectable and own selection, keyboard behavior, detail synchronization, and announcements.

## Guidelines

<DoDont>
  <Do>Pair every visual sample with a concise glaze name and useful target-formatted code when available.</Do>
  <Dont>Do not infer selectable behavior or a glaze data schema from the grid and detail selectors.</Dont>
</DoDont>

- Keep target-owned glaze records and ordering consistent within a composition.
- Add detail content only when the target can keep it synchronized with any selected sample.
- Treat visual color as supporting information rather than the record identity.

## Accessibility

- Keep every glaze name available as text rather than color alone.
- Give informative glaze imagery useful alternative text.
- If samples become interactive, use a coherent native or ARIA selection pattern with visible focus.
- Announce target-owned detail changes when selection updates content outside the control.

## Specification

**Dependencies:** None.

**Anatomy:** `.glaze-guide`, optional header and title, required grid and repeated swatches with visual and name, optional code, and optional `.glaze-detail` image, information, name, and metadata.
