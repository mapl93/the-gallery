## Deprecated identity

Popup (`G4`) is deprecated as an independent component. The owner-selected
direction consolidates it into canonical [Popover](/components/popover): a
non-modal floating surface anchored to the element that opened it.

This migration page renders the exact same Popover renderer, fixture and CSS as
B9. It owns no backdrop, modal semantics, Close Button duplication, Split or
Slide variants, visibility runtime, Studio implementation or Shopify adapter.

## Migration

- `.popup-overlay`, `.popup`, `.popup__*`, `.popup--split` and `.popup--slide`
  are removed from canonical source.
- Use `.popover`, optional `.popover__arrow` / `.popover__title`, required
  `.popover__content`, and the canonical `open` state.
- Connect a native Button trigger with `aria-expanded` / `aria-controls`, or use
  the native Web Popover relationship in a capable target.
- Preserve Escape, outside and repeated-trigger dismissal, natural Tab order
  and keyboard focus restoration.

## Modal marketing campaigns

Marketing content can live inside Popover when it is concise, anchored and
non-modal. If a campaign must block page interaction, dim the background,
contain focus or require an explicit decision, compose canonical
[Modal](/components/modal). That is a recipe choice, not a reason to restore G4.

The temporary G4 contract mirrors only canonical `open` so existing references
can be found and migrated. Its status is `deprecated`, never `stable`.
