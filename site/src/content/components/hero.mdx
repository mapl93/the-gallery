## Overview

Hero Banner presents a prominent page introduction with optional media, a contrast overlay, supporting copy, and Button-composed actions.

The root owns containment, vertical alignment, and responsive minimum height. Media and overlay are optional layers; content remains foregrounded, and actions compose Button without changing its native link or button semantics.

## Usage Guidelines

<DoDont>
  <Do>Use one clear heading and a focused action group that matches the page's primary purpose.</Do>
  <Dont>Do not rely on the media layer to communicate information that is absent from the visible copy.</Dont>
</DoDont>

Choose whether media is informative or decorative in the consuming target. Add the overlay only when it is needed to maintain readable contrast.

## Accessibility

- Use a heading level appropriate to the surrounding page hierarchy.
- Give informative images alternative text and equivalent visible meaning; hide decorative media from assistive technology.
- Verify text contrast against every selected image or video frame.
- Preserve native link or button semantics for each composed Button action.
