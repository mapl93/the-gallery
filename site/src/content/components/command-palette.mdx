## Usage Guidelines

<DoDont>
  <Do>Use command palette for global commands, search, and fast navigation.</Do>
  <Dont>Don't hide essential navigation or destructive actions only inside the command palette.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  The CSS adapter handles the visual overlay; the target owns shortcut handling, filtering, highlighted result state, and command execution.
</Callout>

- Trap focus inside the overlay while open. Return focus to the trigger on close.
- Close on `Escape` key press.
- Focus the search input when the palette opens.
- Keep the highlighted command synchronized with `aria-activedescendant` or the target's equivalent native pattern.
