## Usage Guidelines

<DoDont>
  <Do>Use this component consistently across your theme for a cohesive UI.</Do>

</DoDont>

## Accessibility

<Callout type="info">
  Primitive components are building blocks. They're referenced by higher-level components throughout the system.
</Callout>

- Use `aria-live="polite"` or `role="status"` so screen readers announce loading state.
