## Overview

Determinate bar or circle that represents a known value, plus an indeterminate bar for unknown completion.

## Presentation

Bar and Circle are structural variants. Indeterminate is an orthogonal boolean state available only for Bar and omits `aria-valuenow`.

## Usage Guidelines

<DoDont><Do>Use determinate progress when the target can calculate a meaningful range.</Do><Dont>Do not show a fabricated percentage when completion is unknown.</Dont></DoDont>

Targets own calculations and localized value content. The component owns presentation and progressbar semantics.

Targets must keep `max` greater than `min` and clamp the current value into that range. Studio repairs an invalid edited range atomically so its preview never retains a stale fill. Enabling Indeterminate selects Bar; selecting Circle clears Indeterminate.

`displayValue` is optional, visible, and intentionally compact for either Bar or the fixed-size Circle. `valueText` is independently optional and maps only to `aria-valuetext`, so it can carry a complete localized description. Neither falls back to, copies, truncates, scales, or derives from the other.

## Accessibility

- Provide a non-empty accessible operation label and meaningful finite min/max/value attributes. Invalid required composition emits no Progress root.
- Omit `aria-valuenow`, `aria-valuetext`, and visible value text while indeterminate; do not announce every small update.
- Use `aria-valuetext` when a localized phrase is clearer than the raw number.
- Neutral web removes transitions and indeterminate animation under reduced motion.
