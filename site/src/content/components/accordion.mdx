## Overview

Accordion is a vertical group of related disclosure items. Every item combines a
contextual heading, a native trigger, and one panel that is truly hidden while
collapsed.

## Usage Guidelines

<DoDont>
  <Do>Use Accordion to make related secondary sections scannable while preserving their heading structure.</Do>
  <Dont>Don't conceal information that users must see to continue, or use visual-only height collapse for interactive content.</Dont>
</DoDont>

Consumers choose the heading rank and coordinate independent, single-open, or
at-least-one-open group policy. The neutral item contract does not freeze a
framework value shape. A web target may use the APG Button pattern shown here or
map the same content to native `details`/`summary`.

## Accessibility

<Callout type="warning">
  `aria-expanded`, `aria-controls`, stable ids, and native `hidden` panel state
  must change together.
</Callout>

- Make the native trigger the only child of a heading whose rank fits the page.
- Click, Enter, and Space work through the native Button; keep normal Tab order.
- Hidden panels and their controls must not remain rendered or focusable.
- Add a labelled `region` only when the panel is structurally important; avoid
  creating many redundant landmarks.
- A disabled item remains perceivable but cannot change state.

## Visual Customization

Twenty-eight public roles cover appearance and geometry. Outer border and item dividers start at 1px and are independently editable. The indicator starts at 1.25em of trigger text; its size token changes the box while the target owns artwork. Trigger weight reuses semibold. Gap, block padding and inline padding start at 0.5, 0.6667 and 1 times the responsive spacing base. Content has independent top/inline/bottom factors of 0, 1 and 0.6667. The existing approximation is preserved; no new responsive size mode is introduced.

Keyboard focus width and inward offset start at 2px; the inset token is positive and CSS applies its negative offset. The shared minimum target still bounds trigger height. Header resets, native hidden panels, decorative 180-degree indicator rotation, parent-owned external spacing, state and item/group semantics remain separate from visual customization. Hover applies to enabled triggers whether their panel is open or closed.
