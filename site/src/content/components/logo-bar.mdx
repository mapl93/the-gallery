## Overview

Logo Bar presents one ordered collection of target-owned logos or trust marks. It defaults to a static wrapping list and may explicitly compose canonical Marquee when continuous presentation is useful.

`static` is the default and performs no component runtime work. `marquee` keeps the same source list and delegates motion, one inert visual copy, logical direction, semantic pace, Pause/Resume, focus and hover suspension, hidden-page suspension, reduced motion and no-JavaScript fallback to canonical Marquee.

## Usage Guidelines

<DoDont>
  <Do>Keep marks in meaningful source order, verify every claim, and use a native link only when a mark has a real destination.</Do>
  <Dont>Do not recolor arbitrary brand assets, fabricate alternative text, or use moving logos as the sole source of critical information.</Dont>
</DoDont>

Assets, truthful alternative text, destinations, analytics and brand permissions remain target-owned. Dimensions, gaps, wrapping and color treatment are private composition details pending human review.

## Accessibility

- Name informative marks for the represented entity; hide purely decorative marks from assistive technology.
- Give functional linked marks a useful destination name and visible keyboard focus.
- Keep generated marquee copies `aria-hidden`, inert and outside focus navigation.
- Use localized Pause and Resume labels in marquee mode; reduced motion and missing JavaScript remain readable and static.
- Omit the root when no valid marks exist; a one-mark marquee request falls back to static.
