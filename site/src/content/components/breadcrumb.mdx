## Usage Guidelines

<DoDont>
  <Do>Use breadcrumbs when hierarchy helps people understand where the current page sits.</Do>
  <Dont>Don't use a breadcrumb as a substitute for primary navigation or browsing history.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Breadcrumb is navigation, not decoration. Keep the current page marked and hide visual separators from assistive technology.
</Callout>

- Use `<nav>` with `aria-label` to identify the navigation region.
- Use an ordered list so the hierarchy and item count remain programmatic.
- Mark the current page with `aria-current="page"`.
- Keep labels ordered from broadest to current page.
- Keep the complete path available when labels wrap; truncation and responsive collapse are target decisions.
