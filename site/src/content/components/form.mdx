## Usage Guidelines

<DoDont>
  <Do>Keep source, reading, visual, and keyboard order aligned across responsive columns.</Do>
  <Dont>Don't disable native validation unless the target owns a complete accessible replacement.</Dont>
</DoDont>

## Accessibility

- Preserve native form submission semantics when the target supports them.
- Use explicit button types for submit, reset, and secondary actions.
- Announce error summaries and link entries to the relevant invalid fields.
- Keep responsive columns from changing source or tab order.
