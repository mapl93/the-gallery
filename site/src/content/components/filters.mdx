## Presentation

The component owns collection-level layout only. Checkbox, Radio, and Tag dependencies retain their own selection, keyboard, validation, and removal semantics.

## Usage Guidelines

<DoDont>
  <Do>Expose active filters where they can be removed independently.</Do>
  <Dont>Do not clear unrelated selections when one active filter is removed.</Dont>
</DoDont>

- Keep labels aligned with the language used in product data.
- Use a sidebar only when the available width leaves enough room for results.
- Preserve filter state when view mode or pagination changes.

## Accessibility

- Group related controls with visible labels or fieldset and legend semantics.
- Preserve focus when active tags are added or removed.
- Announce result-count changes after asynchronous updates.
- Interactive filter titles require native button semantics and visible focus.
