## Presentation

The root responds to its own inline size. It uses one column in unusually constrained embeds, two at the base width, three at the intermediate threshold, and four in wide containers by default. All four counts are public tokens. The existing `--grid-columns` name controls the wide band and defaults to four; it now aliases the component role rather than the general twelve-column layout grid.

## Usage Guidelines

Use `--grid-collection-grid-constrained-columns` below 20rem,
`--grid-collection-grid-base-columns` from 20rem,
`--grid-collection-grid-intermediate-columns` from 48rem, and `--grid-columns`
from 64rem. Thresholds use the component container; there is one shared CSS
track formula. Tokens contain positive integer counts. CSS math protects the
minimum of one track and applies its native integer rounding to fractional
consumer overrides; no neutral upper ceiling is imposed.

For existing copies, `data-columns="2"` through `"6"` remains a Web compatibility
override for the wide band and takes precedence over the token. Remove that
attribute when adopting token ownership. Existing inline or inherited
`--grid-columns` customizations still work. Without an override, wide density is
now the documented four rather than the unrelated twelve-column grid alias.
Product Card retains its own complete API. Copy-and-own consumers explicitly
adopt this source/token update; they are not changed remotely.

<DoDont>
  <Do>Keep Product Card children in stable collection order.</Do>
  <Dont>Do not mix manual floats or absolute positioning into the grid.</Dont>
</DoDont>

- Use consistent media aspect ratios across sibling cards.
- Choose a wide-container column count that preserves readable titles and prices.
- Let pagination or progressive loading own result boundaries.
- Compose Empty Collection outside the list when no results need recovery guidance.

## Accessibility

- Preserve DOM order so reading and keyboard order match the visual grid.
- Use native `ul`/`li` semantics; do not add the APG `grid` role or arrow-key focus management to a passive product list.
- Keep each Product Card's accessible name independent from the grid container.
- Announce result-count changes outside the grid when filtering is asynchronous.
