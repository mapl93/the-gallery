## Overview

Comparison Table frames a target-owned native table with an optional visible section heading. The table slot retains caption, header, row, and cell semantics.

The parent supplies overflow containment and optional title treatment. The `table` slot owns the complete native table, including any highlighted header or cells.

## Usage Guidelines

<DoDont>
  <Do>Use concise row headers, a descriptive caption, and consistent values that support direct comparison.</Do>
  <Dont>Do not replace meaningful cell text with color or an unexplained icon alone.</Dont>
</DoDont>

Use column highlighting sparingly and preserve the same information when custom colors are unavailable.

## Accessibility

- Use a native `table` with a descriptive `caption` and correctly scoped row and column headers.
- Keep inclusion and exclusion understandable as text, not color alone.
- Make a horizontally overflowing region keyboard reachable and give it an accessible label.
- Preserve visible focus and avoid changing logical cell order for responsive presentation.
