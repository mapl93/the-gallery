## Overview

Gallery Grid arranges ordered target-owned media in a standard grid or masonry presentation. Item activation and destination semantics remain target-specific.

`grid` is the default responsive presentation. `masonry` maps to `.gallery-grid--masonry`. Hover and focus-within image treatment are visual feedback only and do not make a passive item interactive.

## Usage Guidelines

<DoDont>
  <Do>Choose media with a coherent visual relationship and supply explicit native semantics when an item has a destination.</Do>
  <Dont>Do not assume gallery items open a lightbox, navigate, or trigger commerce behavior.</Dont>
</DoDont>

Let each target decide whether an item is passive media, a native link, or another accepted composition.

## Accessibility

- Provide useful alternative text for informative images and empty alternatives for decorative images.
- Use native links or buttons only when an item has established navigation or command behavior.
- Keep captions and essential information available without hover.
- Preserve visible focus for any target-supplied interactive descendants.
