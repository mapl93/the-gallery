## Overview

Before / After presents two target-owned media layers with optional visible labels and divider or control content. The source does not establish dragging or range behavior.

The artwork is a passive comparison using the current clipped overlay presentation. `.before-after__handle` may contain a target-owned divider or control, but no drag, pointer capture, range value, keyboard increment, or synchronization behavior is implied.

## Usage Guidelines

<DoDont>
  <Do>Use matched media with the same framing so the comparison is meaningful.</Do>
  <Dont>Do not describe the component as a slider unless the target provides complete native or ARIA range behavior.</Dont>
</DoDont>

Keep visible labels concise and let the target decide whether comparison is passive or interactive.

## Accessibility

- Give both informative media layers alternatives that distinguish their states.
- Keep before and after labels available as text, not embedded only in imagery.
- Hide a purely decorative divider from assistive technology.
- If a target makes the control interactive, it must define an accessible name, current value, minimum and maximum, keyboard operation, pointer behavior, and announcements.
