## Overview

Image with Text pairs target-owned media with a required heading and narrative body, plus optional eyebrow copy and a Button-composed action.

`default` is the side-by-side presentation and has no modifier class. `reversed` maps to `.image-text--reversed`, `stacked` to `.image-text--stacked`, `overlay` to `.image-text--overlay`, and `offset` to `.image-text--offset`. Reversed changes visual placement without requiring source-order changes.

## Usage Guidelines

<DoDont>
  <Do>Keep media and narrative closely related and preserve a readable source order.</Do>
  <Dont>Do not duplicate Button properties or activation behavior on the parent section.</Dont>
</DoDont>

Use Overlay only when the supplied media and contrast treatment keep all foreground content legible.

## Accessibility

- Give informative media useful alternative text; use `alt=""` when it is decorative.
- Choose a heading level appropriate to the page outline.
- Preserve logical reading order when Reversed changes only visual placement.
- The optional action retains Button link or command semantics and visible focus.
