## Presentation

The required `items` slot contains native ordered `.masonry-gallery__item` records. Each record requires a `.gallery-piece` and image; caption, title, and price regions are optional. The gallery grows from one to a maximum of three columns from its own available inline size, without viewport breakpoints or JavaScript measurement.

The canonical candidate intentionally uses passive figures and persistent caption metadata on every input. ADR 0080 leaves activation unresolved: a target may later choose passive pieces, native links, Lightbox triggers, or more than one target-specific mode. Only semantically valid target-native interaction may opt into paired fine-pointer hover and focus-visible disclosure.

## Usage Guidelines

<DoDont>
  <Do>Use native list/figure markup, keep artwork in a meaningful source order, and let target-owned natural dimensions shape the columns.</Do>
  <Dont>Do not assume that every gallery piece opens a link or Lightbox.</Dont>
</DoDont>

- Use concise overlay metadata that does not replace the image description.
- Choose title and price content according to target data policy.
- Omit an empty caption, title, or price instead of rendering blank anatomy.
- Add native interactive markup only after the target activation mode is decided.

## Accessibility

- Give every meaningful artwork image useful alternative text and mark decorative images accordingly.
- Keep passive caption title and price visibly available without hover-only interaction.
- If a target makes a piece interactive, use native link or button semantics with an accessible name and visible focus.
- Preserve source order across intrinsic column changes; do not use dense packing, CSS order, or image scale alone to communicate activation.

## References

**Dependencies:** None. Lightbox is not a dependency while activation remains unresolved.

**Anatomy:** required native `.masonry-gallery` list, `.masonry-gallery__item` list item, passive `.gallery-piece` figure, and piece image; optional `.gallery-piece__overlay` caption, `.gallery-piece__title`, and `.gallery-piece__price`.
