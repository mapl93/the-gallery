## Usage Guidelines

<DoDont>
  <Do>Use the collection grid with product cards for consistent spacing and responsive behavior.</Do>
  <Dont>Don't mix collection grid with manual floats or absolute positioning.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Collection components handle responsive breakpoints automatically via CSS Grid.
</Callout>

- Use `<nav>` with `aria-label` to identify the navigation region.
