## Overview

Stats Counter presents a small target-owned set of comparable facts beneath an optional contextual heading. It is a passive section composition, not a dashboard, chart, live region, formatter, or count-up controller.

The parent owns the optional title, list placement, and responsive section rhythm. Every list item consumes the canonical `Stat` implementation for its value, label, optional comparison, and number features.

## Usage Guidelines

<DoDont>
  <Do>Pair every target-formatted value with concise visible context, including any unit or period needed to understand it.</Do>
  <Dont>Do not mix unrelated facts, infer business meaning from a sign, or imply live data without a target-owned update model.</Dont>
</DoDont>

Keep the metric set comparable and avoid mixing unrelated units without enough context.

## Accessibility

- Use a native unordered list when metric order does not change meaning and preserve that source order across responsive columns.
- Keep each canonical Stat value and label adjacent in the reading order.
- Include units, qualifiers, and scope needed to understand the value without relying on punctuation, color, or motion alone.
- Static metrics are not live regions. Targets that update values own atomic replacement and announcement policy; intermediate count-up frames must never be announced.
