## Presentation

Drawer enters from the right by default. `left` changes its resting and open transform while preserving the same anatomy and modal behavior requirements.

| Element     | Class             | Purpose                                  |
|-------------|-------------------|------------------------------------------|
| Overlay     | `.drawer-overlay` | Darkened backdrop layer                  |
| Container   | `.drawer`         | Fixed side panel                         |
| Header      | `.drawer__header` | Optional title and close region          |
| Close       | `.drawer__close`  | Optional close control                   |
| Body        | `.drawer__body`   | Scrollable primary content region        |
| Footer      | `.drawer__footer` | Optional action or summary region        |

## Usage Guidelines

<DoDont>
  <Do>Use Drawer for supporting tasks that benefit from preserving page context.</Do>
  <Dont>Don't nest another modal overlay inside a Drawer.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Layout components handle z-index and focus trapping. Test keyboard navigation before shipping.
</Callout>

- Trap focus inside the overlay while open. Return focus to the trigger on close.
- Close on `Escape` key press.
- Provide `role="dialog"`, `aria-modal="true"`, and a programmatic name when page interaction is blocked.
