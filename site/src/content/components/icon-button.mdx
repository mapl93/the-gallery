## Overview

Icon-only native button for compact actions whose visible symbol is paired with a required accessible name.

## Presentation

Default and Filled control visual emphasis. Round is an independent shape and may compose with either variant and every size.

| Property | Values | Web mapping |
| --- | --- | --- |
| `variant` | `default`, `filled` | base or `.icon-btn--filled` |
| `size` | `sm`, `default`, `lg` | base, `.icon-btn--sm`, `.icon-btn--lg` |
| `round` | boolean | `.icon-btn--round` |
| `disabled` | boolean | native `disabled` |

## Usage Guidelines

<DoDont>
  <Do>Use a familiar icon for a compact action whose meaning is clear in context.</Do>
  <Dont>Do not use Icon Button when a visible text label would remove ambiguity.</Dont>
</DoDont>

Filled increases emphasis; Round changes only shape. Neither changes the action's semantics.

## Accessibility

<Callout type="info">
  The icon is decorative. `aria-label` or `aria-labelledby` supplies the complete action name.
</Callout>

- Use a native `button` with `type="button"` for actions.
- Keep the accessible name aligned with the action, not the icon filename.
- Add `aria-hidden="true"` to the icon when the button already has an accessible name.
- Use native `disabled` when the action is unavailable.
- Do not remove the focus-visible indicator.
- Every accepted size exceeds the WCAG 2.2 `24 x 24px` minimum target.
- Decorative color and background transitions are removed when reduced motion is requested.
