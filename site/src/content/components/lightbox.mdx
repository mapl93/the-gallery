## Usage Guidelines

<DoDont>
  <Do>Use lightbox for focused image viewing, galleries, captions, and zoomed media context.</Do>
  <Dont>Don't use lightbox for forms or non-image workflows that should be a Modal or Drawer.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Lightbox inherits modal behavior: focus management, Escape dismissal, and restored focus are target responsibilities.
</Callout>

- Trap focus inside the overlay while open. Return focus to the trigger on close.
- Close on `Escape` key press.
- All images must have descriptive `alt` text.
- Keep captions, counters, and accessible descriptions synchronized when navigating images.
- Respect reduced motion preferences for image transitions.
