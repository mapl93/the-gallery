## Overview

Single-choice field with validation feedback, a select-only combobox trigger and listbox anchored below the control, plus a native select fallback and form-value owner.

## Presentation

Select has default, error, success, and warning variants plus one default size. When `theme.js` loads, it generates a control wrapper, trigger, and custom listbox from the native options. The panel opens below the field with an `8px` gap instead of covering the selected value. Without an explicit width, the trigger follows its current content; the panel may grow wider to preserve option legibility while remaining within the viewport.

Hover preserves the active Error, Success, or Warning color family instead of returning the trigger border to Default.

When `required` is true, the native select owns constraint validation, the enhanced trigger mirrors it with `aria-required`, and the label shows a decorative asterisk optically centered with the text. The marker is not part of the accessible name.

## Usage Guidelines

Select shares Input's public label/message gaps, border/focus dimensions and
typography. Its popup adds controls for panel gap, padding, border, maximum
dimensions, shadow, indicator size/gap and option spacing/selected weight. The
maximum panel width remains bounded by the viewport and the trigger's minimum
width. These popup controls apply to enhanced Select; the native popup is drawn
by the browser. Validation colors remain inputs to the documented contrast mix.
Disabled color is one shared control for the disabled value, indicator and
options; the ordinary color controls are inactive when those parts are disabled.

<DoDont>
  <Do>Use Select when a person chooses one value from a compact, known list.</Do>
  <Dont>Do not use Select for commands, navigation, or multiple selection.</Dont>
</DoDont>

<DoDont>
  <Do>Use a hidden, selected empty-value option when the field needs an initial prompt.</Do>
  <Dont>Do not use the prompt as a substitute for the visible label.</Dont>
</DoDont>

<DoDont>
  <Do>Pair Error, Success, and Warning styling with a concise, associated message.</Do>
  <Dont>Do not communicate validation through label, border, or chevron color alone.</Dont>
</DoDont>

Use Combobox instead when the list requires search, filtering, asynchronous results, or free-form input.

## Accessibility

<Callout type="info">
  The native select remains the form value and no-JavaScript fallback. The enhanced UI follows a single-select listbox pattern.
</Callout>

- Associate the visible label with the enhanced trigger and listbox.
- Expose the generated trigger as `role="combobox"` with a listbox popup.
- Keep focus on the trigger while arrow keys update `aria-activedescendant`.
- Expose `aria-expanded`, `aria-controls`, `aria-selected`, and `aria-disabled` as documented by the contract.
- Support Arrow Up, Arrow Down, Home, End, Enter, Space, Escape, Tab, and typeahead.
- Close after selection, outside interaction, Escape, Tab, or repeated trigger activation.
- Synchronize every custom selection to the original native field and dispatch native `input` and `change` events.
- Connect supporting and validation messages to both the native field and generated trigger with `aria-describedby`.
- Add `aria-invalid="true"` to the native field for errors; the enhancer mirrors it to the trigger. Success and Warning do not use `aria-invalid`.
- Keep the placeholder as a hidden empty-value native option so it labels the closed trigger without appearing as a disabled choice.
- Use the native `disabled` attribute for unavailable fields and disabled native options for unavailable choices.
- Put `name` and `required` on the native select. The enhancer reflects required state with `aria-required` on the combobox trigger and synchronizes `.select__label--required` for the decorative visual marker.
- Treat the native select as the only value owner. Framework adapters may set its value and consume native `input` and `change` events; they must not create a second enhanced value state.

Choices remain native `<option>` children of `.select__field`. The shared `theme.js` generates `.select__control`, `.select__trigger`, `.select__value`, `.select__indicator`, `.select__listbox`, `.select__option`, and `.select__option-check`, then keeps them synchronized with the native field. The chevron and selected check use Lucide geometry.

The custom popup is deliberately limited to a flat, single-choice native select. A field with `multiple`, `size` greater than one, or `<optgroup>` content remains a styled native select so its richer selection and grouping semantics are not flattened. Use Combobox for search, filtering, asynchronous options, or free-form input.

With reduced motion enabled, field transitions and the decorative chevron rotation are removed while open state remains available through `aria-expanded` and the visible popup.
