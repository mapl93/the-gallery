## Usage Guidelines

<DoDont>
  <Do>Use section components for page builder blocks — they're designed to be reorderable in Shopify's theme editor.</Do>
  <Dont>Don't hard-code section content — use Shopify schema settings for customizability.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Sections map to Shopify's section architecture. Each one can have its own schema settings.
</Callout>

- All images must have descriptive `alt` text.
