## Overview

Two-button control for switching a collection between grid and list presentation.

## Presentation

The active button uses the primary-action background and text tokens. Both controls share a compact border and preserve a 4px focus indicator.

## Usage Guidelines

<DoDont>
  <Do>Offer the toggle only when both layouts provide meaningful value.</Do>
  <Dont>Do not reset filters, sort order, or scroll position solely because the view changes.</Dont>
</DoDont>

- Keep Grid and List in a stable order.
- Apply the selected mode to the results region without moving focus.
- Persist the preference only when the target product has a clear policy for it.

## Accessibility

- Give the group and both icon-only buttons accessible names.
- Keep `aria-pressed` synchronized so exactly one view is active.
- Use native buttons for Space and Enter behavior.
- Disable both buttons when view switching is unavailable.
