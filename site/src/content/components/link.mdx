## Overview

Native anchor primitive for inline and navigation destinations, with Default, Subtle, and Nav visual treatments.

<Preview html={'<a class="link" href="#link-reference">View the collection</a>'} label="Link" />

## Presentation

`variant` changes visual emphasis without changing native anchor behavior. Default is underlined and uses the accent text token, Subtle removes the resting underline and lowers emphasis, and Nav uses primary text with medium weight.

<Preview html={'<nav aria-label="Example navigation"><span class="tg-preview-inline"><a class="link" href="#link-default">Default link</a><a class="link link--subtle" href="#link-subtle">Subtle link</a><a class="link link--nav" href="#link-nav" aria-current="page">Nav link</a></span></nav>'} label="Link variants" />

| Property | Value | Web mapping |
| --- | --- | --- |
| `label` | text | Anchor content |
| `href` | destination | `<a href>` |
| `variant` | `default` | `.link` |
| `variant` | `subtle` | `.link.link--subtle` |
| `variant` | `nav` | `.link.link--nav` |
| `target` | text | `<a target>` when present |
| `rel` | relationship tokens | `<a rel>` when present |
| `currentPage` | `true` | `aria-current="page"` |

Hover and keyboard focus are native interaction states supplied by canonical CSS. Decorative color and underline transitions are removed under reduced motion. `currentPage` communicates navigation context but does not create a fourth visual variant.

## Usage Guidelines

<DoDont>
  <Do>Use Link when activation navigates to a destination identified by `href`.</Do>
  <Dont>Don't use Link for an action that changes local interface state; use Button.</Dont>
</DoDont>

<DoDont>
  <Do>Choose visible text that still identifies the destination outside its surrounding sentence.</Do>
  <Dont>Don't use generic labels such as “click here” or expose the raw URL as the label.</Dont>
</DoDont>

## Accessibility

<Callout type="info">
  Link keeps native anchor semantics. Its keyboard behavior and destination come from a real `a` element with `href`.
</Callout>

- Ensure proper color contrast ratios (4.5:1 for text, 3:1 for large text) when customizing tokens.
- Use real `href` values for navigation and keep buttons for actions.
- Let long localized or unbroken labels wrap instead of truncating the destination name.
- Use `aria-current="page"` for the active navigation destination.
- Preserve the canonical focus-visible outline.
- Honor reduced-motion preferences when changing transition tokens.
- When `target="_blank"` opens an untrusted destination, include an appropriate `rel`, commonly `noopener`.
