## Overview

Address Book is an authenticated grid of target-owned address cards and actions. It can identify a default address and include an add-address action with an optional visible label.

## Presentation

`addresses` is one required slot containing the repeated address cards, their default state, and their actions. Recipient names, formatted addresses, card count, ordering, and action availability are fixture or target data rather than Address Book properties.

`newAddressLabel` controls the visible text inside the optional `.address-card--new` action. The target owns navigation or disclosure into Address Form and all create, edit, delete, and default-address mutations.

## Usage Guidelines

<DoDont>
  <Do>Identify the default address with visible text as well as its border treatment.</Do>
  <Dont>Do not expose address data before the target authenticates and authorizes the customer.</Dont>
</DoDont>

- Format address lines according to their locale and target data model.
- Keep card actions concise and specific to the address they affect.
- Confirm destructive deletion according to target policy.
- Preserve the current default address until a target mutation succeeds.

## Accessibility

- Protect address data behind the target authentication system.
- Expose the default state as readable text, not color alone.
- Give edit and delete actions names that identify the affected address.
- Implement the add-address card as a keyboard-operable button or link with visible focus.
- Announce the result of address mutations through target-owned feedback.
