## Overview

The product card is the primary way to display items in collection grids and related product sections. It combines an image with hover effects, vendor info, title, and pricing.

## Anatomy

| Element                     | Class                    | Purpose                       |
|-----------------------------|--------------------------|-------------------------------|
| Card                        | `.product-card`          | Container with hover shadow   |
| Media                       | `.product-card__media`   | Image wrapper (link)          |
| Image                       | `.product-card__image`   | Product photo with hover zoom |
| Body                        | `.product-card__body`    | Text content area             |
| Vendor                      | `.product-card__vendor`  | Brand/vendor name             |
| Title                       | `.product-card__title`   | Product name (link)           |
| Footer                      | `.product-card__footer`  | Price and actions              |

## Usage in Grids

Product cards are designed to work inside CSS Grid layouts. The card is fully fluid — it fills its grid cell width.

```html
<div class="collection-grid">
  <article class="product-card">…</article>
  <article class="product-card">…</article>
  <article class="product-card">…</article>
</div>
```

<Callout type="tip">
  The card image uses `object-fit: cover` and a subtle scale transform on hover. No extra JS needed for the hover zoom effect — it's pure CSS.
</Callout>

## Usage Guidelines

<DoDont>
  <Do>Keep card content minimal: image, vendor, title, price. Let the image do the heavy lifting.</Do>
  <Dont>Don't overload cards with descriptions, ratings, and multiple CTAs. Save detail for the product page.</Dont>
</DoDont>

<DoDont>
  <Do>Use consistent image aspect ratios across all cards in a grid.</Do>
  <Dont>Don't mix landscape and portrait images in the same collection grid.</Dont>
</DoDont>

## Accessibility

- The card image must have a descriptive `alt` attribute.
- The product title link is the primary interactive element — it should be descriptive enough for screen readers.
- Avoid wrapping the entire card in a single `<a>` — it makes the accessible name too long. Keep links on the image and title separately.
