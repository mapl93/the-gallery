## Overview

Cart Upsell presents target-owned product recommendations and an add action for each available item. The component owns the compact recommendation layout, while recommendation source and purchase rules remain outside it.

## Presentation

The required `items` slot contains target-owned recommendation rows. Each row may compose media, title, formatted price, and the required add action label. `.cart-upsell__action` composes the Button dependency without redefining Button states.

`addDisabled` defaults to `false` and disables recommendation actions when the selected item or variant is unavailable.

## Usage Guidelines

<DoDont>
  <Do>Recommend a small set of relevant, currently purchasable items.</Do>
  <Dont>Do not let recommendations compete with line-item editing or checkout.</Dont>
</DoDont>

- Let the target own recommendation ranking, inventory, and variant-selection rules.
- Update cart totals after a successful add action.
- Keep recommendation prices target-formatted and synchronized with selected variants.

## Accessibility

- Use a heading that identifies the recommendation region.
- Give each add action an accessible name that includes the recommendation title.
- Use useful image alternative text, or hide redundant media when adjacent text names the product.
- Communicate unavailable actions beyond disabled styling alone.
- Announce successful cart additions and resulting count changes without moving focus unexpectedly.
