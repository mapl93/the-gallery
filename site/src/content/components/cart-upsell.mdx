## Overview

Cart Upsell presents a small target-owned recommendation list near a cart. It owns the named compact region and item layout; recommendation source, ranking, availability, destinations, variant selection, price formatting, cart mutation, result status, analytics, and refresh remain target responsibilities.

## Presentation

The required `items` slot contains a non-empty native list of target-authored recommendations. Each item has a non-empty identity and may independently compose media, canonical Link, canonical Price, and canonical Button. The whole component is omitted when the title is blank or no valid item exists.

Direct add is optional. Omit it when a product requires variant selection or the target cannot support a truthful one-click request. Per-item labels, accessible names, availability, and pending state belong inside the item composition; there is no collection-wide add label or disabled property.

The layout wraps from its actual available width, so the same markup fits a cart page, drawer, or embedded surface without a viewport breakpoint. External spacing belongs to the parent.

## Usage Guidelines

<DoDont>
  <Do>Recommend a small set of relevant, currently truthful product options.</Do>
  <Dont>Do not claim “frequently bought together” or expose direct add unless the target can support that promise.</Dont>
</DoDont>

- Preserve target recommendation URLs, including tracking parameters.
- Keep recommendation controls secondary to line editing, totals, and checkout.
- Let each item expose only capabilities that are valid for that product and target.
- Hide the complete region when no recommendation is available; do not leave an empty heading or list.
- Announce confirmed cart results in the parent target status surface rather than making K6 a live region.

## Accessibility

- Label the `section` from its visible heading with a unique `aria-labelledby` relationship.
- Use `ul` and `li`; do not add listbox, selection, carousel, or custom arrow-key behavior.
- Use canonical Link for navigation and canonical Button for actions.
- Give repeated actions contextual accessible names that include the product identity.
- Use canonical Price for complete target-formatted and bidirectionally isolated price text.
- Use `alt=""` when adjacent product identity makes the image redundant; provide concise alternative text only when media adds information.
- Keep unavailable and pending truth per item. The target owns confirmed success/error copy and focus behavior.
