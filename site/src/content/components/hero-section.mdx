## Deprecated identity

Hero Section (`S1`) is deprecated as an independent public component. The
owner-selected `G1-A` direction keeps one public [Hero](/components/hero) and
moves all useful S1 anatomy and layout profiles into that canonical identity.

This migration record renders the same Hero renderer and fixture as G1. It owns
no independent CSS, behavior, Studio implementation, or Shopify adapter and
must not be used for new consumer code.

## Canonical mapping

- `.hero-section` → `.hero`
- `.hero-section__inner` → `.hero__inner`
- `.hero-section__media` → `.hero__media`
- `.hero-section__slide` → `.hero__slide`
- `.hero-section__overlay` → `.hero__overlay`
- `.hero-section__content` → `.hero__content`
- `.hero-section__eyebrow` → `.hero__label`
- `.hero-section__title` → `.hero__title`
- `.hero-section__subtitle` → `.hero__description`
- `.hero-section__actions` → `.hero__actions`

The canonical Hero additionally owns `.hero__track`, `.hero__controls`,
`.hero__previous`, `.hero__next`, `.hero__indicators`,
`.hero__indicator`, `.hero__rotation-control`, `.hero__progress`,
`.hero__progress-value`, and `.hero__status`.

Layout modifiers migrate to `.hero--split`, `.hero--text-only`, and
`.hero--fullscreen`. Current slide uses
`.hero__slide[aria-current="true"]`; playback uses
`.hero[data-autoplay-state="playing"]` or
`.hero[data-autoplay-state="paused"]`; reduced motion is reflected through
`.hero[data-reduced-motion="true"]`. Loop, autoplay, navigation, parallax, and
slideshow use the canonical `data-loop`, `data-autoplay`,
`data-navigation`, and `data-media-behavior` mappings.

## Migration API

The temporary contract mirrors canonical `layout`, `height`,
`mediaBehavior`, `label`, `title`, `description`, `media`, `overlay`,
`actions`, `slides`, `autoplay`, `loop`, `navigation`,
`autoplayInterval`, `previousLabel`, `nextLabel`, `pauseLabel`,
`playLabel`, and `statusTemplate` only so existing S1 references can be
reviewed and migrated. Its contract status is `deprecated`, never `stable`.
