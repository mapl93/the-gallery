## Overview

Passive metric display with target-formatted value, label, and optional directional change.

## Presentation

Stat has one size and variant. Change Direction is semantic presentation on the optional change text; Neutral applies no directional color. Numeric value and change text use Inter through `--font-family-body`.

The same four OpenType controls as Price are available independently: alternate digits (`ss01`), tabular numbers (`tnum`), contextual alternates (`calt`), and fractions (`frac`). Slashed zero is fixed off across the interface; unsupported enabled features are ignored by the active font.

## Usage Guidelines

<DoDont><Do>Format numbers, currency, and percentages in the target locale before rendering.</Do><Dont>Do not infer whether an increase is good or bad from its mathematical sign alone.</Dont></DoDont>

Direction describes mathematical movement, while the target decides the business meaning and wording. Up is not inherently favorable and Down is not inherently unfavorable.

Every textual part wraps extreme or localized content, and Stat Group caps its `120px` preferred track minimum by the available container width.

## Accessibility

- Keep value, label, and change together in reading order.
- Include a sign or directional word so color is not the only cue.
- Use concise labels that remain meaningful outside a visual dashboard grid.

## Visual Customization

Studio and Exhibit expose sixteen public roles, including content gap (4px), preferred group column minimum (120px), shared bold value weight and semibold change weight. The existing grid-gap token stays responsive; the container bounds the requested minimum so a narrow layout can still fit.

The optional Group preview control mounts the current metric with two site-owned examples to exercise group gap and reflow. It is fixture data, not a new public component property, and reset returns to the original single metric. Up/down colors remain a documented mix of 55% feedback and 45% primary text. Formatting, OpenType features, reading order and business meaning retain their existing contracts.
