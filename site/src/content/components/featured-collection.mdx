## Overview

Featured Collection arranges ordered Product Card compositions beneath an optional heading and collection destination. Product queries, sorting, limits, availability, and pricing freshness remain target-owned.

`grid` is the default presentation. `carousel` maps to `.featured-collection--carousel`, and `spotlight` maps to `.featured-collection--spotlight`. Spotlight visually emphasizes the first supplied item; whether that emphasis becomes record metadata remains unresolved.

## Usage Guidelines

<DoDont>
  <Do>Supply an ordered set of complete Product Card compositions with consistent media proportions.</Do>
  <Dont>Do not make Featured Collection responsible for product fetching, pricing freshness, or Product Card actions.</Dont>
</DoDont>

Use the optional collection link only when it has a real navigation destination. The parent controls arrangement; every child retains Product Card semantics.

## Accessibility

- Use a logical section heading and descriptive link label.
- Preserve each Product Card heading, media alternative, link, focus, price, and action requirements.
- Keep horizontal overflow keyboard reachable when a target uses the carousel presentation.
- Announce loading, empty, and error conditions in the target data layer rather than through visual layout modifiers.
