## Overview

Announcement Bar Extended adds existing Countdown, Rotating, and Dismissible presentation evidence to the Announcement Bar dependency.

## Presentation

<Preview html={'<aside class="announcement announcement-bar--countdown tg-preview-frame" aria-label="Limited-time gallery announcement"><span>Studio event closes in</span><strong>2 days, 14 hours</strong></aside>'} label="Announcement Bar with Countdown" />

Countdown uses `.announcement-bar--countdown`; Rotating uses `.announcement-bar--rotating` with `.announcement-bar__slides` and repeated `.announcement-bar__slide` rows; Dismissible uses `.announcement-bar--dismissible` with a named native `.announcement-bar__dismiss` button.

The source does not yet decide whether countdown, rotation, and dismissal are exclusive variants, orthogonal capabilities, or constrained combinations.

## Usage Guidelines

<DoDont>
  <Do>Preserve the base Announcement Bar message and link semantics while selecting only behavior supported by the consuming target.</Do>
  <Dont>Do not infer valid capability combinations, message counts, cadence, persistence, or countdown behavior from the CSS examples.</Dont>
</DoDont>

The current rotation is presentation evidence only. A complete model still requires accepted controls, pause behavior, synchronization, current-message exposure, and target ownership.

## Accessibility

- Preserve readable Announcement Bar content and native link semantics.
- Provide a named native dismiss button when dismissal is offered.
- Do not rotate critical legal, checkout, or safety information.
- Pause or replace automatic rotation when a rotation model is accepted, and disable the current CSS animation for reduced motion.
- Do not describe Countdown, Rotating, and Dismissible as freely composable or mutually exclusive until that boundary is accepted.
