## Overview

Artist Profile is a named, container-responsive editorial biography that preserves portrait-first source order and composes target-owned rich content and canonical actions.

## Presentation

The default presentation stacks into one column and becomes a balanced two-column layout when the component content box is at least `36rem` wide. `portrait`, `label`, `location`, `philosophy`, and `actions` are optional; `name` and `biography` are required. Omitting the portrait leaves one full-width content column at every size.

Biography and actions are target-owned slots. Their rich content and controls retain their own semantics, while Artist Profile owns the named section, narrative order, intrinsic rhythm, and responsive composition. The component has no local state or JavaScript runtime.

Portrait ratio, label tracking, biography paragraph gap, quotation border/inset,
accent share and action gap are public tokens alongside the existing system
values. Ratio means width divided by height; the initial portrait ratio is 0.75.
The quotation accent share starts at 0.7 and accepts a 0–1 fraction of the
existing accent/primary palette mixture. It is not text opacity. Typeface and
italic quotation treatment remain the accepted editorial baseline.

Copy-and-own consumers explicitly adopt the CSS/token update. No new source
mode, interaction property, target data model or remote publication is added.

## Usage Guidelines

<DoDont>
  <Do>Keep the biography focused and preserve the authored narrative sequence.</Do>
  <Dont>Do not rearrange the source order to match the wide visual columns.</Dont>
</DoDont>

- Use portrait media that supports the biography rather than repeating it.
- Keep the philosophy concise enough to remain a supporting quotation.
- Compose only actions that belong to the artist context and use canonical Button or Link semantics for each control.
- Omit optional parts instead of leaving empty media, quotation, or action wrappers.

## Accessibility

- Associate the section with the visible artist heading through a target-unique `aria-labelledby`/`id` pair.
- Use a heading level appropriate to the surrounding page for the artist name; the visual class does not require `h2`.
- Give informative portrait media concise useful alternative text, use `alt=""` when it is decorative, and omit the portrait region when absent.
- Preserve source reading order when the layout changes between one and two columns.
- Use `blockquote` only for a real quotation.
- Keep composed actions keyboard accessible with native semantics and canonical visible focus; the action group is not an extra navigation landmark.
- Allow localized, unbroken and zoomed content to reflow without horizontal viewport overflow.
