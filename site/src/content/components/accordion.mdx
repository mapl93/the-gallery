## Usage Guidelines

<DoDont>
  <Do>Use accordions to reveal related content while keeping the page scannable.</Do>
  <Dont>Don't hide critical information inside collapsed panels when users must see it to continue.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  Accordion panels depend on synchronized `aria-expanded` state and target adapter behavior.
</Callout>

- Use `aria-expanded` and `aria-controls` to communicate state to screen readers.
- Use a native `button` for each trigger.
- Support Enter and Space activation.
