## Usage Guidelines

<DoDont>
  <Do>Use Dropdown Menu for a compact set of immediate, related commands opened from a clearly labelled Button.</Do>
  <Dont>Don't use it for primary navigation, value selection, arbitrary content, or unaccepted nested/checkable menu APIs.</Dont>
</DoDont>

## Accessibility

<Callout type="warning">
  The CSS adapter provides visual and semantic state hooks; every target must implement the Menu Button focus and keyboard contract.
</Callout>

- Use a button trigger with `aria-haspopup="menu"`, `aria-expanded`, and `aria-controls`.
- Move focus to the first command on Enter/Space open; optional ArrowDown/ArrowUp open first/last.
- Maintain one roving `tabindex`; support ArrowUp/Down, Home/End, optional printable typeahead, Enter/Space, Escape, and non-trapping Tab exit.
- Close on Escape/outside/select and restore trigger focus after keyboard dismissal.
- Use labelled `role="group"` wrappers and `role="separator"` for menu structure.
- Expose disabled state through native, ARIA, or adapter data mapping and never activate unavailable commands.

## Visual Customization

46 public roles expose surface and shared item customization. The surface has independent minimum/maximum width (11.25rem/20rem), maximum height (20rem), padding (0.25rem), border (1px), trigger gap (0.25rem), upward entrance displacement (4px), and total viewport gutter factor (2). Width remains intrinsic within its bounds; height overflow scrolls. Keep minimum width at or below maximum.

Shared item tokens cover minimum height (2.5rem), gap and block/inline padding factors (0.5 and 0.25/0.75), transparent border width (1px), focus width/inset (2px each), icon size (1rem), shortcut extra-gap factor (0.5), separator width/block-gap (1px/0.25), label top/inline/bottom padding factors (0.375/0.75/0.25) and tracking (0.05em). Factors follow the existing responsive spacing base. Coarse input uses the greater of item minimum and shared touch target, so a larger custom row does not shrink on touch. Icon content and shortcut text remain consumer data.

Label weight reuses semibold; forced-color danger weight reuses bold as an additional cue. Danger text retains the documented 55% error plus 45% primary mix; Studio identifies both inputs. It is a per-item variant independent from hover, highlight and disabled. Context Menu composes that child variant without adding a second scalar property. Native forced colors remain authoritative for system colors.
