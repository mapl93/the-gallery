## Usage Guidelines

<DoDont>
  <Do>Explain what failed and how the user can correct it.</Do>
  <Dont>Don't rely on the icon or error color as the only message.</Dont>
</DoDont>

## Accessibility

- Associate the message with its invalid control through `aria-describedby`.
- Set `aria-invalid="true"` on the control, not the message.
- Use a polite announcement for routine validation and assertive only when interruption is necessary.
- Hide decorative icons from assistive technology.
