## Overview

Collection-specific resolved-empty profile with zero intentional visual
divergence from canonical Empty State. The owning target selects it only after
collection results are resolved, supplies truthful localized content, replaces
stale results, and composes at most one recovery action.

## Presentation

`.empty-collection` is a Collection-domain hook layered on `.empty-state`; it adds no independent visual API. Canonical Empty State owns centered composition, optional decorative icon, title/message typography, semantic spacing, container response, wrapping, light/dark behavior and optional action placement. Canonical Button or Link owns action presentation and behavior.

The full candidate is intentionally sparse. The icon, copy and Clear filters Button are Studio fixtures, not defaults. Final center alignment, icon treatment, hierarchy, spacing, measure and action prominence require human visual review.

## Usage Guidelines

<DoDont>
  <Do>Select E7 from authoritative resolved collection state and offer one truthful recovery path.</Do>
  <Dont>Do not show it while results are loading or leave stale cards and Pagination focus stops beside it.</Dont>
</DoDont>

- Use concise localized title text that identifies the actual absence. Omit the complete profile when title is blank.
- Use `message` only when it explains the cause or useful next step without repeating the title.
- Keep the icon decorative and text-redundant. A meaningful illustration needs a different alternative-text contract.
- Compose Button when recovery is a command such as an in-place reset. Compose Link when recovery navigates to a real URL. Do not invent a destination.
- The parent collection target decides whether active filters/sort controls remain useful and atomically replaces Grid and Pagination output.
- Do not expose no-inventory/no-results cause variants. Empty source inventory,
  filtered/search zero and merchandising exclusion remain target lifecycle facts
  expressed through truthful content and available recovery.

## Accessibility

- Render `title` in the contextual native heading selected by the host under ADR 0236. The docs target uses H2; heading rank is not an E7 property or visual control.
- Keep static or route-rendered E7 as ordinary content with no role, landmark, `tabindex`, focus trap or automatic live region.
- If an in-place filter, search, removal or section update produces a qualifying “no results” status message, announce concise target-owned text through a pre-existing Status owner without moving focus or duplicating the full visible title.
- Use one native canonical Button or Link with a descriptive accessible name and preserve its keyboard, focus, disabled/loading, forced-color and reduced-motion behavior.
- Remove stale result and Pagination focus stops in the same transition. Deliberately preserve useful filter controls when they are the recovery path.
- Do not use E7 for loading, generic error, permissions, offline or unresolved data states.
- Long localized, unbroken and bidirectional content must grow and wrap without clipping at narrow containers, text spacing and 200% zoom.
