# ADR 0408: 404 and Checkout Progress Visual Values

Status: Accepted

Date: 2026-09-13

Expose eleven 404 roles for code typography, section/core/search/suggestion
measures and suggestion geometry; three Checkout Progress roles for its maximum
width and narrow item/content spacing factors, plus the existing shared element
gap. Defaults and container boundaries remain. Checkout Progress keeps canonical
Steps visuals and passive status semantics; no duplicate stepper or workflow state.

404 composes Empty State, Input and Button. Recovery/search destinations, checkout
records and statuses remain target-owned. Studio/Exhibit use public contract
inventories; Web/Shopify regenerate from source. Copies adopt explicitly.
