## Overview

Compact category, filter, or selected-value label with an optional named remove action.

<Preview html={'<div class="tg-preview-frame tg-preview-frame--sm"><span class="tag"><span class="tag__label">Stoneware</span><button class="tag__remove" type="button" aria-label="Remove Stoneware filter"></button></span></div>'} label="Removable tag" />

## Presentation

Tag has one neutral variant and one compact size. The visible value is required; the remove button is optional and uses a fixed X indicator with accepted Lucide geometry.

| Property | Value | Web mapping |
| --- | --- | --- |
| `label` | text | `.tag__label` |
| `removeAction` | `true` | `.tag__remove` button slot |
| `removeLabel` | text | `.tag__remove[aria-label]` |
| `removalDisabled` | `true` | `.tag__remove[disabled]` |

## Usage Guidelines

<DoDont>
  <Do>Use Tag to represent one current value, applied filter, or category that may be removed.</Do>
  <Dont>Do not use Tag as a passive status; use Badge instead.</Dont>
</DoDont>

<DoDont>
  <Do>Keep only the remove button interactive when removal is the available action.</Do>
  <Dont>Do not make the full Tag clickable unless the product requirement is navigation, in which case use Link.</Dont>
</DoDont>

The native button emits the removal request. The consuming target owns the state update, DOM removal, focus destination, and contextual announcement. Render the action only when `removeLabel` is non-empty; `removeAction` without a valid accessible name is an invalid composition and degrades to a passive Tag.

## Accessibility

<Callout type="info">
  The remove control is a native `button`, so Enter and Space activation work without custom keyboard handling.
</Callout>

- Use `type="button"` so removal does not submit a surrounding form.
- Include the visible value in the accessible name, such as `Remove Stoneware filter`.
- Keep the remove action at least 24 by 24 CSS pixels.
- Keep the X indicator decorative; the button's accessible name communicates the action.
- When removal changes an editable list or active filters, announce the result from the consuming interface's live region.
- Move focus intentionally when removing the currently focused Tag from a keyboard-managed collection.
