## Overview

Lookbook presents a finite, source-ordered editorial sequence of target-owned media. Its asymmetric layout is passive: wide and tall modifiers change only geometry, while optional captions remain visible and any interaction belongs to a complete native target composition.

The renderer used by Exhibit and Studio follows the same `ol`/`li` and `figure`/`figcaption` composition. It does not create focusable cells, placeholder hotspots, hover-only content, or neutral runtime behavior.

## Usage Guidelines

<DoDont>
  <Do>Build a deliberate source order and keep every supplied caption available without pointer hover.</Do>
  <Dont>Do not use span, crop, coordinates, or visual placement as the only way to communicate meaning.</Dont>
</DoDont>

Use `.lookbook__cell--wide` and `.lookbook__cell--tall` sparingly. The layout responds to the component container and preserves sparse source-flow placement.

An optional target hotspot must have a real result. Use a native link for direct navigation, such as a product destination. A button that opens contextual content must compose Popover or an equivalent complete target implementation with open state, focus, dismissal, and relationship semantics.

## Accessibility

- A non-empty title creates a thematic section named by its visible heading; omit the section landmark when there is no title.
- Use native ordered-list markup and keep DOM order meaningful across all layout spans and widths.
- Group captioned media with `figure` and `figcaption`; provide contextual alternatives for informative media and hide decorative media correctly.
- Keep captions persistent. Do not make passive cells focusable, clickable, selectable, or hover-emphasized.
- Give every target-owned link or button an accessible name, visible focus, keyboard activation, and a defined result.
- Lookbook adds no authored motion, JavaScript, observer, listener, timer, request, or layout measurement.

## Target Translation

- **Web:** target-owned native list items and figures consume the neutral CSS contract.
- **Shopify:** reorderable image blocks map merchant content to complete figures; an optional product resource becomes a native product link with block-owned coordinates.
- **Future targets:** preserve source order, persistent caption availability, native activation semantics, and target-owned media delivery.
